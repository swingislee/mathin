# 数独教学 · 2026版 · 教师用书

全年课程：初阶四宫（1–2 年级）、中阶六宫（3–4 年级）、高阶九宫（5–6 年级），每阶 4 讲，每讲 90 分钟。年级是建议范围，入阶也看学生已有的数独经验。

共 264 页课件：13 张规则发现盘、76 张方法页、48 道课堂整题、48 道课后题。所有题目都是可操作的原生数独组件。

## 上课怎么用

- 每讲按“发现规则 → 探索 → 一起说 → 方法卡 → 练一练 → 策略页 → 完整挑战 → 小结”推进。探索页先让学生独立找，再两人交换理由；**一起说**页和**方法卡**分开，先让学生说，再翻出方法卡。
- 方法页只要求找到页面问的格子，其他空格可以留白。棋盘上有行、列、宫高亮和答案揭示；揭示前先留出探索时间。
- 每讲配一份学生讲义（学生讲义.html）：和课件同页同题、不含答案，留有作答和写理由的位置；初阶只写答案，理由靠口头说。
- 盘面统一用深色粗线分宫（课件保留彩色宫底），和纸面题目、比赛用纸一致。
- 学生页只有短提问。提问链、预期回答、常见错误都在本手册的逐页说明里；答案和每一步理由在“教师答案.md”。
- 解题顺序贯穿全课：**同一个数字逐宫找到底 → 换下一个数字 → 全停住，看空格少的行列 → 看邻居多的格子 → 区块 → 每填一个数回到宫内排除**。每讲只用到已经学过的部分。
- 完整挑战按由易到难排列；时间是按本级学生估的，第一次试课请记下实际完成时间，再调整题量。

**第 1 页 · 开场**：一个数字找到底 · 今天学会：宫内排除

**第 2 页 · 规则发现**：这张盘已经填好了 ／ 看一行：有哪些数？ / 看一列呢？ / 粗线框里呢？
- 提问：第一行有哪几个数？有没有重复？ → 换一列看看。 → 粗线围成的小方块里呢？
- 预期：每行、每列、每个粗线框都是 1、2、3、4，各出现一次。
- 留意：学生常只看行。追问列和粗线框，并告诉学生：粗线框叫“宫”。

**第 3 页 · 规则卡**：每行 · 每列 · 每宫：都填 1、2、3、4 / 不重复，也不缺

**第 4 页 · 热身 · 宫里只差一个**：哪个宫只差一个数？ ／ 找到只差一个数的宫。 / 缺几，就填几。
- 提问：这个宫里已经有哪几个数？ → 还缺哪一个？
- 预期：D3 = 2、C1 = 2
- 留意：这只是热身：宫里 1～4 要齐。下一页才开始新方法。

**第 5 页 · 探索 · 一条线挡住**：左上宫缺 4，4 放哪里？ ／ 哪一格已经有数？ / 哪几格的行或列里 / 已经有 4？
- 提问：4 能放在左上宫的哪几格？ → 已经有数的格行不行？ → 这一格的行（列）里已经有 4 了吗？
- 预期：A1 = 4。另一格空着却不能放，是因为同一行（列）已经有 4。
- 留意：学生会说“因为只剩这一格”，可明明还有别的空格；要追问是哪个 4 挡住了它。

**第 6 页 · 探索 · 两条线交叉**：哪一宫里，1 只剩一个位置？ ／ 每个 1 / 管住它的一行、一列。
- 提问：这个 1 管住了哪一行？哪一列？（用手比画） → 还没有 1 的宫是哪个？那里还剩几格？
- 预期：C2 = 1。两个 1 的行和列交叉，把宫里另外三格都挡住了。
- 留意：用行列高亮工具把“管住”的行和列标出来，学生更容易看见。

**第 7 页 · 一起说**：一起说：怎么找到的？ ／ 选了哪个数字？ / 它管住了哪些格？ / 宫里还剩几格？
- 提问：我们先看的是哪个数字？ → 它挡住了宫里哪几格？ → 最后剩下哪一格？
- 预期：先选数字，再用这个数字的行、列划掉宫里的格，只剩一格就填。
- 留意：先让学生说，老师再用高亮复盘；结论在下一页才出现。

**第 8 页 · 方法卡 · 宫内排除**：宫内排除：① 选一个数字 / ② 看它管住的行和列 / ③ 宫里只剩一格，就填它

**第 9 页 · 练一练 1**：哪个格能确定？是几？ ／ 先选数字，再看宫。 / 说出是谁 / 挡住了别的格。

**第 12 页 · 一个数字找到底**：把能确定的 1 都找出来 ／ 找到一个 1， / 马上找下一个 1。

## 题目设计口径

方法页按样式设计，再用求解器证明：

| 样式 | 含义 |
| --- | --- |
| E0 | 宫里只差一格（只作热身） |
| E1 | 一条线挡住几格，其余格已有数 |
| E2 | 只靠几条线交叉（四宫两条、六宫三条、九宫四条） |
| E4 | 线和已有数混合 |
| E5 | 一个数字找到底：后面的位置要等前面填好才出现 |
| E6 | 1～n 轮流找：宫内排除能填几格，然后停住 |
| L1 / L2 | 一行（列）还剩 2 格 / 3 格以上，用列或宫挡住 |
| L3 | 真实解题中宫内排除停住的盘面 |
| 唯一余数 | 排除依据分布在行、列、宫至少两处；四宫为点名格子的观察页 |
| K1–K4 | 宫内区块后宫内排除、宫内区块后行列排除、行列区块、区块后唯一余数 |
| 变形 | 区域页（虚线、窗口当成宫）、锯齿形状页、符号先缩小范围页、摩天楼三个窍门 |

- 方法页：页面问的格子在所有合法终盘中取值相同；单目标页全盘只有这一格（或这一对格）确定；用到的方法不超出本讲。
- 整题：唯一解；只用本讲方法即可解完；要求的方法撤掉就解不下去；变形规则撤掉就不再唯一，且至少有一次推理确实用到新规则。
- 难度：按提示数和“卡点”（全盘只有一个落点的步数）分档，同一讲由易到难排列。
- 全部推理逐步独立回放，详见“逐题校验结果.md”。
