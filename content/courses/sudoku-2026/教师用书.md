# 数独教学 · 2026版 · 教师用书

全年独立课程，初阶四宫（1–2 年级）、中阶六宫（3–4 年级）、高阶九宫（5–6 年级）；各 4 讲，每讲 90 分钟。年级是建议范围，入阶也看学生已有数独经验。

成品含 98 道稀疏单目标方法题、36 道课堂完整题、48 道课后完整题，原生组合课件共 239 页。课堂页以盘面、操作和短提问为主，教师说明集中在本手册。

## 使用

- 开发端课程入口见同目录“开发导入记录.json”；所有题目均为可编辑的原生数独组件。点击格子填数，可用行列宫高亮、候选、撤销和答案揭示；先留出探索时间再揭示。
- 方法页只需要找到一个确定数，其他空格可以留白；“完成目标”不等于填满盘面。教师演示空白页不判断通关。
- 摩天楼的四栋楼按楼高固定配色：1层蓝、2层红、3层绿、4层紫，同一栋积木同色。可旋转、平移，使用立体/正视/左视/右视/俯视、居中、轴向吸附、坐标轴和恢复起点；点左视、右视比较两端遮挡。抽象盘面四侧数字就是该方向看到的楼数。
- “课后练习.html”可按 A4 打印，每讲四题；“教师答案.md”含全部题目的逐步理由。“method-audit.json”保留机器方法证据。

## 90 分钟组织

探索页是问题池。不同班级可把交流集中到 2～3 个代表盘面，其余快速独立判断；保留 10～15 分钟完整题时间。以上为排课预算，实际速度与教学手感仍需课堂试用；学生未完成时保留推理记录，不用猜数赶进度。课后四题可分两次完成。

## 方法进度与审核口径

“宫内排除”=一个数字在一宫只剩一个位置；“行列排除”=一个数字在一行/列只剩一个位置；“唯一余数”=一个格只剩一个候选；“区块”=宫与行列的候选位置交集带来外部排除。

完整题优先顺序：同数字逐宫扫尽 → 换数 → 全部数字循环到无进展 → 优先检查空格少的行列 → 本课允许的余数/区块/附加规则 → 有进展就回到宫内。变形规则是合法候选的组成部分，始终生效。

第一讲各阶 7 道完整题全部宫内排除可解。M2、H2 的 7 道完整题每题至少两步行列排除，撤去行列方法会停滞。M3 每题必用区块。H3 每题必用唯一余数或区块，部分题两种分别必需。变形题移除新增规则后不再满足原目标。

四宫特别说明：枚举 12 个首行规范终盘的部分盘面，去重得到 721584 个代表盘面，其中 565820 个唯一解盘面均可只用宫内排除完成；数字重命名覆盖其他盘面。因此初阶第 2、3 讲改为四种变形，不把行列排除包装成四宫必用技巧。B1 的两个余数方法页用于等价观察，已在答案中明示。复核脚本 check-four.mjs，证据 four-exhaustive.json。

“必用”指按本课程明确定义的方法集合穷尽推理后必须引入该方法；不声称排除了所有可能的人工替代证明。单目标页逐一检查所有空格的所有可行数字，恰好一个格在全体解中固定；完整题独立精确求解确认唯一。

## 逐讲教案

### B1 初阶第 1 讲 · 一个数字找到底

目标：宫内排除＋唯一余数。

1. 从图形排队转到数字：一行四个符号都不同。用空白盘试放，比较行、列、宫。
2. 先展示 T1～T3，学生独立找“确定的一格”，老师追问为什么别的位置都不行。
3. 六个宫内排除盘面把注意力固定在一个数字；T7、T8 改问“这个格子还能放什么”，比较等价解释。
4. 只用宫内排除就能做完全部整题。四宫唯一余数作为观察视角，不安排伪造的“只能余数解”的完整题。

课堂完整题：B1-C1（标准数独）、B1-C2（标准数独）、B1-C3（标准数独）。

课后：B1-H1（标准数独）、B1-H2（标准数独）、B1-H3（标准数独）、B1-H4（标准数独）。每题圈出一次本课方法，写一句“因为……所以……”。

### B2 初阶第 2 讲 · 斜线与会转弯的宫

目标：对角线＋锯齿。

1. 先问：在原来的规则之外，虚线可能表示什么？试填一组有冲突的数验证猜想。
2. 对角线 T1、T2 后，换锯齿 T5、T6：学生沿粗线描出每宫，先数是否恰好四格。
3. 归纳“改变了哪条规则、哪些规则保留”；再做其余单目标题。
4. 四宫锯齿仍是四格一宫，不能沿原来的 2×2 小方块当作宫。对角线两条都生效。

课堂完整题：B2-C1（对角线数独）、B2-C2（锯齿数独）、B2-C3（对角线数独）。

课后：B2-H1（锯齿数独）、B2-H2（对角线数独）、B2-H3（锯齿数独）、B2-H4（对角线数独）。每题圈出一次本课方法，写一句“因为……所以……”。

### B3 初阶第 3 讲 · 符号会告诉我们什么

目标：不等号＋奇偶。

1. 出示不等号，学生用 1、2、3、4 排序，说明尖端与开口；只比较带符号的相邻两格。
2. 不等号 T1、T2 与奇偶 T5、T6 先探索后归纳；让学生自己写出奇数集合与偶数集合。
3. 让学生指出某格不能填什么，再回到宫内找位置，避免只盯新增符号。
4. 奇偶标记是限制范围，不一定直接给答案；空白格没有奇偶限制。

课堂完整题：B3-C1（不等号数独）、B3-C2（奇偶数独）、B3-C3（不等号数独）。

课后：B3-H1（奇偶数独）、B3-H2（不等号数独）、B3-H3（奇偶数独）、B3-H4（不等号数独）。每题圈出一次本课方法，写一句“因为……所以……”。

### B4 初阶第 4 讲 · 站在街边看高楼

目标：摩天楼。

1. 用两组可转动积木场景，先猜再从一端低视角观察。数看到的楼栋，不数积木块。
2. 学生搭 1、2、3、4 与 3、1、4、2，比较两侧分别看到 4/1 和 2/2 栋，再用数字替代模型。
3. 边数 1 意味最高楼在最前；边数 4 意味从近到远依次 1、2、3、4。边数 2 或 3 保留多种可能，比较哪些位置真的确定。
4. 单目标盘面刻意不使用直接确定一整行的边数 4。规则归纳时可用积木演示边数 4，完整题再综合使用四边线索；没有 2×2 宫规则。

课堂完整题：B4-C1（摩天楼）、B4-C2（摩天楼）、B4-C3（摩天楼）。

课后：B4-H1（摩天楼）、B4-H2（摩天楼）、B4-H3（摩天楼）、B4-H4（摩天楼）。每题圈出一次本课方法，写一句“因为……所以……”。

### M1 中阶第 1 讲 · 六宫里的数字侦探

目标：宫内排除。

1. 空白六宫回顾 1～6 和每宫 2 行×3 列。
2. 探索 T1～T3：选一个数字，在各宫间用同行、同列排除。
3. 记录扫描顺序，填完一个数先继续找同数；同数没进展再换下一个数。
4. 本讲所有课堂、课后整题只需宫内排除，不需候选数、行列排除或唯一余数。

课堂完整题：M1-C1（标准数独）、M1-C2（标准数独）、M1-C3（标准数独）。

课后：M1-H1（标准数独）、M1-H2（标准数独）、M1-H3（标准数独）、M1-H4（标准数独）。每题圈出一次本课方法，写一句“因为……所以……”。

### M2 中阶第 2 讲 · 宫里停住，看看行列

目标：行列排除为主，唯一余数为辅。

1. 先尽量做宫内排除，停住后让学生自己挑一条空格较少的行列。
2. 六道行列排除目标题承担主教学；最后两道唯一余数题比较“一个数的位置”与“一个格的数字”。
3. 归纳后让学生解释为什么整行只剩一个位置；每次填完回到宫内。
4. 全部完整题都至少有两步行列排除；禁用行列排除时，即便保留唯一余数也会停滞。

课堂完整题：M2-C1（标准数独）、M2-C2（标准数独）、M2-C3（标准数独）。

课后：M2-H1（标准数独）、M2-H2（标准数独）、M2-H3（标准数独）、M2-H4（标准数独）。每题圈出一次本课方法，写一句“因为……所以……”。

### M3 中阶第 3 讲 · 两格未定，也能排除

目标：区块。

1. 给出不能直接确定值的候选范围，让学生先说明“这个数字只在这几格中”。
2. 同在一个宫又同在一条线，讨论这条线其他地方还能不能放这个数。
3. 既体验宫指向行列，也体验行列指向宫；先完整列出候选范围，再划掉外部候选。
4. 所有完整题必需区块；盘面可能需要两次以上候选排除才产生一个确定值，不承诺每次排除立即填数。

课堂完整题：M3-C1（标准数独）、M3-C2（标准数独）、M3-C3（标准数独）。

课后：M3-H1（标准数独）、M3-H2（标准数独）、M3-H3（标准数独）、M3-H4（标准数独）。每题圈出一次本课方法，写一句“因为……所以……”。

### M4 中阶第 4 讲 · 给六宫加一条规则

目标：对角线＋锯齿＋不等号。

1. 按对角线、锯齿、不等号三个小组依次探索，各先两道方法页，规则只增加一类。
2. 学生先提出规则，教师用一个冲突例确认；每组第三道留给独立尝试。
3. 三个课堂完整题各体验一种变形；课后仍只使用已学基本方法与本题规则。
4. 附加规则确实参与推理：去掉规则，整题会多解。

课堂完整题：M4-C1（对角线数独）、M4-C2（锯齿数独）、M4-C3（不等号数独）。

课后：M4-H1（对角线数独）、M4-H2（锯齿数独）、M4-H3（不等号数独）、M4-H4（对角线数独）。每题圈出一次本课方法，写一句“因为……所以……”。

### H1 高阶第 1 讲 · 九宫也能有序寻找

目标：宫内排除。

1. 九宫不是新方法，先把 1～9 同数字扫描练得有序。
2. 用提示很少的 T1～T3 培养确定性论证，盘面多解不影响目标唯一。
3. 学生轮流说“哪个宫、哪个数、排除哪些行列”，不急着列满候选。
4. 所有课堂、课后完整题仅用宫内排除即可完成。

课堂完整题：H1-C1（标准数独）、H1-C2（标准数独）、H1-C3（标准数独）。

课后：H1-H1（标准数独）、H1-H2（标准数独）、H1-H3（标准数独）、H1-H4（标准数独）。每题圈出一次本课方法，写一句“因为……所以……”。

### H2 高阶第 2 讲 · 从空格少的行列突破

目标：行列排除。

1. 先穷尽宫内排除，再比较各行各列空格数量。
2. 八个目标盘面只在使用行列排除后才能确定一格。
3. 每次突破后重新做宫内排除，避免学了新方法就跳过旧方法。
4. 所有完整题至少两步行列排除，允许方法只含宫内与行列排除，不提前要求唯一余数或区块。

课堂完整题：H2-C1（标准数独）、H2-C2（标准数独）、H2-C3（标准数独）。

课后：H2-H1（标准数独）、H2-H2（标准数独）、H2-H3（标准数独）、H2-H4（标准数独）。每题圈出一次本课方法，写一句“因为……所以……”。

### H3 高阶第 3 讲 · 一个格子与一组位置

目标：唯一余数＋区块。

1. 先让学生找一个格的剩余候选，再讨论一组候选位置带来的外部限制。
2. 前四个目标盘面练唯一余数，后四个练区块；区块先说完整范围再排除。
3. 完整题混合“余数必用”“区块必用”“两者分别必用”，不强求每道都必须同时出现两种。
4. 每道完整题至少需要唯一余数或区块；分别撤去必需方法后验证会停滞。

课堂完整题：H3-C1（标准数独）、H3-C2（标准数独）、H3-C3（标准数独）。

课后：H3-H1（标准数独）、H3-H2（标准数独）、H3-H3（标准数独）、H3-H4（标准数独）。每题圈出一次本课方法，写一句“因为……所以……”。

### H4 高阶第 4 讲 · 九宫规则实验室

目标：对角线＋锯齿＋不等号。

1. 保留九宫已学方法，比较对角线、锯齿、不等号三种常见变形。
2. 各两道方法页先探索规则；归纳后每类一题独立练习。
3. 三个完整题各覆盖一类规则；让学生圈出一个“只有新增规则才带来的突破”。
4. 不追求竞赛高难技巧；规则可以改变，但每步仍须说明确定性依据。

课堂完整题：H4-C1（对角线数独）、H4-C2（锯齿数独）、H4-C3（不等号数独）。

课后：H4-H1（对角线数独）、H4-H2（锯齿数独）、H4-H3（不等号数独）、H4-H4（对角线数独）。每题圈出一次本课方法，写一句“因为……所以……”。
