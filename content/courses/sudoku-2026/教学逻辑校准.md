# 数独教学 2026版 · 教学逻辑校准

2026-10-13。依据：Codex 对话“设计数独课课程体系”、`bank.json` 182 题逐题量化、生成与组页脚本、开发端实际页面截图。

## 一、“搭了壳”的来源

一句话：需求里能被机器判定的部分（唯一解、只有一个确定格、方法不超纲、必用方法撤掉会卡住）都做成了硬约束，并反复审核；不能被机器判定的部分（每页练哪个子技能、页与页怎么递进、整题难度配不配时间、规则怎么让学生发现、页面怎么呈现）没有写成规格，就由随机生成和统一模板填上了。所以 182/182 题都通过，整体看却不像一节课。

审核也只覆盖这一层：`curriculum-check.mjs` 用的是生成器同一套 `logicalSolve` 和方法定义，它证明的是“合法、不超纲”，不是“教得好”。

### 1. 方法页是随机盘面，很多页根本没在练这一讲的方法

56 张标准方法页按盘面样式归类：

| 讲次·方法 | 实际样式 | 问题 |
| --- | --- | --- |
| B1 宫内排除 6 页 | 4 页“宫里已有 3 个数，补最后一格”；2 页“给 3 个相同数字找第 4 个” | 没有一页是真正“用行列线排除宫内格”的混合样式；B1-T4 的提示写“用同行、同列的数排除”，盘面上却没有可用来排除的数 |
| B1 唯一余数 2 页 | 都是“宫里补最后一格” | 和 T2～T5 是同一种盘面，起不到对比作用 |
| M1 / H1 宫内排除 16 页 | 混合排除只有 7 页；M1-T5、T8 是“5 个相同数字找第 6 个”，H1-T4、T5 是“8 个相同数字找第 9 个” | 样式分布靠随机，没有从易到难的阶梯 |
| M2 / H2 行列排除 14 页 | 8 页是“这一行（列）只差一格” | 这其实是规则热身，算不上行列排除；真正的行列排除只有 6 页 |
| M3 / H3 区块 12 页 | 12 页全是“行列区块”（行列指向宫），没有一页“宫内区块”；M3 有 6 页最后要靠唯一余数落子 | 最基础的宫内区块缺席；唯一余数在 M2 只是少量带过，到 M3 却成了主要收尾方法 |

区块偏向的原因：`lockedMoves` 按“行→列→宫”的顺序遍历，`logicalSolve` 只取第一个结果，于是总是先找到行列区块。

### 2. 核心策略“一个数字找到底”没有页面承载

你的方法主线是“同一个数字逐宫扫完 → 换数字 → 都停住了再看行列和格子”。可单目标页按定义全盘只有一个确定格，演示不出连锁；直接跳到整题时，这条主线只存在于答案册的步骤里。从“找一个格”到“解一整盘”之间没有过渡页，比如“找出所有能确定的 3”或“宫里停住了怎么办”。

### 3. 整题难度和时长没有校准

| 现象 | 数据 |
| --- | --- |
| 四宫整题全在最难一档 | B1 七道整题只有 4～5 个提示，而四宫最少就是 4 个提示；旧课件“由密到疏”的递进被删掉了 |
| 九宫课堂整题时间配不上 | H1 整题 24～27 个提示、54～57 步，课堂只给 13/13/10 分钟，相当于每分钟要填 4～5.5 个数 |
| 同一讲的 C1→C3 不是由易到难 | 例如 H1 三道题的卡点数是 10 / 4 / 8（卡点：这一步全盘只有一个能落子的位置） |
| 变形“玩一玩”实际上很难 | H4-C1 要做 11 次区块；H4-C3 有 82 步，其中区块 11 次、不等号 10 次；H4-H3 有 89 步 |
| 初阶变形卡点过多 | B4-H4 有 81% 的步骤是卡点，B3-H4 是 53% |

12 讲用的是同一张 90 分钟时间表，四宫、六宫、九宫都按“整题 13 分钟”排。

### 4. 变形课只告诉规则，学生没有自己发现规则

- 变形探索页右侧直接写着规则全文。教师用书写的是“先问虚线可能表示什么、试填冲突”，但课件里没有对应的页面。
- B2 对角线 4 张探索页全靠唯一余数解，而 B1 只把唯一余数当作“观察视角”。
- 对角线在 B2 每道整题里都有 3 步起决定作用（M4 有 7～10 步，H4 有 11～15 步），答案册却都写成【宫内排除】，规则在哪一步起作用学生看不到。
- 摩天楼的求解步骤是“列举合法排列共 N 种”，这是机器的证明，不是 1～2 年级学生能用的推理。同时初阶禁用了行列方法，而摩天楼没有宫，行列恰恰是它唯一的区域。
- M4、H4 用的对角线、锯齿、不等号就是 B2、B3 的子集。原生引擎只有 5 种变形，课程内容被引擎能力卡住了。

### 5. 排版：239 页只有 3 种模板

- 题目页都是“标题 + 左侧盘面 + 右侧 3 栏窄文字”，下方大片留白。
- 生成脚本用 `\n` 分好的行，在画布上被合并成一段（截图可见）。
- 模板占位符直接漏到页面上：热身页和锯齿规则写的是“1～N”。
- 学生页标题带内部编号，如“探索 B1-T1”“完整挑战 H1-C2”。
- 教师话术出现在学生页上，如“先让学生说；再用突出行、列、宫的工具整理依据”“完整填满不是此页任务”。
- 归纳页一翻开就是全部结论，没有先让学生说的空间。
- 教师用书每讲只有 4 条要点；作业要求统一写“因为……所以……”，1～2 年级也一样。

## 二、校准后的教学逻辑

### 1. 验收分三层

| 层 | 内容 | 现状 |
| --- | --- | --- |
| L1 数学 | 唯一解或单一确定格、原生引擎复核 | 已有，保留 |
| L2 进度 | 只用已学方法；必用方法撤掉就卡住 | 已有，保留，补上区块类型覆盖 |
| L3 教学设计 | 每页带“样式标签”，按阶梯排序；整题难度单调递增并落在本级时长带内；变形规则决定步可见；学生页没有模板泄漏 | 新增，能机器检查的部分写进 `curriculum-check` |

### 2. 每讲骨架：把“探索 → 归纳 → 练习”落到页面

| 环节 | 页面类型 | 要求 |
| --- | --- | --- |
| 引入 | 回顾页 / 规则发现页 | 变形课先给完整终盘或冲突盘，让学生说出规律，规则文字放到归纳页 |
| 探索 | 2～3 张设计过的发现页 | 从最显然的开始，每张只多一个新要素 |
| 归纳 | 演示页 + 结论页 | 演示页沿用探索页的盘面复盘；结论页分步出现 |
| 阶梯练习 | 4～6 张方法页 | 严格按下面的样式阶梯排序 |
| 策略 | 连锁页 / 中盘停滞页 | 连锁页：“找出所有能确定的 X”（现有 `teaching-target` 最多支持 12 个目标，不用改引擎）；中盘页取自整题里真实的卡住局面 |
| 整题 | 按时长配题 | 由易到难，见第 4 节 |
| 小结与作业 | 小结页 + 作业 | 作业形式按年级区分 |

### 3. 方法页样式阶梯

**宫内排除**

- E0 宫里只差一格：只作规则热身，不计入方法页
- E1 一条线 + 宫内已有数占位
- E2 两条线交叉
- E3 三条及以上线（六宫、九宫）
- E4 线 + 占位混合（主力样式）
- E5 连锁：填一个之后，同一数字在下一宫也能确定（多目标页）
- E6 换数：一个数字做尽后，换下一个数字才有进展
- “N−1 个相同数字找最后一个”最多用 1 页，作入门

**行列排除**

- L0 这一行（列）只差一格：热身，不计入
- L1 行或列剩 2 格，靠 1 条交叉线排除
- L2 剩 3 格以上，用列和宫组合排除
- L3 中盘停滞页：宫内排除已经做尽，只有行列能突破

**唯一余数**

- 排除依据分散在行、列、宫三处，任何一个区域都不能已有 N−1 个数
- 四宫改成“指定格”页，提示直接点名格子，例如“C2 能填几？”，并允许与宫内排除等价。实测在 4 万个随机四宫盘面里，找不到既满足“全盘只有一个确定格、宫内排除没有进展”又是真唯一余数的页面，所以四宫只能用这种做法。

**区块**

- K1 宫内区块 → 另一宫的宫内排除（最先教）
- K2 宫内区块 → 行列排除
- K3 行列区块 → 宫内排除
- K4 区块 → 唯一余数（只在 H3）
- 生成器按指定的区块类型出题，不再沿用遍历顺序带来的偏向

### 4. 整题：按时长配难度

10～15 分钟一题是既定时长，由题目来适应时间。难度用四个指标：提示数、步数、卡点数、所需方法次数。同一讲 C1 < C2 < C3；课后题和课堂题同档，最后一题可以略难。以下是初值，第一次试课时实测完成时间后再调：

| 阶 | 初值 |
| --- | --- |
| 初阶四宫 | 一个 10～15 分钟时段放 2～3 道小题，由密到疏（7～8 → 5～6 → 4～5 个提示） |
| 中阶六宫 | M1-C1 提示 ≥14、卡点 ≤1，后续题逐步减少提示 |
| 高阶九宫 | H1-C1 提示 ≥34、卡点 ≤2，C3 不低于 28 个提示；课堂整题 2 道，另备 1 道机动 |
| 变形“玩一玩” | 新规则决定步 ≥2；不需要区块；以宫内排除为主 |

### 5. 变形课

- 规则先发现，后归纳，见第 2 节。
- 求解轨迹标出“由哪条规则排除”，对角线、锯齿起决定作用的步骤要在答案册里写明。
- 摩天楼把学生能用的规则命名，求解器只用这些规则，能这样解完的题才进题库：
  - S1 边数 1：4 层楼紧挨这一边
  - S2 边数 4：从这一边起依次是 1、2、3、4
  - S3 边数 2 或 3：4 层楼不在离这一边最近的（边数 − 1）格里；第一格最多（5 − 边数）层
  - S4 每行每列 1～4 补齐（摩天楼没有宫，行列就是它的区域）
  - 不再使用“列举全部排列”
- 初阶变形方法页的推理控制在 2 步以内（B3 现在是 3～4 步）。

### 6. 页面与排版

- 学生页不出现题号；题号留在页目录和教案里。
- 教师话术移到教案。
- “1～N”按盘面换成 1～4、1～6、1～9。
- 修复换行显示。
- 提示语跟着样式走，每页不超过 3 行短句，字号不小于 28。
- 盘面放大，重新分配右侧窄栏和下方留白。
- 增加页面类型：规则发现页、演示页、连锁页、中盘页、对比页（同一格的两种解释并排）。

### 7. 教师用书

- 每阶一张时间表。
- 每张探索页写清：提问链、预期回答、常见错误、追问。
- 初阶作业改成口头说理和圈画。
- 答案册正文给每题 3～5 个关键突破，机器逐步记录放到附录。

## 三、逐讲校准

| 讲 | 现状问题 | 校准 |
| --- | --- | --- |
| B1 | 宫内排除页 4/6 是补最后一格；唯一余数是假的 | E1→E2→E5（连锁“找出所有 3”）；唯一余数改指定格页；整题由密到疏 |
| B2 | 规则直接给出；对角线探索页全靠唯一余数；答案册不标对角线 | 终盘发现规则；以宫内排除为主，加对角线排除；答案册标出决定步 |
| B3 | 方法页 3～4 步；整题卡点 33%～53% | 推理 ≤2 步；“排序游戏”引出不等号；整题降低卡点 |
| B4 | 靠排列枚举；B4-H4 81% 卡点 | 用 S1～S4；整题按难度梯度重做 |
| M1 | 3/8 页是真混合排除，其余是同数字或补格 | 按 E1～E6 阶梯，加连锁页和换数页 |
| M2 | 4/6 行列页是只差一格 | L1→L3，加中盘停滞页；唯一余数 2 页保留 |
| M3 | 8/8 行列区块，6/8 靠唯一余数收尾 | K1→K3，收尾用宫内排除或行列排除 |
| M4 | 整题要区块；规则直接给出 | 不需要区块；先发现规则 |
| H1 | 有“8 个相同数字”页；整题 24～27 个提示，配 13 分钟 | 按阶梯重做；整题提示 ≥34 起步 |
| H2 | 4/8 行列页是只差一格 | 同 M2 |
| H3 | 区块 4/4 是行列区块 | K1～K4 全覆盖；唯一余数页保留 |
| H4 | 整题区块 10 次以上；变形与初阶重复 | 不需要区块；变形范围待你确认 |

## 四、待确认

1. **H4 的变形范围。** 建议 M4 沿用对角线、锯齿、不等号（3～4 年级大多是新生）；H4 新增 1～2 种。窗口、额外区域和对角线一样是“多一组不重复区域”，实现成本最低；杀手数独需要另做笼子和求和规则。
2. **初阶整题时段。** 建议一个时段放 2～3 道小题，由密到疏。
3. **摩天楼放开行列补齐与行列排除。** 建议放开，因为摩天楼里行列就是它唯一的区域。

## 五、落地顺序

1. 生成器改为按样式规格出题：修正区块偏向，加入连锁页和中盘页、难度带、摩天楼规则、规则决定步标注。
2. 校验加入 L3 检查。
3. 重建页面模板，修复换行显示。
4. 在现有开发课程上原位更新。现在的导入脚本会拒绝重复导入，需要先补一条更新路径。
5. 先做 B1、M1、H1 三讲样板给你试看，再铺开到 12 讲。
