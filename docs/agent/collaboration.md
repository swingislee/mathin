# 协作与交接

开始时看工作树和 `main` 的 [.ai/registry.json](../../.ai/registry.json)，识别正在进行的任务及文件归属。登记服务于避免覆盖他人工作，不决定产品方向和开发优先级。

单个任务由当前负责人直接推进。用户安排并行或需要隔离相互冲突的修改时，使用独立 worktree 与 `codex/` 分支；已有合适工作区可继续复用。任务登记写清分支、负责路径和当前交付点。

`node scripts/agent-context.mjs` 只读显示登记、当前分支与文件归属，可以从当前目录查看其他任务。路径登记使用精确文件名或以 `/` 结尾的目录前缀；`[locale]` 按字面路径处理，通配符先展开为实际范围。

共享文件变化按明确范围协调，集成时保留各任务修改。主目录已有修改与未跟踪文件属于用户或其他任务，保持原状。完成一个可独立使用的增量后单独提交，再按实际内容集成。

交接只写继续工作所需内容：目标、已改范围、提交、可用入口、实际检查、待人工确认与剩余问题。无需为了普通增量建立多轮互审、全量测试和重复证据。独立审查由明确需求或重大风险决定。

[任务卡](../../.ai/tasks/TEMPLATE.md) 与 [交接模板](../../.ai/handoffs/TEMPLATE.md) 可以按需使用。已结束记录集中归档；当前登记保留活跃任务以及本轮必要交付记录。
