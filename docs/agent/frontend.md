# 前端施工

先按 [产品方向](../product-direction.md) 理解当前工作，再读 [设计](../design.md) 与相关目录入口。

Next.js App Router、React、Tailwind 和 next-intl 是网站现有栈。新增界面同步 zh/en 的语义；颜色、字体、边框和间距沿用现有 token，具体表达按当前活动选择。

复用的目标是保持同一对象与操作的连续性。Dashboard 外层、表格展开、统一课件工作台、教具场景和空间动作都有共用入口。修改共享实现时辨认相关使用场景，保留其各自领域语义。

客户端和共享代码使用 `newId()` 支持局域网 HTTP。异步读取与保存保护当前对象、草稿和关注位置；移动端主要动作可直接触摸。用户明确要求验证设备时再调用 [验证技能](../../.agents/skills/verify/SKILL.md)。

普通界面增量实现后交付开发入口，由产品负责人使用确认。需要交付构建时生成构建结果；测试适用条件见 [操作规则](operations.md)。
