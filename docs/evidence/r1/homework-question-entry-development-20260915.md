# 纸质作业逐题登记 · 2026-09-15

状态：开发端已交付，待人工视觉与业务验收。生产未迁移、写入或部署；本增量不改变 R1-Live Gate。

## 已交付范围

- 课后作业区、原作业教师页和教学记录详情提供逐题入口：`/zh/dashboard/teaching/assignments/{assignmentId}`。
- 老师每行添加一道题，题目按稳定 ID 关联作业；按学生或按题登记，使用现有六档课堂学情及原 SVG、颜色、背景、数字快捷键。
- 支持备注、批量填充未检查项、撤销上次登记。保存成功后更新对应单元格，失败保留输入；版本冲突要求重新读取后核对。
- 学生×题目矩阵展示六档状态及已检查数。主管查看同一矩阵，任课教师按权限编辑；纸质登记独立于学生登录账号、在线提交和系统下课动作。
- 教学课次详情按需读取作业记录，首屏班级列表保持摘要。保存仅返回本次变更；已存在的教学详情短时缓存继续使用。

既有在线整份作业提交与批改继续使用。学生在线逐题作答界面尚未实现，后续可关联本次稳定的作业题目 ID；学生答案与教师观察分别保留。当前只支持追加题目，题目改名、排序和移除不在本次入口内。

生产只读复现页仍展示两位老师的原始课堂记录。其快照没有作业逐题数据，页面明确展示采集缺失；本地演示使用独立的虚构班级、5 名样例学生、4 道题与固定开发账号。
