# R1-1 · 机构配置、规则与 Feature Flag

## 结论

R1-1 于 2026-07-28 关闭。机构、校区、教室、节假日、校区学期、规则版本和 Feature Flag 已形成显式 schema/RPC/RLS 合同；规则与开关保存版本、生效时间、操作者、原因和被替代值。财务、外部通知和公共发布能力默认关闭，未知、缺失、尚未生效或读取失败均 fail-closed；Notebook 公共发布同时受数据库 RLS、Server Action 和 zh/en 禁用态约束。zh/en 管理页面和四个配置面板已在开发环境通过浏览器检查，当前阶段推进到 R1-2。
