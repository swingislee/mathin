# 学服新增线索归属与有效沟通补漏

状态：**开发端已交付，待人工验收**，2026-09-08。本批按产品负责人指出的八、九月人员零值问题，核对原始来源并统一修正统计；执行范围为已完成目标核验的本机开发库。

## 原因与修正

- 新增线索原先只使用当前 Lead 负责人，原表人员署名在精简读取时被省略，导致历史线索落入其他人员或未归属。现按原表确认人员、跟进人、沟通人员依次归属，缺少来源署名时沿用现有负责人。保留原获客时间与机构新增总数。
- 部分有效沟通有结果及 `8.21`、`9.5` 等月日值，确认月份留空。现由原表月份、完整日期或合法月日补足统计月份，实际日期保持原有精度。明确失败结果继续使用原义。
- 到访表中已确认的邀约也包含有效沟通依据。现将该依据保存在原登记的来源标签，补入对应学服沟通统计。同一已关联学员或 Lead、同一人员、同一统计月已有有效沟通时沿用沟通记录；周报按机构时区的实际日去重。独立沟通记录及独立来源行分别保留。
- 总览卡片、人员表格和明细共用上述事实；必要资料读取失败时显示不可用。后续来源导入自动生成同样的标签。
- 两位被核对学服的八、九月新增线索仍为零：可确认来源的获客时间属于更早月份；本期确认记录进入有效沟通统计。
