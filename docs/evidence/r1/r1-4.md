# R1-4 · Work-items 混合模型与轻审批

## 结论

R1-4 于 2026-07-28 关闭。原有 11 类领域投影和 `work_item_user_state` 保持不变；新增持久人工/跨域/委派/SLA work item、追加式分派审计、独立审批请求和不可变决定。统一列表现在返回来源、动作、负责人、截止、优先级、读取状态和 `can_act`，逾期每次由 `due_at` 计算。领域投影仍只能通过领域 RPC 改变业务完成态。权限、RLS、幂等、通知去重、双语浏览器旅程与 PERF-04 均通过，当前阶段推进到 R1-5。
