## 人工验收

进入 `/zh/dashboard/renewals?cycle=c98548d1-b55d-49a1-a613-e9b6f197b8ae`，使用本地固定校长账号。

1. 顶部保留“续班池 / 续报健康度 / 周期设置 / 召回与转介绍”及搜索。池中不显示周期和健康度列；学生、班级、负责人、结果使用统一表头筛选。
2. 01—08号样例在同一张表中，主行单行紧凑。点02号快捷结果或登记输入框，在当前学生下展开详情；反复切换学生及结果，确认列宽稳定，备注草稿保留。输入后用 Ctrl/Cmd+Enter 保存并继续下一位，刷新后仍可见结果。
3. 点05号“已支付”，填写报读期数、实际缴费与记录。保存后同行显示期数与金额；再次进入详情修改并刷新，数据保留。重复保存保持同一报名记录。期数是本次报读的登记数量，不自动生成多个学期报名。
4. 06号原先只有报名事实，显示“已报名 / 待补缴费信息”；实际缴费登记完成后才显示“已支付”。
5. 点学生名，右侧打开既有 Student 360；页内左上边缘的小纸签使用收起 SVG，点击后恢复完整池宽度。桌面和移动端使用同一收起入口。
6. 教师观察从学生同行录入。固定教师只能为其任教范围提交，数据库继续执行原教师权限合同。原建议处理页保留兼容入口。
7. 切到“续报健康度”标签，在学生行展开依据，查看每项计数、观察窗口和阈值。无任务、缺测和需关注分别展示。周期说明、名单刷新和维护位于“周期设置”。
8. 在结果按钮上按 1–5 切换；登记输入框内按 Alt+1–5 切换，直接输入数字可正常写入。按 Esc 收起当前登记区。检查主按钮随沟通、待缴、已缴、不续、关注显示对应动作。

## 健康度覆盖

从既有学生的班级成员关系开始读取开课事实，最近28天作观察窗口，前28天作趋势对照；不依赖某次续报操作才开始生成教学记录。当前按需读取，无额外采集定时器和续报概率评分。

| 维度 | 当前依据 | 覆盖限制 |
| --- | --- | --- |
| 沟通 | 学生跟进中的电话/到访记录 | 微信等未结构化沟通需补充；提示登记频率，不推定全部真实沟通量 |
| 考勤 | 已开课课次中登记的请假/缺席 | 未登记考勤为缺测 |
| 课堂参与/挑战度 | 学习检查的观察覆盖、独立完成和讲解状态 | 是代理指标，逐题答题次数和准确率尚未接入 |
| 作业提交/掌握 | 已到期任务、学习账号提交及0—100评分 | 未绑定学习账号为数据待补齐，逐题错题数尚未接入 |
| 视频 | 已发布、有截止时间且到期的任务与学生视频 | 无任务不评价家长积极性 |
| 趋势 | 前后28天各至少3份已评分作业的平均分 | 难度与评分标准变化需人工复核 |

原种子主要展示续班状态，缺少完整教学记录，因此健康度出现“数据待补齐”符合当前事实。阈值在周期设置中说明，当前未提供阈值编辑器。
