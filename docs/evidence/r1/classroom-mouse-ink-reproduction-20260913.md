# 2026-09-13 鼠标书写粗细起伏复刻

状态：合成轨迹复算、矢量对照及交互回放检查完成。基线应用为 `0c6792a3`，应用源码与参数保持原样，阶段保持 R1-Live-2。本记录不代表真实设备输入到显示延迟测量，也不替代用户书写验收。

## 用户反馈与已知现场

用户确认用鼠标在开发端试讲副板书书写，标出两条竖线的粗细不均与边缘起伏。此前已通过 Codex 内置浏览器读取页面：副板书 `inputMode=ink-lock`、`renderProfile=classroom`、effective DPR=1.5，设备 DPR=2。当前浏览器检查接口提供的 DOM 读取不包含 React store 或 Canvas 像素接口，因此尚未取得这两笔的原始坐标与时间序列。

本次按用户要求模拟书写，以缓慢减速、小幅左右微摆、不同采样间隔和坐标取整构造输入。生成的是同类形态的合成复刻，没有把截图反推的假设当作现场采样事实。

## 复算方法

- 使用仓库真实 `pointerInkMetadata`、`BoardInputSink`、`appendStrokeInput`、`previewStroke`、`classroomPressureOutline`，以及已安装的 perfect-freehand 1.2.3。
- 每点保留鼠标时间戳，输入 pressure=0.5；应用入口按真实规则将其置为 null，最终进入模拟压力支路。默认 0.75 px 距离筛选、60 Hz RAF 调度，保留预览尾点。
- 采用约 758 CSS px 的主板书线宽基准与默认中号 0.006，得到 size=4.548 CSS px。字号是实验设定，不声称已读到用户所选字号。坐标归一化按 345×864 逻辑画布计算。
- 六种输入：匀速均匀采样；相同匀速、4/16 ms 采样间隔按约 100 ms 区段交替；匀速坐标取整；平滑减速；匀速向下并左右微摆；减速、微摆、间隔变化与取整组合。
- 前三种笔直轨迹均为 250 CSS px／1.5 s；组合轨迹约 250 CSS px／1.8 s。间隔分布和运动函数用于隔离机制，尚未验证为现场设备分布。
- 对照每次只改变 thinning=0.5、streamline=0.5、smoothing=0.9、二次曲线连接，或使用基于时间的实验压力。另设 thinning=0 作为几何对照，未作为产品方案。
- 笔宽在 y=68.25～228.25 的笔画内部按 1 CSS px 横截面测量，避开端帽。弯曲笔画的水平截面受方向影响，其宽度区间不能直接全部解释为压力噪声。

## 主要发现

### 1. 匀速也会因采样间隔不同产生笔宽波动

同一条完全笔直、设定速度恒定的合成轨迹，均匀采样产生较稳定宽度；改成间隔交替，出现周期性鼓包与收窄。数据经过实际输入筛选后，229 个原始点保留 139 点，时间戳仍在。

| 相同匀速、间隔交替的输入 | 内段最小～最大笔宽（CSS px） |
| --- | ---: |
| 当前参数 | 4.3894～5.2731 |
| 仅 thinning 0.7 → 0.5 | 4.4347～5.0659 |
| 仅 streamline 0.1 → 0.5 | 4.4769～5.2346 |
| 仅 smoothing 0.6 → 0.9 | 4.3894～5.2731 |
| 仅二次曲线连接轮廓 | 4.4286～5.2174 |
| 按时间估算并平滑压力，再交给 PF | 5.8649～5.8650 |

均匀 8 ms 采样的当前配置内段为 5.7375～5.8650 px，仍有初始压力收敛的尾部影响。间隔交替不仅改变局部波动，也改变了平均笔宽。

PF 的当前模拟压力根据相邻处理点的距离与笔刷 size 推算，而非直接计算距离÷时间。`thinning=0.7` 是变化幅度的放大因素；仅将其降至 0.5 可以缓和，但没有消除这类采样依赖。提高 smoothing 也不能替代压力处理。

### 2. 同一点列的书写时间拉长三倍，当前最终轮廓完全相同

将筛选后点列的所有时间戳乘以 3，坐标保持一致，当前 `classroomPressureOutline` 的输出逐值相同。实验时间压力版本会随时间尺度改变。这项对照直接证明当前鼠标分支尚未利用已保存的时间信息。

### 3. 减速本身可以产生自然粗细；局部鼓包需要分开处理

平滑减速且没有横向微摆的当前轨迹呈现连续的细到粗变化，内段宽度约 2.9180～6.3171 px。这是速度笔锋的预期方向，不能把全部宽度变化当作缺陷。

组合轨迹复刻出细段、粗段与局部结节。单降 thinning 缩小粗细幅度，单增 streamline 减弱一部分轨迹摆动；二次曲线连接减轻折角，但较长尺度的粗细起伏仍在。仅处理压力时，真实输入曲线中的左右微摆仍被保留。后续应分别处理压力连续性、轨迹噪声和轮廓连接。

同类起伏直接存在于 PF 输出的矢量轮廓中，生成独立 SVG 也可观察到。该机制不依赖课堂 Canvas 的局部清除、网络或 DPR；这不能排除现场还叠加其他显示因素。

### 4. 保留原始点时，RAF 合批不改变最终笔迹

对同一批原始样本分别执行逐点投递、每批四点投递，以及 60/30 Hz RAF，最终保留点列逐值相同，因此当前最终轮廓也相同。这个对照没有证据把 RAF 合批本身认定为粗细起伏的原因。真实浏览器是否丢点、合并事件的可用性及输入到显示延迟不在此结论内。

## 时间压力对照的边界

实验计算距离÷时间得到速度，速度用 24 ms 时间常数平滑，再以 8 ms 参考间隔映射到 PF 压力目标，压力用 28 ms 时间常数平滑，目标限制在 0.05～0.95。然后设置 simulatePressure=false，由 PF 继续生成可变宽轮廓。

这些系数只用于验证因果关系，不是拟定的最终笔刷参数。初始压力暂设 0.5，可能造成较胖的起笔；短笔画、急停、停顿、横折钩与设备差异仍需处理。时间平滑会延缓粗细响应，虽未改变坐标或增加输入排队，也不能据此承诺真实低端设备的显示延迟不变。

建议下一增量先将已有时间戳用于连续的模拟压力，并按输入增量维护压力状态；保留最新落点及预览跟随。随后独立对照轮廓曲线连接和 thinning 强度，维持笔锋变化。新旧笔刷的预览、同步、保存与回放一致性应在实际实现时配套验证。
