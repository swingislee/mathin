# 2026-09-13 自然笔锋与跟随优化

状态：开发端可验收，待人工书写手感验收。生产未部署，阶段保持 R1-Live-2。

用户体验上一轮等宽笔迹后明确：引入 perfect-freehand 的目的是模拟自然粗细，让字迹美观；跟随优化应保留这项能力。本增量在 [3f0c3655 开发增量](classroom-ink-optimization-development-20260913.md) 上恢复自然笔锋。

## 实现

- 课堂新画笔生成 `brush: freehand-v1`，复用锁定的 perfect-freehand 1.2.3。保留 `thinning=0.7`、`smoothing=0.6` 和模拟压力，将 `streamline` 从历史配置 0.5 降到 0.1。
- 每次提供当前完整点列，使用 `last=true` 让此次轮廓末端落在最新采样点。预览和正式重放都使用同一配置，不根据抬笔状态切换几何算法。本次未加入额外的末端 taper。
- 活动画笔每帧清除草稿后重算整笔轮廓，消除尾段独立计算时的压力重置和旧轮廓叠加；已有笔画继续绘制在底层。新轮廓通过 Path2D 数值方法构造，减少字符串组装与解析。
- 本笔颜色继续缓存，主题改变时更新缓存，保留上一轮每个指针事件只读取一次边界的优化。起笔显色、连续提交补画和掌擦沿用上轮已验证的链路。
- 局部橡皮继续生成 `round-v1`，其作用范围与光标一致。历史无版本笔迹、已保存的 round-v1 和新 freehand-v1 分别按各自规则重放。
- 新版本加入 checkpoint 解析和同步 provider；现有进度传输、归档读取与撤销保持版本字段。坐标仍为归一化二维点，本次使用模拟压力，没有新增真实压力数据或数据库迁移。
