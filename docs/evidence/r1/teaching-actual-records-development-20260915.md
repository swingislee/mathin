# 教学实际记录入口 · 2026-09-15

状态：**开发端已交付，待人工视觉与交互验收**。本批没有生产发布，不改变 R1-Live Gate。

## 范围与入口

产品负责人本轮说明：当前有两位老师使用实际上课流程，另一位老师仅使用学情记录。该说明作为本次入口设计的使用背景，不据此补记生产验收或变更人员权限。

- `/zh/dashboard/teaching?view=records` 新增“上课学情与沟通”，主管默认进入该页；原“我的待办”和“团队完成情况”继续可用。
- 按机构时区的周／月、教师 ID 和班级 ID 筛选课次；课次和“查看实际记录”进入只读详情，返回保留老师、班级及日期范围。原完成情况表也提供实际记录入口。
- 详情展示本节花名册学生的考勤与备注、逐题学情、标记人及时间、当前已保存课评和分数。未在系统开课的课次可以直接读取学情；记录列表不显示备课逾期判断。
- 日常沟通没有课次外键，页面明确按本节花名册学生展示，可能涉及其他课次；显示完整正文、记录人及时间。学生／家长反馈展示老师实际保存的内容。课次联络任务备注独立展示，并将任务负责人和记录人概念区分。
- 沟通按录入时间倒序，提供 10／20 条分页，保留课次与筛选上下文。数据库每次读取 20 条，页面适配器在该块内选择对应的 10 条。

## 数据和权限

新增 `20260915003000_teaching_session_records`，增加只读 RPC `get_teaching_session_records(uuid, integer)`。已通过本机主机、Supabase origin、监听进程、Docker 网络和数据库指纹核对并应用。

- active staff 且有 `class.view.all` 的主管可读取团队记录；普通教师需有 `class.view.mine` 且实际负责该课次，代课替换主讲归属。匿名、学生和无关系教师拒绝访问。
- 只读取正式、未归档、未回收班级中的有效课次；冻结课次使用已冻结的花名册，其他课次使用现行课次花名册来源。
- 沟通正文另需 `followup.view`，逐生记录继续检查 `can_access_student`。查询没有扩大课评、考勤或课堂写入权限，也不返回联系方式字段。
- PostgreSQL 类型从本机生成，只合入新增函数定义；迁移摘要覆盖已跟踪迁移与本任务新增迁移。其他任务尚未跟踪的迁移与数据库类型差异不纳入本提交。
- 应用回退时可保留该兼容只读函数；若需要移除函数，单独处理本函数，不回退业务数据。
