## 统计与权限

- 学生人数在本期班级内去重；出勤和课评按学生课次计数。到课包含迟到，分母为已点名人次，尚未点名不会计为缺席。
- 学情分母为各课次题目数乘对应花名册人数之和。需关注来自本期至少一题的需提示、模仿完成或未完成标记，同班按学生去重。
- 已有记录依据实际考勤、学情标记或课评内容，与系统开课／下课状态分开统计，支持只使用学情记录的老师。
- 日常沟通按本期课次花名册合并学生、按沟通录入时间筛选，同班不重复计数；正文可能涉及其他课次。
- 新增只读 RPC `get_teaching_class_overview`，复用 `get_teaching_workbench` 的教师／主管课次授权和时间范围。沟通独立检查 `followup.view` 与逐生访问权限，不返回联系方式字段。
- 新迁移 `20260915004000_teaching_class_overview` 经本机主机、实际 Supabase origin、监听进程与数据库指纹核对后，仅应用于开发数据库。类型取自该实际数据库，仅合入新增函数定义；迁移摘要纳入已跟踪迁移与本次迁移。
- 应用回退可保留兼容的只读函数。本批没有业务数据迁移或写入权限变更。

## 原位详情与加载

- `records-detail` 独立 POST 读取先经过 `requireAnyPerm` 员工环境与教学权限闸门，再由既有实际记录 RPC 核对课次和学生范围。入参经 Zod 校验，响应使用 `private, no-store`；此次原位展开增量没有新增迁移。
- 详情代码动态加载，展开时才读取当前课次；收起或切换时取消请求并丢弃迟到响应，失败可在原处重试。沟通按 10／20 条局部分页，不触发整页导航。
- 缓存仅属于当前工作台实例，最多 8 页、30 秒有效，离开页面后释放；失败与取消结果不缓存。概览班级链接关闭自动预取，避免进入页面时同时读取各班工作区。
- 首屏 DTO 去掉备课资料、任务等本页未展示字段。固定开发主管当期样本 JSON 从 25,674 B 降到 19,101 B，减少约 26%；这是概览数据量，不是全页大小。汇总、排序和日期格式器复用，展开动作不重复聚合全部课次。
- 局域网 HTTP：开发端首次重新编译后的详情请求约 330 ms，其中服务端记录读取约 174 ms；其余已编译的 zh/en 列表约 400–496 ms。首个列表请求包含开发冷编译约 18.3 s，首个详情包含接口冷编译约 2.1 s；这些样本不代表生产性能承诺。
- 按 `bundle:report` 对比开发构建教学路由引用清单，gzip 合计 1,704,588 → 1,708,464 B（增加 3,876 B）。该清单包含共享壳与开发依赖，不是生产首屏包体积；完整详情模块通过动态导入按需使用。
