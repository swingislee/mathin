具体改动：

1. 关闭 `experimental.preloadEntriesOnStart`，首个请求按需加载路由。旧时间线显示全站课件、公开内容、学生详情等无关路由在首次请求期间加载；该开关及其取舍见 [Next.js 官方说明](https://nextjs.org/docs/app/guides/memory-usage#preloading-entries)，实现也核对了固定版本 16.2.11 的加载路径。
2. 管理员数据总览、今日工作、家长及学生首页分别按已通过身份检查的分支加载。
3. 将完整中英文客户端消息拆为按语言加载的静态消息块，保留 SSR、所有消息键及上下文；HTML/RSC 不再逐次携带整份消息对象。服务端翻译配置继续使用原始目录，语言切换和客户端弹层继续取得完整文案。嵌套 Provider 的配置继承规则参考 [next-intl 官方配置](https://next-intl.dev/docs/usage/configuration)。
4. 大屏统计与今日工作列表同时读取；当前学期的班级范围在学期查询完成后立即读取，与其他业务事实并行。
5. 同一次月统计只计算一次本期、上期月份，减少逐条历史事实的重复时区格式化。周／月、来源确认月份、去重、顺序和未知值口径保持一致。
