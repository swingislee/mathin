## 已验收合同

- `finance_release_gate_open()` 在 1.0 固定返回 false；`is_feature_enabled('finance.enabled')` 同时要求版本化开关和发布门。Feature Flag 写入触发器拒绝启用版本，设置页双语显示锁定原因并禁用创建/回滚按钮。
- `orders`、`order_items`、`payments`、`refunds`、`coupons`、`coupon_grants`、`scholarships`、`student_accounts`、`account_ledger` 增加 restrictive SELECT policy；管理员、员工、学生或家长的既有宽松分支均不能越过关闭门。
- finance domain 或指向财务路由的持久 work item/审批不能新建或继续更新；历史记录不删除，但统一列表和 summary 使用过滤后的读取结果。
- 财务领域事件仍保留审计；通知 staging 跳过该类事件，authenticated 的通知/投递 RLS 同时隐藏历史财务通知。
- job 写入触发器拒绝财务 payload；关闭动作取消 pending/retry/running 财务 job、终止 attempt 并释放 reserved effect，`claim_jobs` 在领取前再次执行抑制。
- 财务路由继续以开关 fail-closed；固定教师和管理员的 Dashboard 导航均不返回财务项。管理员浏览器未绕过 R1-3 的 MFA AAL2 门。
