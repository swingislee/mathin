# 2026-09-13 PF 跟随与压力开发增量

状态：开发端已交付，待人工书写手感验收。阶段保持 R1-Live-2，生产未部署。

当前范围按产品决定收敛到 perfect-freehand：优先降低低端机器连续书写的负担，同时补齐压力信息。自研仿 PPT 钢笔仅保留为未来候选，见[选型研究](classroom-ink-engine-landscape-20260913.md)。

## 本次实现

- 活动层以旧、新笔迹范围的并集清除并裁剪重画。与更新区域重叠的笔迹按原顺序恢复；未变化的远端轮廓复用 Path2D。收笔、取消、尺寸、DPR 和主题变化分别更新缓存，完成底图继续按提交追加。
- PF 仍接收当前整笔，保留压力与轨迹平滑的连续性。未采用独立截取尾段后重置 PF 状态，也未加入预测点。自然轮廓继续使用 `thinning=0.7`、`smoothing=0.6`、`streamline=0.1`、`last=true`。
- 直接输入在起笔缓存画布边界，滚动、resize 和 ResizeObserver 通知后重新读取；先过滤非当前指针，再提取合并样本。CSS 变换后的坐标按实际显示尺寸换算。坐标和压力均重复的静止样本不再安排绘制帧。
- 小于 0.75 CSS px 的末点在当前 RAF 更新本地临时预览，稳定采样继续用于保存和进度广播；收笔时补齐末点。压力变化达到 0.02 时也保留样本。
- 直接 Canvas、Smart 公共端口和 H5 桥保留样本时间与笔的接触压力。Smart 从起笔记录原始时间，即便先等待点击判定，后续转为书写也沿用同一时间起点。
- 新课堂笔迹使用 `freehand-v2`，通过 PF 自身的真实压力接口生成轮廓。仅有缺失压力或恒定默认 0.5 时回退到原模拟粗细；出现非默认的 pen 接触压力时使用记录值。此判断是浏览器数据回退策略，并未完成硬件压力能力或物理压力的校准。抬笔后的零压力不作为接触样本，沿用最后接触值。
- 新版本的孤立点以重复同一落点的方式交给 PF，统一起笔与同位置抬笔的点形，避免 PF 对单点自动补偏移轨迹造成点形跳变；历史笔刷保留原规则。
- `samples` 与二维 `points` 按索引对齐，存储相对起笔时间与压力；时间保留 0.1 ms、压力保留 0.001。新版本的补点与临时尾点采用 1e-6 归一化坐标精度，减少 JSON 体积。在 3840 px 宽度上，每轴舍入误差不超过约 0.00192 px。
- 进度包、checkpoint、板书保存入口、备课批注合同、归档、移动复制和撤销保留样本与笔刷版本。已有无版本、round-v1、freehand-v1 笔迹继续按原参数重放。新增笔刷已登记版本化同步 provider。
- H5 runtime 升为 5；协议版本仍为 1，增加可选压力与时间字段并兼容旧二维消息，嵌套 iframe 转发保留这两个字段。此次没有修改课件内容版本或数据库结构。

## 验证依据与限制

定向检查覆盖以下行为：

- 同速轨迹的真实压力粗细变化、缺失与默认压力回退、抬笔压力保持、单点与转折、预览与完成轮廓一致。
- 小末点的当前帧预览、重复静止输入不调度、实际 CanvasSurface 输入端口中的合并样本和非当前指针隔离、滚动后的坐标缓存失效。
- 局部清除、重叠笔迹恢复、未变化轮廓缓存、完成/取消清理、画布尺寸与主题变化、已有掌擦和连续提交行为。
- H5 注入运行时的逐样本压力/时间和最新点、向后兼容协议、乱序进度、checkpoint、归档与撤销。
- 4000 个经过本次输入量化的样本在既有 checkpoint 预算内完整保存，点数不减少；不匹配的样本数量、倒退时间和越界压力被解析器拒绝。

在固定的合成局部更新场景（1920×1080，活动笔迹加一条不相交的远端笔迹）中，清除面积低于整画布的 2%，本次更新只计算活动笔迹的 PF 轮廓。重叠场景则复用远端轮廓并在裁剪区域内恢复，确保局部清除不会抹掉其他笔迹。这些是绘制工作范围的机器检查，不能换算为低端大屏输入到显示的实际延迟。

受影响文件 ESLint 通过。全库 TypeScript 检查仍有既有的 `tests/teacher-workspace-entry.test.ts:31` TS18048，未修改该范围外文件。本机开发健康接口返回 200 / development。没有浏览器自动操作、数据库业务写入或生产请求。

新版本及携带样本的笔迹在 checkpoint 中保留完整点列，避免单独抽取中心线后改变粗细或错配压力。超出既有单笔体积或整板预算时仍由保存错误流程处理；本轮未扩大数据库预算。任意超长笔画的分段、点数合同及压力感知压缩需要独立处理，不能将上述 4000 点用例外推为任意大小输入均可保存。

当前活动 PF 轮廓生成仍随本笔点数增长。首轮改进覆盖绘制面积、重复轮廓、布局读取及尾点；浏览器合成、显示扫描、驱动与设备输入年龄仍须实际设备测量。模拟压力继续使用 PF 原模型，采样密度造成的风格差异尚未改为基于时间的速度模型。

## 人工验收

从[开发端班级入口](http://192.168.5.213:3130/zh/dashboard/classes)刷新并进入已有课次试讲。优先使用低端 Windows Chrome / Edge，在空白主板书、副板书分别写点、短横、快慢横线、“永、国、心”、连续长线；再比较有效压感笔的轻重、抬笔、翻页后重放和撤销。最后复核整笔擦与局部掌擦。
