## 已固化的逐生检查边界

正式课件只保存稳定 `page_doc_id + track` 上的“需逐生检查”布尔标记，发布时固化到 release。备课课次默认继承当前 release，允许本课删除默认页或临时加入其他课件页；额外项目通过新增空白课件页实现，不另建脱离页面的自定义项。每次点击自动写入 `session_learning_checks`，`class_sessions.learning_checks_configured_at` 使明确保存的空清单刷新后仍保持为空；所有课次调整不反向修改正式课件。

## 本轮媒体问题结论

学生从中间页加入时，页面文档会先于绑定资源 URL 到达；旧实现又按整套课件顺序串行预载，导致教师端已缓存可播放、学生端长时间显示“资源不可用”。当前页对象现在排在队首并采用 4 路有界并发，其余对象后台预载；绑定未到时显示明确加载态，完成后视频无原生控制条且不接受学生触摸。
## 课前工作区与材料审核增量

- 进入课前阶段自动开始备课，不再提供“开始备课”按钮；复制备课、完成备课、预览课件并试讲与阶段导航同行。
- 左栏只保留解析记录、标准教案、磨课链接三步实际生产流程。有效上传/链接保存会为对应材料创建或递增审核 revision，状态进入 `pending`，并向有效课程审核人发送实时通知；未配置审核人时管理员审核队列兜底。
- 审核面板按课次和材料显示签名附件/链接，支持通过或退回修改。三项材料必须全部 `approved`，并满足课件 release 与逐生检查门，教师才能完成备课。
- 右侧工作区使用 13rem 窄页栏和 4:3 预览；正式文档页书本图标直接切换本课“需逐生检查”，选中后显示绿色确认图标，再次点击可取消。点击后串行自动保存并显示保存状态，写入仅影响本课，不反向修改正式课件。
- 当前代码通过 typecheck、lint、messages、数据库类型与规划审计；迁移已应用开发库、数据库类型已重生，production build 与本轮 R1 定向回归通过。最终响应式浏览器复测仍保持 pending。
