- “还有 N 项待完成”压缩为单行高对比状态条，只展示必需任务计数和完成进度；补登记出勤、完成或重新打开本次课移动到“课前 / 课堂 / 课后”阶段导航同行区域。

## 已固化的逐生检查边界

正式课件只保存稳定 `page_doc_id + track` 上的“需逐生检查”布尔标记，发布时固化到 release。备课课次默认继承当前 release，允许本课删除默认页或临时加入其他课件页；额外项目通过新增空白课件页实现，不另建脱离页面的自定义项。每次点击自动写入 `session_learning_checks`，`class_sessions.learning_checks_configured_at` 使明确保存的空清单刷新后仍保持为空；所有课次调整不反向修改正式课件。

## 本轮媒体问题结论

学生从中间页加入时，页面文档会先于绑定资源 URL 到达；旧实现又按整套课件顺序串行预载，导致教师端已缓存可播放、学生端长时间显示“资源不可用”。当前页对象现在排在队首并采用 4 路有界并发，其余对象后台预载；绑定未到时显示明确加载态，完成后视频无原生控制条且不接受学生触摸。

## 家庭门户发布与跨子女隔离增量

- `get_my_schedule` 与 `get_my_attendance` 返回稳定 `student_id`；`/dashboard/children` 和家长首页按 ID 过滤，不再以可重复的姓名拼接多子女数据。
- 家庭课评投影只联接 `published_at is not null` 的家庭摘要，删除了对内部 `class_sessions.knowledge_summary` 草稿的回退。
- 保存家庭摘要会清空发布时间；逐生课评 insert/update/delete 由触发器自动撤回当前家庭摘要。教师显式重新发布后家庭端才再次可见。
- `get_my_session_review_states` 只投影家庭可见的课次元数据和 `pending/published/withdrawn`；孩子详情与家长首页显示待审核或已撤回，不再把两者伪装成“暂无课评”，发布正文仍由独立 RPC 控制。
- `get_family_session_brief` 对家长要求 `grades` scope；关系或 scope 撤回后 RPC fail-closed。
- `revoke_my_guardian_relationship` 只删除调用者自己的关系；同一学生上的操作串行化，当前同意记录追加 `withdrawn`，主监护人离开时按绑定时间顺延下一位。
- 家庭页先区分学生本人档案与监护绑定；只有监护绑定显示解除入口，并用 `AlertDialog` 明确即时失权后果。
