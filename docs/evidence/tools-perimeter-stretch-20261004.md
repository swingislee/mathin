# 周长探究 · 凹凸多边形定量拉伸

> 2026-10-04；开发端已交付，待人工视觉与教学手感验收。数据库、生产与业务 Gate 保持。

## 行为与边界

自绘、模板及编辑后的简单凹凸多边形，可开启“定周长拉伸”或“定面积拉伸”，用整体宽高输入和两个方向方柄联动调整。方向随材料旋转与镜像，顶点次序、材料身份和其它材料保持；仅重置被改材料的绕边／拉直进度。

定面积的两个正轴缩放互为倒数；定周长逐条计算真实边的欧氏长度并单调求解另一轴，不以包围框度量代替图形度量。尺寸限制到可解与坐标范围后再做完整几何校验；短边、退化等不合法时保留原状。矩形继续沿实际边方向，原变方形动画仍保量；普通多边形不变换拓扑。

测量主动开启后显示边长、周长和面积，单位为 30 舞台单位 = 1 u，面积为对应 u²；关闭操作仍保留读数，默认关闭结论。关闭操作回到普通编辑，这是整体定量拉伸，不是逐顶点永久锁。沿用 `10-create` / v2 真实点位、历史、备课固定副本及课堂 snapshot；没有新增字段、版本、共享输入原语或数据库迁移，旧 v1 保持。

## 人工验收

在统一开发入口打开“周长探究”，画一个凹多边形并选中；开启定周长或定面积，调整宽高、拖方柄并核对主动开启的读数。旋转、镜像后重复，确认其它材料保持；关闭面板自由编辑，测试撤销、保存重新打开与恢复起点。矩形原变方形过程继续可用。人工结果与机器检查分别登记。
