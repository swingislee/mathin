> 2026-10-02；实现与定向机器检查完成，本机正式安装与 main 交付待串行窗口。人工视觉及教学手感待验收；生产与业务 Gate 不涉及。

## 本批可操作范围

- 自绘或快捷添加的三角形都可开启内点 P、底边分点 D 和四个真实分区；自由内点始终位于合法内部。
- 数字输入与直接手柄使用同一比例。共线开启后 P 沿对顶点—D 连线移动，D 变化时保持 P 的高度比例；解除共线不跳点。旋转、镜像与网格开关不会把点拉离约束。
- 换底保持 P 的实际位置，共线时同步新 D；极靠边导致新比例超界时，保留原底与点位，仍选择被点击的材料。
- 分区整组复制成四张独立材料，原件与观察保留；材料容量、ID 或几何边界不足时整次取消。关闭面板或 Esc 收起手柄，观察继续展示；课堂只读端没有手柄。
- 新建改为 `plane-area-relations-lesson-v3` / `18-interior`，v1/v2 及冻结副本继续按原版本读取。没有改动共用工作台、课堂事件壳、业务表或身份。
- 方格条、共角、共同纸片移除和相似联动继续后续；本批不宣称这些能力已完成。

## 人工验收入口与动作

在统一开发入口打开“面积关系”，选中三角形，打开“内点与两翼”并显示分区。拖动 P、D，开启和解除共线；旋转材料后重复操作。开启测量比较两翼，复制分区并搬开，再试撤销与恢复起点。保存场景后重新打开，核对内点比例与观察；已有 v1/v2 课件仍按原样打开。
