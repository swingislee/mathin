# 面积关系 · 共角与定点等比伸缩

> 2026-10-04；实现、定向测试与中英文局域网路由启动检查完成，开发端已交付，待人工视觉与教学手感验收。本次没有数据库、生产或 Gate 操作。

## 可操作范围

- 在自己绘制或现有的三角形上，以所选底边的对顶点 O 为中心，准确设置 OA／OB，或沿实际射线拖动 A／B。独立调边保留共角；等比伸缩让当前两边联动，其他材料不动。
- 添加同向共角或反向沙漏副本，保留原片与观察，选中新材料。材料彼此独立；自由搬动或改形后按实际几何重新判断关系。
- 开启测量，显示当前与参照材料编号、两条射线对应比和面积比；有多个合法参照时取面积最大者，同面积按 ID。对应比相同、底边平行时显示平方关系；不同只说明这组对应底边不平行，不否认交换对应后的相似可能。
- 一键沿 OB 调为对应底边平行；缩为一半或放大一倍有过程动画，可暂停、保存准确中间材料、继续或一次撤销。关闭操作收起手柄，继续普通编辑。
- 保留等高线锁定的优先级；需先解除该锁再沿射线调边。网格不改变数学终点；容量、ID、最小几何或坐标边界不允许时整次保持原状。
- 使用现有 `18-interior` / `plane-area-relations-lesson-v3`；无新增持久字段、内容版本、SQL 或共用宿主分支。原 v1/v2 和冻结副本保持。本批不建立跨材料永久联动，旧方格条及通用凹形／圆弧布尔仍为后续范围。

## 人工验收

在面积关系开发页选中三角形，打开“共角分别调边”，添加同向或沙漏副本。分别拖动两端，开启测量核对当前／参照对应，再到“定点等比伸缩”调整为平行、拖任一端、缩为一半并暂停。试撤销、关闭面板、自由移动以及保存重开；旋转或换底后重复体验方向与读数。产品结论由这次人工验收确认。
