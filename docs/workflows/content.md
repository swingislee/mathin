# 内容、知识世界与家长使用

## 数学知识世界

Terms 是稳定的知识关联入口。Story、Minds、Games、Tools、Notebook 和课程通过稳定身份形成关系，标题或 slug 调整时继续维护链接与引用。

Terms 的星球、岛屿、路径和概念帮助从整体进入具体数学；Story 用可探索的场景承接故事与数学活动；Minds 用内容和阅读结构承接思考。插画参与组织入口、方向与层级。学生的探索、理解和实际操作是这些页面的主要活动。

游戏按玩法组织材料与反馈。数独可以服务于方法讨论、部分盘面和完整挑战；反馈时机依据具体玩法。教具服务于解释与探索，评测能力由产品负责人另行选择。

## 写作与发布

Notebook 支持私人积累与后续整理；草稿、审核、发布、撤回与修订分别表达实际行为。作者身份、发布归属和阅读权限在服务端核对。已发布课堂 release 保持不可变，后续修订产生可追溯的新版本。

英文界面与中文界面同步维护。英文课程或文章尚缺时显示明确的回退或未发布信息；实际内容进度见 [当前状态](../current.md)。

内容导入维护源资源、页身份、比例与衍生版本，操作入口见 [课程导入](../ops/courseware-import.md)。历史导入材料可以查阅，正式资源与冻结版本继续受保护。

## 家长与多端

家长围绕孩子查看课表、学习记录、报告、错题与作业，办理测评、活动、请假等已经接入的工作。已有账号和亲子关系延续到各端，数据与权限由同一后端验证。

网站、小程序、iOS 和 Android 使用适合各端的交互。共享对象和 API 语义，按设备组织导航与触摸。平台代码、可运行包、发布与人工验收各自记录。

实现与平台操作分别见 [apps](../../apps/README.md) 和 [家长 API](../../contracts/parent-api/README.md)。范围与优先级依据产品负责人当前任务；当前各端完成度见 [当前状态](../current.md)。
