# 产品方向

Mathin 是让师生直接操作数学材料、让学校人员连续处理真实业务的工作现场；系统整理事实、计算和保存，使用者决定材料、方法与判断。

## 首版就这样做

1. **先交付能完成的工作。** 缩小首版支持范围，把所选工作做通。例如老师在课件里配好教具、保存、重新打开，上课从备好的起点操作并恢复起点。
2. **把对象和关系直接摆出来。** 教学进度用“班级 × 讲次”矩阵，点进对应备课、学情或课后材料；总览沿具体人员与记录展开处理，数字汇总服务于这些事实。
3. **按真实的一整组来操作。** 课堂主板书、副板书、20 人名单持续同屏；名单保持座次，逐人登记后用“补齐未登记”处理余下学生，保留已作出的判断。
4. **高频动作直接上屏。** 黑、红、蓝三色就是三支笔，点击即写；首联用 1–4 选结果、↑↓ 连续处理、Ctrl/Cmd + Enter 显式保存，填写者不用反复打开菜单。
5. **给材料，也让人自己做材料。** 教具打开有起点，教师自绘、导入、编辑的材料继续参与同样的数学操作；在同一图形上叠加平移、旋转、对称和参照。七巧板拼摆与图形认识按教学目的分开。
6. **查看依据与动手处理放在一起。** 跟进就在记录行下登记；阶段报告把学情、作业、视频、课评依据放在正文旁，查看与写作往返时保留位置和草稿。
7. **分别记事实，再推导状态。** 测评、意向、报名、班级安排各记其事；未知保留未知。学生五个主标签从真实完成事实互斥归类，首联、邀约等过程继续并行，不做强制逐级通关。
8. **自动完成杂务，保留明确意图。** 有效首联保存时同事务建立最小学生档案；课后材料分别保存、由事实派生进度。自动保存草稿与发送、发布分开，批量处理保留人工选择，失败后保留输入。
9. **同一材料持续可操作。** 备课、试讲、课堂共用教具和数学约束；拖动实时预览、松手提交一次，按钮与手势到达同一终点。折叠、旋转、切拼展示过程，暂停后继续；冻结课件保持当时内容。
10. **视觉直接组织工作。** 公开探索用小王子场景与空间入口；Dashboard 等工作区用连续表格、画布和细分隔线。工具操作用 SVG＋语义颜色，说明放悬停提示和无障碍名称；表单登记标签完整显示。手机沿用同一记录和草稿纵向排列。

## AI 默认做法 → Mathin 做法

| AI 默认做法 | Mathin 做法 |
| --- | --- |
| KPI 卡片铺满首页 | 展示人员、记录与关系，就地展开处理 |
| 标题、筛选、内容各套卡片 | 连续工作区；仅保留明确批准的独立对象卡片 |
| 先做漂亮说明页 | 先让用户操作材料、完成一次真实工作 |
| 向导要求逐步完成 | 并行登记事实，真实依赖决定顺序 |
| 工具藏进菜单 | 三支笔直接上屏，高频动作靠近对象 |
| 单人详情反复进出 | 整班同屏、矩阵对照、行下连续登记 |
| 只能挑预设示例 | 自建材料同样参与操作 |
| 相近能力做成切换模式 | 在当前材料上增加能力，延续现场 |
| 只显示数学结果 | 直接操作、过程动画、准确终点与恢复 |
| 加说明段帮助发现 | 固定位置、SVG、颜色、悬停与焦点提示 |
| 切换选项即保存 | 草稿保留，实际提交显式发生 |
| 总览拉全量明细再算 | 数据库按权限聚合，展开才读一页明细 |
