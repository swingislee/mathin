## 2. 稳定页面语法

### 2.1 Mathin 是签名，不是横幅

- 场景型页面：Mathin 位于左上角，作为页面签名；通知与菜单位于右上角。
- 内容型页面：Mathin 可位于内容轴或页面边缘，但标题、正文、列表必须共用同一左边线。
- Dashboard：Mathin 位于左侧导航顶部，属于工作区框架，不再重复占用主内容顶部。
- 全屏工作区：品牌可退化为返回入口；不为保持统一坐标而强塞全宽栏。

Logo 尺寸稳定、位置清楚、与当前页面身份相关，并保留呼吸空间；不同页面类型不要求同一绝对坐标。

### 2.2 边缘控制星座

| 区域 | 职责 | 当前实现 |
| --- | --- | --- |
| 左上 | 品牌、返回、当前位置 | 公开场景的 Mathin；Dashboard 左侧品牌 |
| 右上 | 通知、全局菜单、账户 | `ChangeBell` + `UtilitySheet` |
| 左侧 | 当前空间导航 | Dashboard 静态导航；移动端左 Sheet |
| 右侧 | 当前对象工具或设置 | 各工作区的对象面板/工具轨 |
| 底部 | 进度、分页、模式状态 | 各场景或工作区按需提供，不建全局底栏 |

边缘按钮统一为 44×44px 圆形玻璃纸材质、细边框、轻阴影；hover 只上浮 2px。`SiteHeader` 本身 `pointer-events-none`，只有实际控件恢复交互，因此不存在一条遮挡内容的透明横栏。

### 2.3 三种页面坐标系

1. **场景型页面**：以视口边缘为坐标系。左上为品牌与页面身份，右上为全局功能，中央为主场景，底部只放必要状态。
2. **内容型页面**：以正文主轴为坐标系。面包屑、标题、简介、正文与列表共用左边线；浏览器页面承担纵向滚动。
3. **工作区页面**：以工作区框架为坐标系。静态导航、工作区标题、主工作内容各司其职；面板型工具在桌面端使用内部唯一滚动区。

`SectionShell` 继续服务内容型/尚未场景化的页面，不再作为五个公开主题首页的强制统一壳。学校端标题继续服从 P4I 的 `ObjectBar` / `ObjectWorkspace`，不回退到全站统一的“H1＋短线＋说明”。

## 3. 右侧 UtilitySheet

固定结构：

```text
UtilitySheet
├── DrawerHeader          账户摘要或登录入口，固定
├── DrawerScrollBody      唯一滚动区
└── DrawerAccountFooter   语言、主题、退出登录，固定
```

规则：

- 不展示“全站导航”标题；登录用户直接显示头像首字、昵称与邮箱，未登录用户显示登录入口。
- 中部按“公开空间 / 使用环境 / 登录功能”分组。每个分组是一张容器卡，组内入口是 44px 紧凑导航行，以分隔线区分，不再一入口一卡。
- 环境切换只在用户拥有多个环境时出现；当前环境用 `aria-current=page` 标识。
- 语言、主题和退出登录固定在尾部，不会被低分辨率窗口挤出。
- 隐私政策与儿童个人信息保护不属于导航抽屉；仅在注册页作为必选同意项出现。

## 4. 五个公开主题首页

五页共享 `ThemePageIdentity`，标题合同固定为：

```text
星球身份 / eyebrow
板块主标题 / h1
板块简介 / description
```

三段文案分别来自同一板块的 next-intl 命名空间；不得在某页用副标题、某页用口号、某页再叠一套说明。标题位于左上安全区，具体颜色可随场景调整，但层级、间距和宽度保持同一合同。

| 页面 | 空间结构 | 可操作对象 | 当前状态 |
| --- | --- | --- | --- |
| Story | 沙丘与旅行路径形成地平线和方向 | 章节场景节点（当前为展示占位） | 场景已落地；真实章节仍属 P5 |
| Games | 王冠、拱门、盾徽构成皇家大厅 | 游戏对象卡 | 数独/数和/幻方及成绩入口可用 |
| Minds | 路灯构成纵向阅读轴 | 思维导航行 | MDX 思维文章入口可用 |
| Terms | 星系、星球、岛屿构成空间层级 | 3D 星球与图谱入口 | 知识宇宙现有交互继续复用 |
| Tools | 账本、印章、工具箱构成工作台 | 工具对象卡 | 已注册工具入口可用 |

插画承担起点、方向、分区、状态与终点，不作为卡片角落贴纸。当前场景资产位于 `public/illustrations/`；Dashboard 的观测台插画位于导航区底部，作为空间收束。

## 5. 卡片使用边界

卡片只保留给可操作对象：教室、Puzzle、工具、任务、课程、用户、章节节点。页面分组、背景、标题区、导航外框、简介和空状态优先依靠排版、线条、局部底色与留白表达。

例外说明：UtilitySheet 的“分组容器卡”用于把紧凑导航行组织为一个控制集合；组内每个入口不是独立卡片。

## 6. 滚动责任

同一方向只允许一个主要滚动责任：

| 页面类型 | 主要滚动者 | 固定/内部区域 |
| --- | --- | --- |
| 内容页 | 浏览器页面 | 无重复纵向滚动容器 |
| Dashboard 普通页 | 主工作区 `<main>` | 左侧导航静态，必要时低显性内部滚动 |
| 面板型工作区 | 工作区内部 | 外层在桌面端 `overflow-hidden` |
| 全屏场景 | 场景固定 | 桌面端不滚；移动端内容超高时允许页面滚动 |
| UtilitySheet | 中部 `ScrollArea` | 头部与账户尾部固定 |

全局滚动条使用 6px 窄条、透明轨道、圆头 `--crater` 滑块；Firefox 与 WebKit 使用同一视觉语言。Radix `ScrollArea` 不得另起明显不同的滚动条皮肤。

## 7. 字体策略

- `html:lang(zh-CN)`：正文、标题、按钮与表单统一使用 `LXGW WenKai`，回退为系统楷体。
- 其他语言：使用 `Iowan Old Style` / `Palatino Linotype` / Palatino / Georgia，保持相近的书卷气质。
- 数学公式继续使用 KaTeX 自带字体；等宽信息继续使用 `ui-monospace`。
- 禁止 Google Fonts 远程加载；字体必须自托管。

当前霞鹜文楷由上游 `unicode-range` CSS 拆成 **97 个 WOFF2 分片，总计约 4.42 MiB**。这些文件不是 97 套字体，也不会无条件全部下载；浏览器只请求当前页面字符覆盖到的分片。保留拆分可以避免每个页面下载完整中文字库。后续若重新子集化，必须同时验证中英文、后台长尾姓名/地名和动态用户内容，不能只按静态标题字符裁剪。

## 8. 注册与账户入口

- 注册页字段：昵称、邀请码、邮箱、密码。
- 注册前必须分别勾选隐私政策和儿童个人信息保护政策；两项链接只在注册流程展示。
- Server Action 使用 zod 校验；数据库 `handle_new_user()` 再校验邀请码和双同意，阻止绕过应用直接注册。
- `registration.invite.manage` 控制邀请码设置页；主管/校长和 admin 可配置邀请码及启用状态。
- UtilitySheet 不重复展示隐私政策链接，也不承担注册合规确认。

## 9. 动效与无障碍

- 场景元素入场：`scene-rise`，700ms，轻微上移淡入。
- 允许的环境漂浮：`scene-drift`，7s，位移约 7px；交互卡 hover 上浮不超过 8px。
- 所有场景动画和边缘控件过渡必须响应 `prefers-reduced-motion: reduce`。
- 边缘控件有可见焦点环；抽屉使用 shadcn `Sheet` 提供焦点陷阱、Esc 与滚动锁。
- 场景背景图为结构性装饰时使用空 `alt`；页面身份与操作对象必须保留语义标题和 aria 标签。
