## 产品目标

提供可预先配置、可放入课件、课上可继续操作的数学教具。旋转、多视角、折叠、移动与参数变化呈现数学关系；操作过程本身承担展示和验证。老师组织问题与解释，工具不要求教学目标、标准答案、学生提交、判题或检查点。

立方体结构、正方体展开图、骰子、投射、分数和行程具有独立工具入口。它们共用合适的视角、拖动、面板和教学场景接入能力，不强求相同的领域操作。旧 `spatial-lab` 地址及已发布内容继续可读。

投射首个增量复用空间内核与共用场景接口，聚焦单位立方体结构与三个正投影面的动态关系；不增加视图条件判题或目标答案流程。自由光源、任意实体投影和连续旋转实体属于后续独立设计，不包含在当前增量内。

## 使用路径

1. 在正式课件或教师自建课件中选择工具。
2. 直接使用原工具配置教学起点，例如三条轨道的速度、时间、方向和起点。
3. 将自包含、版本化的场景保存为课件组件；重新打开时继续配置。
4. 课堂直接从备好的起点操作，展示端跟随；恢复起点只影响本次演示。

独立工具页共用“我的场景／保存场景／另存一份”，课堂临时调用继续保留为辅助入口。个人场景库与课件直接配置使用同一内容合同，保存个人场景不作为插入课件的前置门。步骤录制是可选能力，保存场景不要求录制；原立方体草稿可以导入当前现场或已录步骤。

## 共用边界

- 工具提供严格起点/运行状态合同、原组件的初始化与状态导出、必要的语义动画动作。
- 共用层负责选择、配置、固定副本、编辑、权限、实例隔离、课堂同步、晚加入及恢复起点。
- 场景包含工具需要的初始参数、可见性与视图设置，不保存可变个人草稿指针或逐帧动画。
- 发布副本与源草稿独立；课堂操作不回写课件。更新、删除个人场景不改变历史课堂。
- 老内容不静默迁移；新增工具无需逐个改写课堂页面、事件存储或恢复流程。
- 保留数学正确性和受控输入校验，但不把它们变成强制的题目作答流程。
- 空间教具同时提供直接操作与精确控制：命中对象时操作对象，空白处旋转视角；按钮和直接动作共用数学终点与过程动画。共用组件、当前工具核查及接入边界见[立体教具共用交互](../../src/features/tools/spatial-interaction/README.md)。

## Tools 数据参数与接口权威

统一入口为 `src/features/tools/scenes/`。`registry.ts` 维护工具身份、内容版本和宿主能力；`contract.ts` 维护严格场景联合与固定副本；具体工具声明自身参数，课件、独立工具页与课堂消费相同数据。

| 层级 | 共用字段或能力 | 领域内容 |
| --- | --- | --- |
| 教学场景 `ToolScene` | `toolId`、`contentVersion`、`payload.title`；严格校验与 512 KB 序列化上限 | 立方体保留 `history/toolbar`；其余工具的 `payload.initial` 保存各自场景 |
| 账号草稿 `tool_scene_drafts` | `id`、`owner_id`、`catalog_id`、`name`、`revision`、`scene`、创建／修改时刻 | `scene` 始终通过同一版本化场景合同；不按工具新建一张表 |
| 课件固定副本 | `freezeToolScene()` 复制完整场景，组合页只使用公共 `toolSceneSchema` | 与可变草稿 ID 解耦，旧 release 不重写 |
| 课堂现场 | 共用实例标识、起点哈希、状态收发、失败恢复、晚加入与复位 | 工具登记参数状态和必要的语义动作，连续画面在原组件渲染 |

现有参数边界：

- 立方体结构：方块、位置、分组、面色与标注、可见性、视角、工具栏，以及可选录制步骤。
- 展开图：图形来源、折叠角、当前支撑面、剪棱与面位置、标色和显示设置。
- 骰子：各骰子位置与左右手系、点数显隐、移面、面色／透明度、滚动足迹和观察设置。
- 分数：分数单位、各行点数、缩放／平移、整数刻度和辅助线。
- 行程：轨道长度、各跑道的位置／方向／速度／时间／路程／角色、求解方式与显示设置。备课存静止起点，课堂播放另存时间锚点，不逐帧写入。
- 投射：单位立方体结构的当前位置、显隐、面色／透明度／标注和预设视角，以及三个投影面与投射线的显示设置。保存当前结构，不携带个人草稿指针、临时拖动帧或撤销历史。

HTTP 接口统一为 `GET /api/tools/scenes`（本人元数据列表）、`GET /api/tools/scenes?id=...`（本人完整场景）及 `POST /api/tools/scenes`（`id / expectedRevision / scene`）。`expectedRevision=0` 创建，其余作乐观版本更新；名称与目录身份从已校验场景提取。共用客户端负责账号绑定，服务端负责 Cookie 鉴权、同源检查、流式字节限制和 RLS。冲突保留编辑内容，并提供另存一份。

旧 `spatial-lab` wire ID 与 `*-lesson-v*` 内容版本是已发布数据的兼容身份；目录分别显示为立方体结构、展开图、骰子。`cube_structure_drafts` 及原 API 保留工作过程草稿，新场景库通过导入复制内容，不搬移或删除原记录。新工具接入共用场景、组件和课堂合同，不逐个扩展课堂路由、事件表或发布流程。

### 工作台接入声明

- `scenes/workbench-adapter.tsx` 定义统一的 `Preparation`、`Presentation` 和可选 `Import` 槽。备课接收固定起点与名称，导出稳定候选场景；交互或异步构建中返回 `null`。共用宿主严格校验候选，不把它回灌为正在操作的组件初始值。
- 每个工具在本领域的 `*-scene-adapter.tsx` 或 `scene-adapter.tsx` 内连接原组件。默认场景、参数转换、录制选项和工具栏语义由工具自身维护；共用层不要求分数、行程和 3D 使用同一组按钮。
- `scenes/workbench-registry.ts` 穷尽登记当前可备课版本的客户端接线，工具组件按需加载；`scenes/registry.ts` 保留服务端与公开目录可用的轻量身份和能力元数据。备课与课堂展示按同一客户端登记选取组件，切换工具时重新建立编辑会话。
- `scenes/classroom-envelope.ts` 提供与具体数学工具无关的事件外壳、规范化摘要和实例标识；`scenes/runtime.ts` 统一按工具身份与版本读写课堂状态。原立方体接口委托共用实现，已存事件与起点摘要保持兼容。
- `scenes/useToolSnapshot.ts` 负责离散场景的本地操作、课堂持久写入锁与失败提示；立方体和投射共用。课堂由确认后的权威状态驱动画布，投影与立方体移动共用动画，不在回执后另行播放。

后续接入工具时：声明其严格参数与状态／动作合同，登记领域组件接线，并增加该工具的参数往返与课堂恢复用例。新增参数版本仍需同步服务端持久化校验；保存 API、草稿表、课堂主页面和事件传输流程直接复用。投射已按这条路径接入；通用录制与旧草稿整体迁移继续后置。
