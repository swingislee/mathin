# 正方体展开图 · 逐面折叠教学工作台

> 2026-09-14 状态：产品负责人已明确通过直接拖拽功能验收，保留任意面抓取、临时支撑与空白旋转基线。新增逐面动画展开、11 种展开图弹窗与平面 90° 变换，以及“立方体 → 剪棱 → 展开图”的第二条探索路径；新增部分开发端已交付，待人工视觉与交互验收。独立 Tools 增量不改变 doc 04 当前阶段、SML-0 暂停状态或生产 Gate。

## 1. 教学合同

老师决定先折哪个面、向哪边折、停在哪个角度，观察后再判断。打开页面不显示“合法展开图”徽标、相对面答案或自动播放步骤，也不挂载原来的合法性选择题面板。

- 左上形态按钮打开包含 11 种展开图的弹窗，以中性编号和缩略图选择。选择另一种图形时，先将当前纸片逐面展开，再在当前纸面所在平面内作 90° 转动；相同部分保留原位，字母随方格移动。自由拼图、不能闭合的候选形态另行设计；当前结果不声称覆盖全部 35 种六连方。
- 平面变换在可达的合法展开图之间搜索：沿相邻方格中心或共用顶点，将连接的一侧转动 90°，每步完成后仍为合法形态。先最小化整个过程实际移动的方格数量，再最小化转动步数；此最小性限于上述变换规则。旋转中允许纸片掠过，是平面拼摆示意，不将其描述成保持所有剪口粘连的物理折叠。
- 默认“折叠纸片”模式中，按住任意面即可拖动，不要求先选面、折痕或底面。连接边按抓取点就近确定；等距时优先带动较少纸片。抓取所在的一侧及其连带纸片转动，另一侧在本次手势内作支撑。按下后显示将移动的纸片与连接边；没有永久固定的 A 面，前次支撑面也可在下次抓取。
- 抓取点沿折痕轴作真实圆周运动，根据当前观察投影求拖动角度；范围仍为 −90°～90°。移除选面按钮组、滑杆和数字快捷落点，只在画布内辅助显示角度。接近 0°／±90° 时松手吸附，其余位置可以停住。
- 单次指针捕获只在松手时写入一步；轻点不折叠也不产生撤销记录。拖动中间帧仅作预览。Esc、失焦、pointercancel 和丢失捕获取消本次操作。折叠模式下拖空白处直接旋转观察，拖纸片时立即暂停相机；松手恢复。显式“观察”仍支持从模型上旋转，“平移”保留独立工具。
- 支持撤销、重做和全部展开。“全部展开”从当前支撑侧向外确定顺序，末端先展开，一次动画只改变一条连接边，跳过已经放平的边；完成后一次提交并可撤销。动画中仍可旋转观察，停止按钮、Esc 或失焦取消预览；系统减少动态效果设置使用直接落点。最近 100 次操作构成本页撤销窗口，撤销后继续操作形成新分支。
- 第二条路径从完整立方体出发：点击右侧“剪棱展开”，或在形态弹窗选择“立方体 → 展开图”，逐面收成立方体后开始剪棱。单击可见棱剪开，再点恢复；剪口以玫瑰红虚线标记。拖动仍旋转，背面棱由前面的纸面遮挡，切换观察／平移时保留剪口显示。
- 剪棱过程中给出连接状态：六个面仍相连且只剩五条连接棱时可全部展开；还有环路时提示继续剪，分离成几片时提示恢复剪口。展开图由实际保留的棱刚性铺平生成，目录仅识别其形态，不替换老师的剪法。动画完成后可继续直接拖纸片折叠。剪口可撤销／重做或“重新剪”；返回折叠工具回到进入剪棱前的纸片状态。
- 老师点击“判断当前折叠”才出现结果。根据当前几何区分闭合、尚未闭合、重叠或穿插；继续改变角度时清除旧结果。尚未闭合不代表原图不能折。整体正折和整体反折形成的正方体都成立。
- 这是零厚度纸面的几何演示，结果只检查当前姿态，不证明拖动路径全程无碰撞，也不模拟纸张受力或阻挡。
- 复用立方体工作台的 4:3 画布、按钮、面板与布局样式：右上为立体／正视／左视／右视／俯视、重新居中、吸附、坐标轴；右侧为观察、平移、折叠、剪棱、判断、全部展开、撤销／重做，竖屏沿用底部横排。左上形态按钮选择展开图，设置面板保留场景切换。原堆叠立方体的切分工具保持原行为。
- 初始纸面平放在 XZ 平面、Y=0。数学内核保留原参考坐标，表现层根据本次支撑面的三个顶点作刚性对齐；换支撑时几何不跳位，其他连接角度不变。两类工作台共用正交相机工厂、Y 向上与取景比例。拖动时取景保持稳定；主动点击视角或重新居中按当前几何重新取景。当前连接边只作辅助提示，不承担点击入口；面标签保持在工具栏之下。

## 2. 数据与接入边界

本地状态为 `cube-net-teaching-v1`：折痕 ID → 相对角度、本次支撑面的定位及撤销／重做历史。角度与定位共同提交、撤销和重做；全部展开保留当前支撑定位并将相对角度归零，也可撤销。平面切换保留纸片的可见字母与定位，目标形态建立新的本地操作历史。剪棱另存本地剪口及撤销历史，展开成功才接入纸片会话；取消和生成失败保留剪口。离开页面后重置，当前不提供账号持久保存、录制步骤或课件插入。

复用既有拓扑、铰链树和折叠数学内核，新增独立折痕的计算入口；旧全局进度、冻结 `spatial-page-v1`、模板 hash 和课堂 command schema 保持原合同。渲染层只消费内核计算结果，不从 Mesh 推导答案。

`LOCAL_SPATIAL_WORKBENCH_SYNC_PROVIDERS` 显式声明本版本仍需正式空间语义同步；当前本机操作不等同于教师端、展示端、学生端同步。课堂发布与持久化按后续明确批次实施，本增量没有数据库、Storage、生产服务写入。

新增机器检查覆盖 11 种形态两两平面变换、倾斜纸面的连续切换、逐面展开、动画取消和一次提交；枚举立方体全部剪口组合，其中 384 个连通五边树覆盖 11 种展开图，保持未剪棱和各面定位。真实 R3F 事件检查鼠标／触摸单击剪棱、恢复、背面遮挡与从棱上拖动旋转。复用开发服务检查 zh/en 页面可启动；未执行正式发布 Gate 或生产写入。

直接拖拽功能已由产品负责人验收通过；以下课堂屏幕组合检查与本次新增项目继续按实际使用验收，不由机器结果代替。

- [ ] 选择几个不同形态，直接抓取不同纸片及 A 面，确认自动确定的连接边和连带范围符合直觉，无需选底面。
- [ ] 拖到中间角度停住、折起／放下、撤销与重做；拖动中按 Esc 或移出再松手，检查取消和提交。

- [ ] 每次折叠后从空白处直接旋转；再抓此前的支撑面继续折，检查图形不跳位、相机不与折叠抢手势。
- [ ] 在实际课堂屏幕上检查纸片抓取、观察／平移、取景稳定性及横竖屏工具布局。
