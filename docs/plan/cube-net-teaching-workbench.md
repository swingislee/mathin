# 正方体展开图 · 逐面折叠教学工作台

> 2026-09-15 状态：直接拖拽已由产品负责人验收。本次按反馈修正主动教学动画被系统减少动效分支省略的问题，移面、剪棱展开与换图保留连续过程；11 图目录改为画布旁的常驻非模态窗口，按 141/132/222/33 顺序内部排列、不显示分类名称，采用四列三行与统一方格比例。开发端已交付，待人工视觉与交互验收。独立 Tools 增量不改变 doc 04 当前阶段、SML-0 暂停状态或生产 Gate。

## 1. 教学合同

老师决定先折哪个面、向哪边折、停在哪个角度，观察后再判断。打开页面不显示“合法展开图”徽标、相对面答案或自动播放步骤，也不挂载原来的合法性选择题面板。

- 右侧形态按钮开关 11 图常驻窗口；桌面与画布并排，窄屏位于画布下方，不覆盖主视觉、不加遮罩或锁定焦点。选图后保持打开，动画中显示原窗口并暂时禁用再次选图。仅显示中性编号，内部按 141（6 种）→132（3 种）→222（1 种）→33（1 种）排序，不显示分类名称。选择区四列三行；缩略图各自横向摆放、不超过三行，共用 6×4 视框与相同方格比例，不随形状单独放大。选择另一种图形时，先逐面展开、放平至 X–Z 桌面，再在纸面内作 90° 转动；相同部分保留原位，字母随方格移动。自由拼图、不能闭合的候选形态另行设计；当前目录仍为 11 种。
- 平面变换沿相邻方格中心或共用顶点，将连接的一侧转动 90°；每步落点保持六个方格连通且不重叠，中间形态可以不属于 11 种展开图。先以广度优先搜索最少转动步数，再在等长路径中最小化实际移动的方格数量；此最小性限于上述变换规则。旋转中允许纸片掠过，是平面拼摆示意，不将其描述成保持所有剪口粘连的物理折叠。
- 默认“折叠纸片”模式中，按住任意面即可拖动，不要求先选面、折痕或底面。连接边按抓取点就近确定；等距时优先带动较少纸片。抓取所在的一侧及其连带纸片转动，另一侧在本次手势内作支撑。按下后显示将移动的纸片与连接边；没有永久固定的 A 面，前次支撑面也可在下次抓取。
- 抓取点沿折痕轴作真实圆周运动，根据当前观察投影求拖动角度；范围仍为 −90°～90°。移除选面按钮组、滑杆和数字快捷落点，只在画布内辅助显示角度。接近 0°／±90° 时松手吸附，其余位置可以停住。
- 单次指针捕获只在松手时写入一步；轻点不折叠也不产生撤销记录。拖动中间帧仅作预览。Esc、失焦、pointercancel 和丢失捕获取消本次操作。折叠模式下拖空白处直接旋转观察，拖纸片时立即暂停相机；松手恢复。显式“观察”仍支持从模型上旋转，“平移”保留独立工具。
- 支持撤销、重做和全部展开。“全部展开”从当前支撑侧向外确定顺序，末端先展开，一次动画只改变一条连接边，跳过已经放平的边；摊平后用刚性动画落至 Y=0 的 X–Z 桌面，保留参考面中心的 X/Z 位置与已有平面朝向。完成后一次提交并可撤销。动画中仍可旋转观察，停止按钮、Esc 或失焦取消预览。按产品负责人明确要求，这些主动教学过程使用 essential 播放，不被系统减少动态效果分支直接跳过；非教学动效仍沿用系统偏好。播放时持续请求 demand 画布帧，停止后恢复按需绘制。最近 100 次操作构成本页撤销窗口，撤销后继续操作形成新分支。
- 第二条路径从完整立方体出发：点击右侧“剪棱展开”，或在图谱窗口选择“立方体 → 展开图”，逐面收成立方体后开始剪棱。进入时保留原纸面取景的空间余量；剪后展开沿用当前取景，避免起动时突然缩放或重置手动视角，仍可通过视角／居中按钮调整。单击可见棱剪开，再点恢复；剪口以玫瑰红虚线标记。拖动仍旋转，背面棱由前面的纸面遮挡，切换观察／平移时保留剪口显示。
- 剪棱过程中逐条检查保留连接的桥边：某侧已可绕一条棱活动，就可以点面独立展开这一侧，即使只剪了三条棱、只展开一个面；包含数学参考面的侧同样可操作。右侧“展开可动部分”优先较小侧、逐条展开当前可动连接。展开后保留纸面位置，继续剪其他棱；已经放平的连接会跳过。六个面分离时提示恢复剪口；已经分开的剪口先撤销展开再恢复。剪口与纸面姿态共同撤销／重做，也可“重新剪”。
- 当保留连接成为五边树且各面均放平时，按实际剪口编译为纸片会话、对齐 X–Z 平面并继续直接拖拽；目录只识别形态，不替换老师的剪法。最后一次动画可以撤销回其开始姿态。返回折叠工具回到进入剪棱前的纸片状态。
- “立方体 → 展开图”路径的右侧提供“移面观察”开关，默认关闭。开启后六个面各有细描边的扁平箭头，沿面中心的外法向留出间距，细引线对应面中心；按钮层完整显示侧后方面的箭头，并作屏幕边界约束与互相避让。点击黄色箭头沿外法向动画移开该面，点击绿色箭头归位，可独立移开多个面。箭头为 48px 原生按钮，支持触摸与键盘，按钮外拖动仍旋转。该模式是观察性分离，不改变剪口与折痕；关闭时各面归位、箭头隐藏，原剪口保留。“全部归位”保留开关开启；如直接要求展开，先归位，再按当前剪口展开。
- 老师点击“判断当前折叠”才出现结果。根据当前几何区分闭合、尚未闭合、重叠或穿插；继续改变角度时清除旧结果。尚未闭合不代表原图不能折。整体正折和整体反折形成的正方体都成立。
- 这是零厚度纸面的几何演示，结果只检查当前姿态，不证明拖动路径全程无碰撞，也不模拟纸张受力或阻挡。
- 复用立方体工作台的 4:3 画布、按钮、面板与布局样式：右上为立体／正视／左视／右视／俯视、重新居中、吸附、坐标轴；右侧为观察、平移、折叠、剪棱、11 种展开图、移面观察、判断、展开、撤销／重做，竖屏沿用底部横排。左上设置面板保留场景切换。原堆叠立方体的切分工具保持原行为。
- 初始纸面平放在 XZ 平面、Y=0。数学内核保留原参考坐标，表现层根据本次支撑面的三个顶点作刚性对齐；换支撑时几何不跳位，其他连接角度不变。两类工作台共用正交相机工厂、Y 向上与取景比例。拖动时取景保持稳定；主动点击视角或重新居中按当前几何重新取景。当前连接边只作辅助提示，不承担点击入口；面标签保持在工具栏之下。

## 2. 数据与接入边界

本地状态为 `cube-net-teaching-v1`：折痕 ID → 相对角度、本次支撑面的定位及撤销／重做历史。角度与定位共同提交、撤销和重做；全部展开将相对角度归零并记录 X–Z 桌面定位，也可撤销。平面切换保留纸片的可见字母与原位部分，目标形态建立新的本地操作历史。剪棱另存本地剪口、各面的刚性位姿及联合撤销历史，全展开成功才接入纸片会话；取消和生成失败保留剪口与位姿。离开页面后重置，当前不提供账号持久保存、录制步骤或课件插入。

移面观察另存开关与逐面偏移；开启时为移动预留取景范围，逐面移动中不重新取景。关闭或离开剪棱路径时清理观察偏移，折痕与剪口状态保持各自合同；观察偏移不进入内核判定或冻结场景。

复用既有拓扑、铰链树和折叠数学内核，新增独立折痕的计算入口；旧全局进度、冻结 `spatial-page-v1`、模板 hash 和课堂 command schema 保持原合同。渲染层只消费内核计算结果，不从 Mesh 推导答案。

`LOCAL_SPATIAL_WORKBENCH_SYNC_PROVIDERS` 显式声明本版本仍需正式空间语义同步；当前本机操作不等同于教师端、展示端、学生端同步。课堂发布与持久化按后续明确批次实施，本增量没有数据库、Storage、生产服务写入。
