# 正方体展开图 · 逐面折叠教学工作台

> 2026-09-14 状态：首版“选面＋滑杆＋外置面板”未获人工验收；产品负责人要求复用已确认的立方体工作台视角与工具布局，并明确选择“点选折痕，直接拖动纸片折起或放下”。本轮已交付该交互的开发端版本，待人工交互与视觉验收。独立 Tools 增量不改变 doc 04 当前阶段、SML-0 暂停状态或生产 Gate。

## 1. 教学合同

老师决定先折哪个面、向哪边折、停在哪个角度，观察后再判断。打开页面不显示“合法展开图”徽标、相对面答案或自动播放步骤，也不挂载原来的合法性选择题面板。

- 首批复用现有 11 种展开图，以中性编号和缩略图选择。自由拼图、不能闭合的候选形态另行设计；当前结果不声称覆盖全部 35 种六连方。
- A 面为固定面。使用右侧“折叠纸片”工具，先点虚线折痕，再拖动高亮纸片。与该面相连的后续纸片一起转动，其他折痕的相对角度保持不变。初始没有预选折痕。
- 抓取点沿折痕轴作真实圆周运动，根据当前观察投影求拖动角度；范围仍为 −90°～90°。移除选面按钮组、滑杆和数字快捷落点，只在画布内辅助显示角度。接近 0°／±90° 时松手吸附，其余位置可以停住。
- 单次指针捕获只在松手时写入一步；拖动中间帧仅作预览。Esc、失焦、pointercancel 和丢失捕获取消本次操作。折叠、观察、平移是独立工具，抓取纸片期间相机手势暂停。
- 支持撤销、重做和全部展开；全部展开也可撤销。最近 100 次操作构成本页撤销窗口，撤销后继续操作形成新分支。
- 老师点击“判断当前折叠”才出现结果。根据当前几何区分闭合、尚未闭合、重叠或穿插；继续改变角度时清除旧结果。尚未闭合不代表原图不能折。整体正折和整体反折形成的正方体都成立。
- 这是零厚度纸面的几何演示，结果只检查当前姿态，不证明拖动路径全程无碰撞，也不模拟纸张受力或阻挡。
- 复用立方体工作台的 4:3 画布、按钮、面板与布局样式：右上为立体／正视／左视／右视／俯视、重新居中、吸附、坐标轴；右侧为观察、平移、折叠、判断、全部展开、撤销／重做，竖屏沿用底部横排。左上形态按钮选择展开图，设置面板保留场景切换。
- 纸面平放在 XZ 平面，固定面位于 Y=0，正折向上；通过刚性坐标变换呈现，数学布局不变。两类工作台共用正交相机工厂、Y 向上与取景比例，不再在“立体观察”时切换透视投影。拖动时取景保持稳定；主动点击视角或重新居中按当前几何重新取景。折痕辅助线叠加在原粗边之后，面标签保持在工具栏之下。

## 2. 数据与接入边界

本地状态为 `cube-net-teaching-v1`：折痕 ID → 相对角度以及撤销／重做历史。切换图形或离开后重置，当前不提供账号持久保存、录制步骤或课件插入。

复用既有拓扑、铰链树和折叠数学内核，新增独立折痕的计算入口；旧全局进度、冻结 `spatial-page-v1`、模板 hash 和课堂 command schema 保持原合同。渲染层只消费内核计算结果，不从 Mesh 推导答案。

`LOCAL_SPATIAL_WORKBENCH_SYNC_PROVIDERS` 显式声明本版本仍需正式空间语义同步；当前本机操作不等同于教师端、展示端、学生端同步。课堂发布与持久化按后续明确批次实施，本增量没有数据库、Storage、生产服务写入。

## 3. 验证与人工验收

定向机器检查覆盖 11 种形态的正反闭合、单折痕作用范围、多折痕连接、任意角度停留、撤销与重做、输入边界、缺失安全上下文 API、旧进度和渲染合同以及课堂同步边界。本轮增加平放／向上折叠、所有折痕的抓取投影反解、已有折叠后的连带纸片展开、俯视方向歧义、落点吸附、指针取消合同与共享真实相机帧循环检查。类型检查、受影响文件 ESLint 与 zh/en 开发页面 HTTP 检查通过；遵循 verify 技能复用已有开发服务，未用浏览器自动化替代人工验收。

- [ ] 选择几个不同形态，点选折痕后分别抓取直接连接的面和连带纸片，确认转动符合直觉。
- [ ] 拖到中间角度停住、折起／放下、撤销与重做；拖动中按 Esc 或移出再松手，检查取消和提交。
- [ ] 一面一面折成正方体，检查结束前不显示答案，点击判断后反映当前形状。
- [ ] 在实际课堂屏幕上检查折痕命中、纸片拖动、观察／平移切换、取景稳定性及横竖屏工具布局。

通过这一批手感验收后，再确定自由拼图／错误形态、固定面选择、备课保存与课堂接入的下一批范围。
