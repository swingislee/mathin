# 立方体结构 · 分组整体旋转

> **状态**：2026-09-19 七个教具现场中的第 6 项开发增量；机器检查与人工验收分别登记，不关闭 R1-Live Gate。
>
> **方向**：老师操作实体、观察变化与重新拼合；不建立题目、答案或判定流程。

## 1. 定位依据

本项属于**立方体结构既有移动能力的补充**。单块、编组、临时多选、切开分组、格点、面染色和录制已经在同一工作台中存在；旋转不创建另一份结构或一个新工具入口。入口放在右侧“移动单位块”的原浮窗内，与轴向移动、拆开展示及合拢并列。

## 2. 教师动作

1. 切开结构，或通过多选／分组确定需要移动的部分。
2. 打开右侧移动工具，用原有拖拽或步数按钮给逻辑排列留出空间。
3. 在“整体转动”中点击 X、Y 或 Z 的正／负 90°按钮，观察整组刚体转动。没有临时选择时作用于当前分组或整体。
4. 继续使用原有逻辑移动拼合；拆开展示偏移可以合拢。体积与表面积始终读取逻辑格，不将展示间隙计入几何。

转轴经过最靠近选择范围中心的单位块中心；同距时按稳定 ID 选锚点。连续转动不会反复舍入中心而漂移，四次同向四分之一圈回到原现场。重叠、非格点、缺失 ID、显示位移超限或逻辑坐标超限时整步保留原现场。

## 3. 实现复用

- `cube-structures-rotation.ts` 提供整数四分之一圈、面方向、面内标记朝向及成对标注留位变换。方块、分组和编号身份保持不变。
- 旋转命令分别保存逻辑轴心 `pivot` 和展示轴心 `displayPivot`。相同展示偏移保持不动；存在不同偏移时，展示实体仍共同围绕一个轴心转动。
- `useCubeDisplayMotion` 延续原拖动预览／松手衔接；旋转使用 650ms 缓入缓出、共同角度和圆弧中心轨迹，不把各方块直线插值穿过中心。
- 从 `VoxelCanvas` 抽出原有 `VoxelGeometry`，静态与转动时使用相同实体、面色、透明度和粗棱边。旋转期间将它和原标注组件放进同一个 Three group；没有另造立方体样式。
- 原拖动控制器、吸附规则、选取与相机手感没有改写。减少动态效果偏好直接落到已提交终点。

## 4. 接入与兼容

- 原 `cube-structures-draft-v3` 及普通默认起点原样保留；`legacyCubeHistorySchema`、`legacyCubeStructureStateSchema` 不接受新字段，也不添加默认字段。
- 首次 `rotate` 明确升级到 `cube-structures-draft-v4`。命令保存 `ids / axis / turn / pivot / displayPivot`；表面标注按需保存 `quarterTurns / laneDirection`。`cubeHistorySchema` 是 v3/v4 显式联合。
- 工作历史、可选录制、撤销／重做、调序／重录和账号草稿复用原通道；恢复只依赖语义状态和命令，不保存动画帧。
- 新课件外层为 `cube-structures-lesson-v3`，公共登记、固定副本与课堂分派由本批共用接入增量维护。旧 lesson-v1/v2 和 projection-v1 不开放旋转；工作台仅在独立入口或宿主明确传入 `allowRotation: true` 时开放。
- 相同课堂快照的重收不会再次播放；新一步、撤销和逐步回放由命令识别共同旋转，晚加入直接显示当前完整现场。原点与其他实例不受影响。

## 5. 窄验证

本项测试覆盖 XYZ 正负方向、四转复原、整数格点、稳定身份、面色、面标记朝向、成对留位、拆开展示与统计隔离、隐藏／展示碰撞、边界失败保持、旧 JSON 严格兼容、新草稿往返、录制与重录、撤销重做、刚体距离不变、动画 hook、减少动态效果与快照重收。并复用原拖动动画、切割显示、历史与教学标注回归。

机器检查不替代人工课堂手感。入口为 [立方体结构](http://192.168.5.213:3130/zh/tools/cube-structures)，待产品负责人验收。

## 6. 剩余边界

- 本次只提供正交轴 ±90°，不加入自由角度旋转、物理拖转或任意旋转支点。
- 旋转是逻辑重排，可能改变接触关系及表面积；拆开展示本身继续保持原逻辑统计。若原逻辑位置受阻，先逻辑移动再转动。
- 校验的是提交终点，动画过程不进行连续刚体碰撞物理模拟。
- 转动中的粗边沿用原实体边线，旋转结束后恢复原隐藏边虚线处理；不改写现有深度 pass 为通用旋转物理渲染器。
- 没有生产／数据库写入、浏览器自动化或正式发布 Gate。公共版本持久化迁移及人工多端教学验收单独登记。
