# 真实截面观察 · 教具功能

> **状态**：2026-09-19 已开发并通过定向几何、组件状态检查；由本批 Tools 集成统一接入备课与课堂，待开发端人工视觉与操作验收。不改变 R1-Live Gate。
>
> **范围来源**：[七个典型教学现场](teaching-spaces-seven-scenes.md) 中的真实截面观察。目的为教师连续操作切平面、展示内部关系，不设置题目、答案、提交或判定。

## 1. 定位

**“立体观察”的一个右侧功能按钮**，不是新的工具，也不是旧立方体结构中整数层拆分的改名。教师需要保留正在观察的实体、尺寸、颜色、摆放和相机，让切平面在同一空间中经过它。

首批支持正方体、长方体、三棱柱和四棱锥。圆柱、圆锥、球在面板中明确显示本批边界，不把有限曲面采样线称为精确截面。

## 2. 教师动作

1. 选中一个支持的立体，点击右侧“截面观察”；打开舞台内的非模态浮窗并显示初始 X–Z 切平面。
2. 选择 X–Z、Y–Z、X–Y 或“斜切”，直接拖动蓝色切平面进行平移，拖动两个边角圆柄倾斜；边上的双向箭头同样可平移。正对切平面时，向上拖动推进切面。数字输入与步进按钮收在“精确调整”中。
3. “完整立体”保留原物体；“移去正侧／移去负侧”将相应半空间平滑淡出，露出高亮截口。再次选择“完整立体”让它恢复。
4. 截口在实体内部持续高亮，旁边的正视图通过同色引线连接实际截口；两处使用同一精确交点，实时同步变化。正视图使用固定比例尺，小截口会实际变小。关闭设置浮窗后仍保留截口、正视图与拖动；隐藏辅助平面后仍可观察截口。
5. “复位切平面”恢复水平居中的切面；工具原来的“恢复备课起点”同时恢复实体和截面设置。

切面作用于当前选中实体；选择别的实体后使用相同切面参数观察它。切平面外的空白仍可旋转视角；点击“旋转视角”工具后，暂停切面拖动并保留截面展示。使用“显示截面”开关恢复完整显示。所有控制和正视图保持在 4:3 舞台中，不增加底部提示行或撑开布局。

## 3. 实现与复用

- `solid-sections.ts` 复用 `getSolidMeshData`、`solidLocalToWorld` 和原有 XYZ 旋转规则，在世界坐标中求真实棱与平面交集；去重、排序及共线处理后生成截口。
- 相切于顶点、相切于棱、与整个面共面、穿过内部和完全不相交分别保留其几何维度；点和线段不产生面积。
- `SolidGeometryScene` 继续使用同一个 `SolidObject` 绘制实体；仅为当前实体启用两个互补半空间，并插值相应半空间的透明度。实体自身的持久透明度、颜色和尺寸不变。
- `SolidSectionOverlay` 绘制切平面、真实截口及边界；不建立新的舞台、相机或物理系统。
- `SolidSectionHandles` 与 `solid-section-drag.ts` 复用轴拖动的屏幕投影与指针捕获边界。平面和圆柄命中才接管主指针手势；空白和右键继续留给相机。Escape、取消、失焦、切换实体和卸载均放弃未确认手势。
- `SolidSectionReadout` 是画布注解，不是设置窗口；同色连接线随截口和相机更新，注解不接管指针。`sectionPlaneBasis` 避免倾斜经过旧参考轴阈值时突然翻转预览。
- 入口和浮窗复用 `CubeIconButton`、`CubeCanvasPanel`；按钮/数字输入复用现有 shadcn 控件。双语文案在该功能目录维护。
- 原 `renderScene`、`renderToolbar`、`renderPanel` 扩展槽保留，供同批测量功能使用。

## 4. 备课与课堂参数

截面属于尚未发布的 `solid-geometry-lesson-v1` 的严格 `section` 对象：

| 参数 | 合同 |
| --- | --- |
| `enabled` | 是否显示截面 |
| `axis` | 基准法线轴 `x/y/z`，默认 `y`，即 X–Z 切平面 |
| `offset` | `-1.2..1.2` 有限数；以当前实体在法线方向的最大投影半径归一，能移过整个实体 |
| `tiltA` / `tiltB` | 围绕另外两坐标轴的角度，范围 `-90..90°` |
| `removedSide` | `none/positive/negative`，正负沿切平面法线划分 |
| `showPlane` | 辅助切平面开关 |

默认关闭截面；本轮原型省略此字段时由严格 schema 补入默认对象。初始场景和课堂快照均保存这些参数，不包含中间显示帧、草稿引用或任意 JSON。

继续通过共用 `useToolSnapshot` 更新；课堂教师只有一个权威写者，每次输入确认或拖动松手只提交一次离散终点。拖动中间帧只作本机预览；教师端在等待确认时保持已拖到的终点，收到相同回显后不重播。展示端仍由权威快照驱动平面/透明动画；晚加入直接显示快照终态。失败时退回已确认现场。拖动、待确认和动画中 `useSceneCapture` 返回空候选，避免备课冻结半途显示。

## 6. 当前边界

- 首批是上述四种凸多面体；一般非凸形体、多重截口、圆锥曲线和球截圆留待单独明确设计。
- 平移/倾斜支持直接拖动与精确数字输入；当前切面仍是单个无限平面的有限辅助显示，不支持弯曲刀面。
- 平视预览只展示截口形状与边数，不自动命名题型或判断学生答案；面积计算供正确性测试和后续测量复用，不在本面板另设成绩或答案。
- 移去一侧是可恢复的观察显示，不创建两个独立可搬动的切割实体。需要拼接切块时应另行设计其稳定 ID 和拓扑合同。
- 和测量的单位块内部展示同时使用时，由共同宿主协调观察模式，避免透明和裁切表现互相覆盖。
