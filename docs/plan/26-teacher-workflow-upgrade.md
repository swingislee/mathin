# Mathin 教师备课生产链升级规划

## 文档目的

本规划用于指导 Mathin 教师端备课工作流升级。

本次升级围绕当前 `/dashboard/sessions/[sessionId]`
课次工作区展开，将课件预览、试做记录、解析记录、标准教案整合为连续生产流程。

目标：

-   教师在课件页面完成试做与板书记录；
-   板书记录直接生成解析材料；
-   教师在教案阶段完成结构化教学设计；
-   教案与当前课次、课件形成绑定；
-   保留上传入口，形成双入口生产模式；
-   继续复用现有审核、revision、材料状态体系。

------------------------------------------------------------------------

# 一、当前实现与设计约束

当前教师备课核心入口：

    /dashboard/sessions/[sessionId]

该页面已经形成课次生命周期：

    课前
     ├── 研读课件与试做
     ├── 形成教案与课堂检查
     └── 磨课、调整并定稿

    课堂
     ├── 点名
     └── 行课

    课后
     └── 复盘

当前页面布局：

    左侧：课前流程与材料任务

    中间：课件目录

    右侧：课件预览工作区

因此：

-   板书属于课件页面能力；
-   教案属于教学设计阶段能力；
-   教案不采用右侧浮窗形式，避免破坏课件预览区域。

------------------------------------------------------------------------

# 三、功能一：课件页面板书系统

## 目标

-   思路分析；
-   页面批注；
-   课堂讲解痕迹。

完成后直接生成解析记录。

-   文件小；
-   可重新渲染；
-   支持未来 AI 分析。

    ↓

    审核
