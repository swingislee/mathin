# Mathin 教师备课生产链升级规划

## 文档目的

本规划用于指导 Mathin 教师端备课工作流升级。

本次升级围绕当前 `/dashboard/sessions/[sessionId]`
课次工作区展开，将课件预览、试做记录、解析记录、标准教案整合为连续生产流程。

目标：

-   教师在课件页面完成试做与板书记录；
-   板书记录直接生成解析材料；
-   教师在教案阶段完成结构化教学设计；
-   教案与当前课次、课件形成绑定；
-   保留上传入口，形成双入口生产模式；
-   继续复用现有审核、revision、材料状态体系。

------------------------------------------------------------------------

# 一、当前实现与设计约束

当前教师备课核心入口：

    /dashboard/sessions/[sessionId]

该页面已经形成课次生命周期：

    课前
     ├── 研读课件与试做
     ├── 形成教案与课堂检查
     └── 磨课、调整并定稿

    课堂
     ├── 点名
     └── 行课

    课后
     └── 复盘

当前页面布局：

    左侧：课前流程与材料任务

    中间：课件目录

    右侧：课件预览工作区

因此：

-   板书属于课件页面能力；
-   教案属于教学设计阶段能力；
-   教案不采用右侧浮窗形式，避免破坏课件预览区域。

## 保存原则

不以图片作为主数据。

保存：

    BoardItem[]

原因：

-   可编辑；
-   文件小；
-   可重新渲染；
-   支持未来 AI 分析。

解析板书直接复用上课教室的 `Toolbar`、`CanvasSurface` 与对象状态合同，不维护独立简化工具栏。图形、颜色、填充、线宽、尺规、撤销、清空和导出随共享工具栏同步升级；后续计算器与函数图像也应先进入这条共享能力链，再由课堂与解析场景共同获得。

公式识别暂不进入当前版本。仓库不保留识别入口、识别服务、部署依赖或公式对象持久化合同；未来若接入自研手写识别库，应重新立项并定义笔画、候选纠错与输出对象的数据迁移。

## 图片输出

解析成品不是脱离课件的空白板书。每条 `board` 解析以稳定 `page_doc_id` 找到对应 `PageDoc`，把该页 4:3 渲染作为底层，再叠加同 revision 的 `BoardItem[]`。教师档案弹窗、审核页预览与 WebP 导出复用同一个合成 DOM；关联页不可用时明确提示并禁用导出，不得退化成空白底图。

展示与导出：

    PageDoc 4:3 + BoardItem[] → 1920 × 1440 WebP

不使用 PNG 作为默认格式。

当前客户端派生质量为 `0.82`；Vector/BoardItem 与 PageDoc 继续作为可编辑权威数据，WebP 只承担审阅与交换。

打印：

单独生成 PDF。

## BlockNote Markdown 语法评估（2026-07-31）

当前锁定的 BlockNote 0.51.4 已内置常用 Markdown 输入规则：块级覆盖 `# ` 标题、`- `/`+ `/`* ` 无序列表、`1. ` 有序列表、`[ ] `/`[x] ` 检查项、`> ` 引用、`---` 分隔线和三反引号代码块；行内覆盖 `**粗体**`、`*斜体*`、`~~删除线~~` 与反引号代码。粘贴 Markdown 会自动解析；`tryParseMarkdownToBlocks` 和 `blocksToMarkdownLossy` 分别提供导入与有损导出，BlockNote JSON 继续作为无损权威存储。

| 范围 | 结论 | 预计工作量 |
| --- | --- | --- |
| 让教师直接使用现有块级与行内快捷语法 | 已具备；只需补一个轻量帮助入口和回归测试 | 0.5 天，低风险 |
| 增加 Markdown 文件/文本导入与导出按钮 | API 已具备；需要覆盖覆盖确认、文件校验和有损能力提示 | 0.5～1 天，中低风险 |
| 增加链接、表格等尚未内置的实时输入语法 | 需自定义 BlockNote/Tiptap input rule，并处理撤销、中文标点和粘贴一致性 | 1～2 天，中风险 |
| 提供 Markdown 源码与可视化编辑双向切换 | 需要解决表格、媒体、嵌套块和未来自定义块的无损往返 | 3～5 天，高风险 |

当前建议先显式告诉教师已经可用的块级与行内快捷语法；若需要交换文件，再增加导入/有损导出。源码双模式不进入 doc 26 当前施工范围。

- 复用 `session_preparation_reviews`、通知和备课质量状态；备课审核队列成为课件侧栏显式入口，审核人将解析/教案与同课次真实课件并排审阅并通过或退回，决定同步教师状态与教案状态；产物入口返回对应备课步骤，所选课件页以稳定 `page_doc_id` 直达编辑位置；待审核教案允许原提交教师显式撤回并恢复草稿。课次新增显式审校人，第一阶段由教师选择并允许本人，队列只对所选审校人与管理员开放；assignment source 同时预留主管指定，切换后教师不可覆盖。上述状态在 R1-Live 是可见的质量信号，不是冻结快照或开课的服务端前置条件；
