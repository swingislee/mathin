## 1. 产品合同

分层计数、遮挡计数、三视图、表面染色、挖空与表面积统一进入 **立方体结构 / Cube Structures**。五项作为同一工作台中的支线起点；选择支线不限制工具能力。长方体尺寸测量与正方体展开图继续独立。

备课与课堂演示使用相同画布、SVG 工具按钮、工具参数与操作模型。按钮改变下一次点击的作用，鼠标与悬浮预览表达当前工具。录制默认关闭，明确开始后，每次确认的场景操作才记录为一步；批量操作仍是一条记录。选中、hover 和相机拖动中间帧属于本地交互态，不逐帧进入教学步骤。

用户已确认：**切开并移开属于拆开展示，原结构体积与表面积保持不变；真正挖除才重新计算。** 后续实现保留逻辑整数坐标与展示位移两层数据，避免把展示间隙误算为新增表面。

## 3. M1 实现合同

- `cube-structures-draft-v3` 是本地 Tools 草稿，不是新的 `CoursewareDoc`。不改写冻结的 `spatial-page-v1`，正式课堂同步 provider 保持 read-only。
- 单位块使用稳定 ID；删除再搭建不复用旧 ID。后续移动、编组和标注以 ID 关联，不以变化后的坐标充当身份。
- 整块底色与六个面的染色分开保存。修改底色保留逐面颜色；“清除面染色”保留底色。染色分类只统计明确染过的面。
- 隐藏层只改变可见集合。数量、内外表面积以及“涂外表面”的几何判定使用完整逻辑结构；隐藏相邻块不把其共用面变成外表面。单面工具可对显露的内部面明确染色。
- 记录包含实际对象 ID、面方向、颜色、层、可见性和视角等参数。批量操作重放目标已物化，不依赖重放时的临时选择。
- 日常撤销历史与教学录制分离。开始录制捕获当前结构；替换已有录制或载入新起点需确认。暂停可自由试操作；继续录制若需恢复已录末步，会明确确认，避免未录动作进入后续依赖。回看不修改当前现场，退出回放后继续自由操作。
- 录制完成后可选择某步，在其前一状态重新执行一次操作替换该步；支持拖动、上下移、移动到指定步和删除。搭建／编组重录保留原对象身份。调序、替换和删除验证整段对象依赖与碰撞，失败保留原记录并提示受影响步。
- 图标工具条全部在 4:3 画布内：横屏右侧竖排、竖屏底部横排；视图条始终右上横排。工具参数面板贴近工具栏展开，横屏位于工具栏内侧、竖屏位于工具栏上方；重复点击当前工具可收起／展开参数。组名条固定画布右下角，工具栏为其预留空间。结构／模板设置仍贴近左上齿轮。观察与平移是独立工具；平移允许鼠标左键或单指操作视野，保留双指缩放。
- 选择后输入名称编组，画布内的组名条选择操作范围。组外块保留；批量染色、移动、显隐及新增块使用当前作用域，新块加入当前组。逻辑移动真实改变几何统计；移动面板明确区分逻辑移动与拆开展示。
- XYZ 层列表使用包括隐藏块的完整作用域，逐层恢复与全部恢复入口保留。层面板非模态，切换观察仍可操作画布。显隐按稳定块 ID 保存，移动后仍能恢复。
- 红 X、绿 Y、蓝 Z 轴及对应字母可开关。原点固定在创建时左后下顶点，初始层从 1 开始；增减、移动和显隐不平移原点。空模型在第一块创建时固定原点。
- 普通边线保留原三维粗边；实验性细线与叠加轮廓已撤下。原棱边替色和面高亮方式已获用户验收；本轮按追加反馈将临时选中的黄色独立于组色，首组默认叶绿。选择面板复用填充色板设置新组颜色，并可明确应用到当前组；只更新组的颜色，保留组 ID、名称、成员和顺序，支持撤销／录制。共享棱边仍去重，宽度、位置和遮挡保持原几何。取消选择恢复当前组色，底色与教学面染色保持不变。新配色手感待人工验收；斜视边宽问题单独保留。
- 本机演示从备课记录复制；临场操作不修改备课。重演备课恢复其初始状态与操作记录。
- 共用原有 Orbit 手动控制及平滑视角切换。染色、显隐、选择不触发相机自动重定位；视角按钮与重新居中明确记录观察操作。书签的 `up` 只定义画面朝向，开始手动手势时统一用世界 Y 轴作为轨道竖直轴；俯视极点保留屏幕方位并使用 Orbit 所需的微小离极偏移，避免俯视后绕转轴变成 −Z。Three/R3F 与场景覆盖层共同动态加载。
- 当前容量为 512 个单位块、256 个录制步骤、各轴坐标 −12～12；日常自由操作滚动保留最近 256 步撤销窗口。全部挖除后可在固定原点高度的地面重新搭建。当前组件内存保存，刷新或离开工作台会丢失；界面明确标注。

## 4. M2 / M3 实现合同

- XYZ 切割沿整数层之间的截面进行，不切碎单位立方体。默认“选层间线”：指向可见面上的内部格线，预览穿过该线的 XYZ 截面并高亮命中线；相邻块两侧命中映射到同一层界，交点附近保留已选轴。可切换“选面朝向”：面中心区域确定法向及内侧最近层界，靠近棱边时不切换到相邻面。点击只锁定预览，在截面旁显示“切割 / 取消”，再点击切割才生成操作；无效点击保留已锁定截面。重新展开参数可微调层界／正负方向，微调时清除旧命中高亮；取消与 Escape 清空锁定，悬浮／锁定／取消不进入录制。沿正／负方向移开 0.5～8 个单位，移开的部分自动编组，可继续切割或移动。本轮选线是单条层间线映射到 XYZ 平面，两条任意共面直线构面仍属于后续可选方式。
- 移动工具的鼠标左键／单指用于轴向移动，不再旋转相机。可拖动 XYZ 箭头，或在面板选轴后拖动实体；单击选单块，拖动沿用当前选择／分组／整体。按当前相机与缩放投影轴向距离，朝向屏幕的轴提示切换立体视角或使用数值按钮。开启右上磁铁后，逻辑移动实时对齐逻辑整数格并保留已有展示位移；拆开展示以被拖动块的实际位置对齐完整单元格，手柄使用首个可见目标块作锚点，整组选用同一位移以保持相对位置。预览与松手提交使用同一吸附终点。关闭吸附时连续预览，松手取整数格（拆开展示为半格）。每次拖动只提交一个既有移动操作；碰撞或超限保持逻辑状态并平滑回位。Escape、指针取消、失焦或切换工具撤销预览。手柄与命中共用世界长度；开始拖动接管未完成的视角动画。非拖动时保留滚轮缩放、右键平移。
- 每块 `displayOffset` 独立于逻辑整数 `position`，以半单位步长调整，各轴偏移限制 ±24。展示实体重叠、超限和无效截面保持原状态并提示。局部合拢发生重叠时保持原状态；整体合拢同时复位全部位移。逻辑几何、外表面染色和统计保持按原结构计算。
- 展示后命中通过展示坐标还原稳定块 ID；相邻面搭建使用原逻辑格并继承该块展示位移。面染色、标记、编号和显隐均跟随同一单位块。重新居中使用包含展示间隙的边界，相机平时仍保持原观察位置。
- 切割、逻辑移动、展示移动、合拢、撤销及步骤重放使用按稳定 ID 插值的平滑过渡，短程约 0.4～0.6 秒、长程最多 0.95 秒。展示层同时插值实体、原粗棱边、面染色和标注，录制只保存确定的终点，不记录中间帧。动画中场景编辑短暂禁用，加载不同起点直接初始化；尊重减少动态效果偏好。
- 圆形、三角形、方形、星形、菱形、十字六种分类符号复用 SVG 路径。支持旁注、点击面和半透明中心；符号和编号可在同块共存，面／中心使用并排留位。中心标注将该块不透明度降至最多 30%，随后可在透明度面板调整。
- 连续编号从 1 开始，记录实际数字与块 ID；重复点击已有编号的块不重复计数。撤销恢复计数器；清除某块编号与“清空全部编号、从 1 开始”分别提供，符号可独立清除。
- 不透明度 0～100% 可逐块或批量应用。滑块使用 1% 精度、44px 高拖动区和 24px 手柄；读数独立即时更新，场景预览每帧至多一次，松手提交一个操作，取消拖动恢复未提交状态。仍可点击单块应用当前值。仅透明度变化时复用原棱边实例，减少无关几何更新。整块底色和逐面染色使用同一不透明度，0% 保留棱边与标注；隐藏依然是独立状态。
- 半透明块使用独立对象中心进行渲染排序。虚线功能启用且存在半透明块时，在更新相机后绘制实体深度 pass，对原棱边材质的被遮挡片段做虚线裁剪；可见片段保留原粗边和选择色。关闭虚线或全部恢复不透明时撤下附加深度 pass。实际像素效果由人工验收，不以 shader 合同测试替代。
- 新工具与现有工具共用备课／本机演示、撤销、独立录制及步骤编辑。切割记录物化两侧对象和新组身份，重录保留组 ID；调序验证几何／对象依赖。正式课堂传输、持久课件、生产部署继续独立。
