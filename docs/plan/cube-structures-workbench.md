## 1. 产品合同

分层计数、遮挡计数、三视图、表面染色、挖空与表面积统一进入 **立方体结构 / Cube Structures**。五项作为同一工作台中的支线起点；选择支线不限制工具能力。长方体尺寸测量与正方体展开图继续独立。

备课与课堂演示使用相同画布、SVG 工具按钮、工具参数与操作模型。按钮改变下一次点击的作用，鼠标与悬浮预览表达当前工具。每次确认的场景操作记录为一步；批量操作仍是一条记录。选中、hover 和相机拖动中间帧属于本地交互态，不逐帧进入教学步骤。

用户已确认：**切开并移开属于拆开展示，原结构体积与表面积保持不变；真正挖除才重新计算。** 后续实现保留逻辑整数坐标与展示位移两层数据，避免把展示间隙误算为新增表面。

## 3. M1 实现合同

- `cube-structures-draft-v1` 是本地 Tools 草稿，不是新的 `CoursewareDoc`。不改写冻结的 `spatial-page-v1`，正式课堂同步 provider 保持 read-only。
- 单位块使用稳定 ID；删除再搭建不复用旧 ID。后续移动、编组和标注以 ID 关联，不以变化后的坐标充当身份。
- 整块底色与六个面的染色分开保存。修改底色保留逐面颜色；“清除面染色”保留底色。染色分类只统计明确染过的面。
- 隐藏层只改变可见集合。数量、内外表面积以及“涂外表面”的几何判定使用完整逻辑结构；隐藏相邻块不把其共用面变成外表面。单面工具可对显露的内部面明确染色。
- 记录包含实际对象 ID、面方向、颜色、层、可见性和视角等参数。批量操作重放目标已物化，不依赖重放时的临时选择。
- 设为录制起点保留当前状态并明确确认清空记录；回看期间可自由观察，继续录制须返回末步或确认替换后续步骤。新起点载入同样明确确认。
- 本机演示从备课记录复制；临场操作不修改备课。重演备课恢复其初始状态与操作记录。
- 共用原有 Orbit 手动控制及平滑视角切换。染色、显隐、选择不触发相机自动重定位；视角按钮与重新居中明确记录观察操作。Three/R3F 与场景覆盖层共同动态加载。
- 当前容量为 512 个单位块、256 步、各轴坐标 −12～12。全部挖除后可在地面重新搭建。当前组件内存保存，刷新或离开工作台会丢失；界面明确标注。
