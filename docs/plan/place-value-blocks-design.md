# 数位积木 · 交互设计稿

> **状态**：2026-09-27 已扩展为 2、3、4、5、7、8、9、10、16 进制及 3～6 个数位，完成进退位动画、双数比较和共用 Tools 接入；开发端待人工视觉与课堂手感验收。机器检查范围见[本次实现记录](../evidence/place-value-first-trial-20260926.md)。
>
> **范围**：独立的数与运算教具，共用已有 3D 舞台与 [Tools 场景接入](prepared-teaching-tools.md)。不改变现有立体工具、生产部署或 R1-Live Gate。

## 1. 核心体验

老师添加真实的单位积木，让学生看到“十个旧单位组成一个新单位”。进位改变分组和摆放，保持单位积木的数量、尺寸、颜色与身份不变；从正面观察数位，从其他角度观察一个计数单位的内部组成。

工具暂名「数位积木」。一个工具内提供「数数与进退位」「两个数比较」两个教学现场；按钮只服务操作，不增加出题、作答、判分或检查点。

| 数位 | 正面看到什么 | 实际空间结构 |
| --- | --- | --- |
| 个位 | 逐个叠高的小方块 | 每块表示一个一，沿 Y 叠高 |
| 十位 | 逐条叠高的端面 | 一条包含十个原单位块，沿 Z 向后伸展 |
| 百位 | 逐串叠高的端面 | 十条十积木首尾连接，一串包含一百个原单位块，沿 Z 向后伸展 |

数位从左到右固定为百、十、个，正面使用正交视角。空数位保留摆放槽；观察角度变化不改变数学归属。每五个单位换一次黄／蓝，在进位和退位时保持原色。十条、百链的前五组正常摆放，第六至第十组反向摆放，让另一端朝前，用积木原有的黄／蓝色辨认五个十、五个百。合百时逐条转向、首尾连接；拆组按原路径回放，颜色始终跟随原积木，不另加端面边带。

百位保留用户提出的真实百块长串，不替换为百格板，也不沿长度方向压缩模型。

以上为十进制示例。其它进制按同一规则满基数进一，各位从左到右按位权递减，标为 `bⁿ … b¹、b⁰`；十六进制数字用 `0–9、A–F`。视觉颜色独立于进制和数位数，固定五黄、五蓝循环；长条每五组切换摆放方向。进位只改变分组，保存的单位颜色相位继续随原成员移动。

## 2. 舞台与按钮

沿用工具页单行身份栏：工具名点击修改；场景操作靠右；窄屏保留有名称提示的 SVG。课件内只显示教具本身。

- 中央：稳定的 4:3 舞台；移除整面网格，前沿按数位数保留摆放槽。已有单位旁提供相应位权单位长的地面标尺；长度文字以单面贴图落在 XZ 平面，随平面投影并接受积木遮挡。俯视／斜上方可见，正面、左右正侧面及下方观察时连同标尺一起收起。
- 顶部视角栏：正面看数位、斜看组成、侧看组成、显示全部、恢复备课视角。自由观察继续复用已有相机；切换视角有可追踪过程。
- 数位下方：数字直接对应本列，可点开输入当前进制的一个数字。每列配轻量 SVG 加减按钮，增减该位的一个单位；不再保留独立「数的写法」框。
- 侧视下数位前沿投影重叠时，数字与标签跟随真实锚点重叠，不再为排开文字改变数位投影位置或顺序。
- 进位：满一组时，在源数位与目标数位之间显示红色「进位」按钮。待进位的最后一层及其后方完整长条临时标红，进位过程继续跟随，完成后恢复原色；原单位颜色数据保持不变。播放期间同一位置成为暂停／继续，不挤动数字、加减或其他数位。
- 右侧：固定的起点配置、比较、拆组、组成查看、显隐、结构与显示设置、撤销／重做和恢复起点。单步与进度条放在组成查看浮窗，数量变化不临时插入工具栏按钮。
- 结构与显示设置从右侧按钮开启同侧共用浮窗，可选进制及 3～6 个数位，不再单独占用左上角。切换保留两边实际数量，超出容量时明确提示，不截断；待进位时先完成进位。相机始终围绕数位前沿的固定中点旋转，保留缩放和显式适合画面；这个舞台关闭视野平移，其他工具保持原行为。

普通点选没有 XYZ 手柄、旋转圆环或常驻对象快捷栏。图标采用现有工具栏的命名与提示方式，参数浮窗提供文字说明与准确设置。图标语义进入共用动作目录；加减一个、合十进位、拆组退位互不借用整体平移的图标。

## 3. 进退位的动作约定

### 3.1 9 → 10

1. 点个位下的「+」，第十块进入个位堆叠；真实数量成为十，但数字先显示竖排的「9」「+1」，十位尚为 0。
2. 保持十块可数的竖排；该数的加减、就地改数、重新摆放与拆组暂时锁定，只开放对应数位的进位操作。视角观察、暂停与显式撤销／恢复保留。
3. 点「进一位」，将这十块作为刚性整体抬起、向后转 90°、移到十位空位并落稳。旋转过程中保持每块可追踪。
4. 数字使用同一动画进度从「9／+1」过渡为十位 1、个位 0，和积木同时结束。完成后正面可见一个端面，转动视角可见完整的十块。

默认手动进位；老师可在设置里开启自动进位。手动状态可以停在满十现场，但先完成进位才继续数数；多个低位同时满十时先处理个位。旧场景和备课中的非规范分组仍可读取，不把每位只能存 0～9 的数字数组作为唯一场景模型。

### 3.2 19 → 20

新形成的十积木落在已有十积木上方；已有十积木不被删除重建。正面出现两个端面，侧面可见两条十积木。

### 3.3 99 → 100

这是两个可分别暂停和撤销的数学动作：

1. 个位十块变为第十条十积木，暂停在「10 个十」。
2. 十条保持各自内部十块的连接，依次移出、首尾相接，形成百位长串；最后得到一个百。

第二段保留十组分界。相机不自动追随、缩放或跳到侧面；老师可在开始前选择侧面，或在过程中暂停后自由观察。完成一串百积木，不意味着强迫显示完整长串；「显示全部」是明确的观察动作。

自动进位下也保留两段及段间短暂停顿。第一段结束仍需进位时，数量操作持续锁定，直到合百完成。取消或恢复使用已知端点，不能留下半个分组；如果需要停在中间观察，用暂停而不是取消。

### 3.4 拆组与减一个

- 「拆一组」优先拆一个十为十个一；当前没有十但有百时，拆一个百为十个十。
- 有个位积木时，「减一个」只移出一块，总数随实际移出改变。
- 个位为空时，「减一个」提示需要拆组，可点「拆一个十」；100 → 99 要先百拆十、再十拆一、最后减一。
- 拆组本身保持总数不变。查看组成与减数分开，避免学生把“拆开”理解为变少。
- 主动拆组及随后的减数用于退位演示，不强制马上合回；再次增加数量或改数形成满十时重新启用进位保护。两数比较时分别保护各自的待进位现场。
- 撤销一步回到上一个数学端点；恢复备课起点回到准备好的完整场景，另设清空到 0 的动作并允许撤销。

进退位中允许暂停和旋转视角，新的数量与分组命令等待该动作结束。未满十的普通加减仅有短入场反馈，支持直接再次加减，不积累隐藏队列；待进位的保护由分组状态决定，动画结束也不会提前解锁。调度结束显式确认展示终点，避免两套时钟的舍入误差遗留忙碌状态；暂停、单步与进度预览继续可用。

## 4. 数字、组成与总数

以“0 个百、9 个十、10 个一”为例：真实数量为 100，数字先对应现场分组，显示百位 0、十位 9、个位「9／+1」。第一段合十后显示十位「9／+1」、个位 0；第二段合百后才完整显示 1、0、0。

- 未进位的一列超过当前进制最大数字时，用「最大数字／+余量」的竖式表达（十进制为「9／+余量」），不能抢先显示归组后的高位数字。
- 进退位的数字与几何读取同一表现进度；暂停、进度预览、课堂回执和晚加入采用相同规则。
- 归组完成后只保留对应数位下的单个数字，不叠加总数或第二份读数框。
- 起点配置可以保存同一个数的不同组成，例如 2 个十、1 个十和 10 个一、20 个一。
- 点击单个数位数字就地输入，改变该列单位数，保留其他列的成员身份；Enter 或失焦确认，Esc 取消。加减、输入、撤销与场景保存使用同一领域状态。
- 隐藏数字只改变可见性；再显示时使用真实组成和当前演示进度。默认积木与数字同时显示。

人工重点检查数字和积木是否在同一时刻完成进位，以及每个可点数字是否清楚对应它上方的数位。

## 5. 看清一百与内部组成

相机能力不通过改变单位尺寸来解决长串：

- 正面看数位：保持各列端面等大，百位深度自然遮挡。
- 斜／侧看组成：看见黄蓝分段、每十组边界与地面长度标尺；绕前沿观察或缩放，旋转支点不转移到长链中央。
- 显示全部：统一缩放整座舞台，保留各方向真实比例；比较模式两边同步缩放。
- 查看一组：选中一条十／百后用细边框标明整体，可逐层拆到低位并重新合拢。没有复制体伪装成原件，也不靠学生记住上次动画。

可移动的观察偏移属于表现数据，不改变分组价值；若后续开放自由摆放，标明原数位归属，并提供归位。首版以合组／拆组的受控动作和共用相机为主，不默认开放容易破坏数位布局的任意拖放。不能把单块拖到十位就让总数增加九。

## 6. 两个数比较

左右各有一套百／十／个地标和数字；单位边长、观察方向、相机缩放与地标间距一致。教师可分别配置数及组成；观察相机默认联动。

提供两个用途，不自动替老师判题：

1. **按数位比较**：在规范分组下，点击百、十、个标题同步强调两边对应数位，依次观察；比较符号由教师选择显示。
2. **同一个数的不同组成**：例如 20 个一与 2 个十；先观察、合组，再发现总数相同。暂未进位时不自动高亮“最高不同位”并推断大小。

起点建议：19 与 20；59 与 61；99 与 100；101 与 110；20 与 20 的不同组成。差距不会因为左右分别自适应大小而被视觉放大或缩小。

## 7. 保存与共用接入

当前支持 3～6 个数位；上限为 `bⁿ−1`，例如十进制六位为 999999，十六进制六位为 FFFFFF（十进制 16777215）。输入使用所选进制，超出容量时明确提示；最高位满额后停止增加，不做截断。旧 `place-value-lesson-v1` 固定副本仍按三位十进制打开和回放，新建场景使用 v2。

场景的权威数据是单位与分组关系：

- 最小单位身份及稳定黄蓝色用连续区间和颜色相位记录；每个高位组包含基数个低位组，成员只归属一个组。记录规模取决于分组和实际编辑产生的区间数，不与大数值本身成正比。
- 各数位已有组及未归组单位；总数从成员推导，不保存可能失配的第二份总数。
- 单数／比较模式、两侧内容、数字及标签可见性、教师选择的比较符号、进位方式、备课视角。
- 语义动作含源组、目标组、开始时间、时长与暂停进度；客户端根据动作重建动画，不把每帧位置写进数据库。

示意中的简单计数结构只用于探索动作；正式接入采用版本化的严格领域合同，防止重复引用、丢块、错误组容量和回执重播。保存起点使用稳定数学端点，允许“十个一待进位”；暂停中间帧作为课堂运行态处理，不伪装成持久分组。

共用层继续负责工具注册、场景库、课件固定副本、实例隔离、课堂权限、语义同步、晚加入和恢复起点。复用空间相机、动作面板、选择退出、动画时钟、姿态插值与触控命中；新增的领域部分限分组守恒、进退位编排与数位展示。浏览器新 ID 使用 `newId()`。

渲染独立小方块的预算固定为整个舞台 2048 个，两数比较平分预算。更长的组改用真实长度长条和程序化分格／黄蓝纹理，远处不可分辨的格线逐渐淡出，靠近重新出现；选择命中仍映射到真实单位。进位、拆组和红色强调共用相同组与区间数据，不因简化而改数、缩短或改变单位边长。每侧最多 2048 个独立组与 4096 个区间；把大数全部散为单个一时明确提示采用数位分组，避免不受控扩张。历史按条数和序列化预算收敛。

## 8. 设计验收与后续实现边界

| 现场 | 要观察的结果 |
| --- | --- |
| 9 加 1，暂停再进位 | 先显示 9／+1；同一条完整躺到十位，数字与积木同时成为一个十 |
| 19 加 1 | 两条十积木叠高，既有十不跳动或换色 |
| 99 加 1 | 分别看到十个一与十个十；百串确有 100 个等大单位 |
| 100 拆开再合拢 | 能追踪十条十积木与其各自十块；总数不变 |
| 20 减 1、100 减 1 | 先退位，最后才减少一；每个动作可撤销 |
| 101、110、200 | 空列及零保留，两个百是两条真百串 |
| 双数比较 | 相同尺度；零占位明确；非规范分组不被误当成大小结论 |
| 中途暂停、换视角、继续 | 对象连续，不因回执重播；相机不自行跳转 |
| 保存待进位现场、插入、课堂操作、恢复 | 组成与可见性可复现；课堂操作不修改备课原稿 |
| 切换二／十六进制与六个数位 | 位权、数字输入、逐级进位与保存使用同一进制；A–F 可就地编辑 |
| 大数长条与侧视 | 长度比例不压缩；标签随真实位置重叠；红色进位入口在两列之间 |

实现使用现有 VoxelModelCanvas／VoxelGeometry、SpatialCameraRig、SpatialViewButtons、SpatialActionButton、SpatialCanvasPanel、useSpatialToolState 和动画调度器。新场景使用 place-value-lesson-v2，旧 v1 通过适配层复用同一工作台并保留原版本回写；备课、插入、课堂权威回显与晚加入走现有 Tools 接口。会话示意中的独立画布未进入正式实现。

本轮人工验收重点仍是进位方向、百串连接节奏、待进位与规范数字的区别、不同视角与 4:3／触屏布局。全部可操作不等于产品负责人已验收，也不表示生产部署或阶段 Gate 已关闭。
