## 五个主阶段

| 标签 | 归类依据 | 常见当前情况 |
| --- | --- | --- |
| 待首联 | 尚无有效首联，也未发生更后续的正式事实 | 尚未联系、未接通、待分配、号码无效 |
| 待测评 | 已有效首联，尚无完成的专业测评结果 | 尚未预约、协调中、已约待测、未到待重约 |
| 待报名 | 已完成测评，尚无正式报名关系 | 测后未报、待回复、考虑中、有意报名、缴费待核实 |
| 待续班 | 至少一项有效的报名或在班关系仍在继续 | 等班、在读、续班考虑中、本轮不续 |
| 历史学员 | 曾有报名关系，当前所有有效课程关系均已结束 | 已退课、课程已结束 |

主阶段互斥，正式课程关系优先于测评和首联事实。单科退课后仍有其他有效课程的学生继续留在待续班；表达不续班但本期仍在读的学生也继续留在待续班。只有退款备注不构成退课事实。已确认但缺少结构化课程结束事实的来源记录继续保留服务状态，待实际业务关系补齐后归类。

测评预约、未到、取消、空测评记录和报名意向均不代替相应完成事实。未到后的重约创建新尝试并保留原记录。阶段归类沿用数据库批量读取；字段筛选先通过既有权限读取器分批获取完整范围，再由共享字段合同生成最终计数、候选和分页。

## 行内登记

- 点击行展开登记，姓名打开既有学生全景。可以单独记情况，或选择首联、测评／活动邀约、报名／续班／重新报名。
- 使用既有登记字段和邀约日历。报名意向保存到课程机会，具有报名权限的员工核实缴费并填写依据后，可调用既有正式报名流程；班级安排继续在分班办理。
- 备注、所选业务安排和回执在同一事务保存。请求 ID 处理重试幂等；邀约保存检查原安排的 ID 与更新时间。
- 保存失败时保留会话草稿。保存成功后保留当前行的位置，更新当前情况并标记“本轮已处理”；支持保存并下一位。刷新名单或切换范围后按正式归类重新加载。
- 回收站沿用原入口。学服过程页和原有学生全景继续承担各自业务记录。
