# 七个立体教具现场 · 开发分工

> 2026-09-19 产品负责人授权七个 agent 分项施工。七项领域实现及共用接入已完成，开发端已交付、待人工视觉与教学手感验收。方向遵循 [可备课数学教具](prepared-teaching-tools.md)，生产阶段与 Gate 保持原状。

## 共同交付结构

每项说明定位与依据、教师现场动作、实现与复用、参数及备课／课堂接入、定向验证、剩余边界。定位从功能按钮、新工具、既有工具补充中选择，不把七项机械地做成七个工具。

统一沿用 4:3 舞台、右上视角、右侧图标工具及非模态浮窗。保存、课件固定副本、课堂单写者与恢复起点使用 Tools 共用接口；教师的拖动与过程观察是教学主体，不增加题目、作答、评分或强制教学流程。

## 集成边界

- 当前并发限额为三个施工 agent，七项分批进入；主 agent 统一处理注册、旧版本兼容、保存校验、消息和最终提交。
- 各 agent 仅修改约定领域文件，新增能力保持小而可独立验证；数学合同与演示限制写清，不将原型或 schema 当成已完成教具。
- 已发布的旧场景保持原数据与解析语义；扩展的折纸与旋转使用明确新版本，不改写历史副本。
- 无生产数据库、Storage 或部署写入。开发端版本校验启用前先按仓库规则核对实际目标。

机器检查与开发端可操作交付分别登记，最终视觉和教学手感由产品负责人验收。

## 首批明确边界

- 自由拼纸为 1–12 格、树状连通方格纸；可折不闭合布局，没有答案判定。闭环、断连、碰撞阻挡与任意多边形不在本批。
- 其它展开支持长方体、等腰三棱柱；曲面展开、其它棱柱／棱锥留待后续。
- 截面支持正方体、长方体、三棱柱、四棱锥；通过按钮和数值调平面，尚无三维切平面抓手，圆柱／圆锥／球截面暂未开放。
- 测量采用抽象单位 u；单位块填充限整数边长 1–6 u、至多 216 块，超限或小数明确提示。测量和截面展示互斥，读数仍指完整原实体。
- 分组转动为正交轴 ±90°，验证终点可放置，不模拟途中物理碰撞。
- 容积比较固定一圆柱与一圆锥，采用受控转移示意而非流体物理；改变尺寸清空容器，改变圆锥朝向先排空再转动。
