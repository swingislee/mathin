# 爱学习单讲增量导入

本入口用于向已配置的课程包补充讲次。HAR 的采集与物化继续由来源仓库执行，任务负责衔接到 Mathin 的目录映射、构建与导入。开发端最终页面由产品负责人验收。

## 执行

在 Mathin 根目录运行：

```powershell
pnpm cw:aixuexi:task --input '<授权 HAR 目录>'
```

默认包是 `2026-gplus-sujiao-math`，默认来源仓库为相邻的 `2026-07_mofaxiao_courseware`。其他包使用 `--package-key`；来源配置可用 `--source-config` 指定，Mathin 的映射配置可用 `--definition` 指定。声明式配置字段见 `scripts/config/aixuexi-packages.json`。存在多目录版本时用 `--catalog-version` 明确版本。

执行前应用 `20260907000500_aixuexi_incremental_source_snapshots.sql`。入口会核对开发环境声明、本机 Supabase origin、Docker endpoint、Windows 监听进程及新增表。目标为本机 `development`；生产晋级继续执行独立授权与目标 preflight。

## 任务合同

- 只读解析 HAR，按正文中的稳定讲次 ID 选择范围。原始 HAR、请求头与凭据不进入 Mathin 产物。
- 将本次观察合入已有来源目录，保留其他年级、讲次和缺失槽位的证据；讲号或课程身份冲突时报告差异。
- 自动执行来源引导、播放器资源、可恢复本地阶段、离线验证、最终导出与本次讲次的版式检查。最终导出显式覆盖既有站点与本次讲次的并集，并保留来源的范围收缩守卫。
- 对源端“队列已前进、仍有本地阶段”的失败继续恢复；相同阶段重复失败或需要额外授权输入时保存失败与下一步动作。
- Mathin 只构建所选讲次。来源真实数量与历史整包基线分开；需要核对历史基线时单独传 `--check-baseline-counts` 给构建器。
- 构建写入独立目录，验证后发布到 `artifacts/<inputFingerprint>`；`latest.json` 指向完整产物。相同输入复用产物，失败目录和上一份完整产物保留。
- 首次导入只接受已有目录中的空讲次。来源包身份保持稳定，新增 manifest 存入不可变快照，并以单讲内容指纹记录导入回执。重复导入相同内容复用既有 release。
- 已有内容发生变化时进入明确的版本升级流程；本入口会报告内容或映射冲突。现有 `--upgrade-source-runtime` 路径保持独立。

## 恢复与范围

任务记录位于 gitignored 的 `.tmp/aixuexi-tasks/<inputFingerprint>/`，包含输入摘要、阶段状态、构建产物和 `mapping.json`。直接重跑原命令即可恢复；已完成的来源阶段会复用，构建重新核对输入指纹，导入重新核对内容回执。

额外的 ITV 捕获、授权 MP4 等仍由来源引擎的 `nextAction` 描述。需要这些输入时，任务保存进度；按来源现行手册完成相应授权阶段后重跑。当前版本已跑通普通 HAR 新讲次，尚未把全部视频分支编排到同一命令。

单独使用原有入口时，构建和批量导入均支持重复的 `--lesson-id` 或逗号分隔的 ID。通过批量导入入口接收新快照时显式传 `--incremental-source`。新构建包含 `source-manifest.json`；旧包继续沿用原有 manifest 漂移守卫。
