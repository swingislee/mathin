## 已接通

- 正式课件、微课共用 `CoursewareCompositionWorkbench` 的插入入口与“编辑教学起点”窗口。
- 内容版本为 `cube-net-lesson-v1`、`dice-lesson-v1`，沿用 `courseware-composition-v1` 文档、网格布局、发布 revision 和共用舞台。
- `spatial-teaching-content.ts` 是 client-safe 严格合同，最大单组件内容 96,000 字节；不导入 Three.js 或空间场景构建器。
- 展开图记录目录来源或剪棱来源、五条折痕角度、支承面的三个顶点、剪开面的刚体位姿、纸片身份、样式、移面状态及预设视角。
- 骰子记录最多 8 个骰子、左右手系、位置和旋转、点数显隐、面样式、0.9 宽移面、最多 128 个滚动足迹与相贴面题目。
- 配置窗口、课件展示均复用 `CubeNetFoldWorkspace` / `DiceTeachingWorkspace`；起点保存等待拖动、透明度预览或教学动画结束，不保存撤销栈、个人草稿指针或逐帧动画。
- 自由轨道镜头、临时透视观察、展开的设置面板属于本机预览；固定起点只保存预设视角及其取景范围。
- 组件内部使用现有 `courseware` 布局模式，外层选择、拖动和缩放继续由组合编辑器负责。

## 开发端人工验收

1. 从现有正式课件或微课编辑页打开“插入工具组件”，分别选择展开图、骰子。
2. 在同一工作台配置起点，等待动作完成后插入。检查组件区域及编辑器句柄；不应出现额外名称框。
3. 保存并重新打开，检查折叠/剪棱、左右手系、点数、标色、透明度、移面和足迹。选中组件后使用“编辑教学起点”，分别检查应用和取消。
4. 发布后修改草稿，确认已发布预览保持原起点。课堂当前仍为只读固定展示。
