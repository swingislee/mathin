# 交互题目编辑器与题目分组

状态：2026-09-25 开发端已更新，待人工视觉与业务验收。数据库变更只应用到本机隔离开发库；生产部署与 R1-Live Gate 分别执行。

## 录题与分组

- 班级详情的“班级作业题号模板”、教研讲次的“本讲作业与标准教案”、具体作业的“编辑作业与课后主题”沿用已有入口。
- 题目表格提供题号、题干、答案、分组及操作列，支持连续录入。在题干或答案按 Ctrl + Enter 添加同组下一题并进入题干；空组可从 6 题或 8 题开始。
- 分组是有顺序的题目集合，例如“基础过关”“能力提升”。同一题只归属一组；可新建、重命名、上移／下移分组，并将题目移入另一组。空分组会保存；未指定的题目在“未分组”中。
- 题干与答案分别打开共享交互题目编辑器，使用原微课编辑器的文字、公式、图形、图片、游戏、单文件 H5 和教具组件。表格显示内容摘要；富文本和互动内容通过画布继续编辑。
- 画布修改即时进入当前作业草稿，返回表格可继续录入；顶部“保存”持久化整份作业。组件上传期间等待上传完成后再切换；保存失败保留草稿。
- 微课也使用“交互题目编辑器”，顶部维护分组，左侧目录按分组排列，当前题目可用“移入分组”调整归属。切换分组先保存当前画布；保存到课次、审核提交作用于整份微课。
- 教研题库绑定及发布后保存独立副本，题干、答案和分组一起复制。教师可保留共同题目并单独调整某位学生的题干。

## 数据与边界

- 继续使用 `courseware-composition-v1`、现有网格、组件 registry 和共用舞台；`InteractiveQuestionEditor` 为同一编辑器实现提供通用入口。
- `homework_documents` 的题目可携带 `composition` 与 `answerComposition`；文本题保持兼容。`groups` 保存分组顺序和空分组，题目保留稳定 ID，原逐题记录继续关联。
- `homework_assets` 保存图片／H5 的稳定资源键及所属班级、讲次或作业。上传先校验业务写入权限；读取使用 RLS 确认可访问资源后生成临时地址。签名地址不写入内容，复制到可访问作业的资源可继续读取。
- 富文本在保存与读取时消毒，游戏与教具经过已有版本合同校验。H5 使用已有隔离展示方式。
- `teacher_microcourse_question_groups` 保存微课分组及版本。分组写入遵循原作者授权与课件锁，冲突时保留当前题目及输入；目录调整同步原页面顺序，冻结课件继续保留原快照。
