# 首联入口与待联系名单

> 更新：2026-09-08。依据产品负责人要求优化首联筛选和名单加载的反馈。
> 状态：开发端已交付，待人工视觉与交互验收。首联草稿与显式保存继续沿用[已验收基线](../plan/school-support-followup-panel-contract.md#10-首联已验收保护基线)。

## 日常使用

1. 打开 `/[locale]/dashboard/followups/communication`，直接进入“待联系”。学服老师默认查看自己的名单；同时具备团队读取和线索分配能力的主管默认查看团队。手动切换后，后续进入保留该范围与每页条数。
2. 从名单展开一个人，按既有方式登记沟通、保存或保存并下一位。分配负责人后，未约定联系时间的线索即可进入名单。
3. 下次联系时间继续作为可选业务安排。逾期与当天提醒优先显示；明天及以后的提醒、未来到访安排可从“按日查看”或“全部名单”查看。有当天回访提醒的人继续进入待联系，即使另有未来到访安排。
4. “沟通记录”按选定日期回看实际登记；“全部名单”用于查找其他当前可见对象。切换视图清除列筛选，保留可见搜索与负责人范围。“清除筛选”可同时清除搜索词和列条件。
5. 联系清单是可选的名单收藏：先勾选，再点“保存联系清单”。清单只包含明确勾选且可操作的记录；使用当天作为清单日期。既有清单从“已存清单”继续使用。

## 首联摘要行

2026-09-08 按产品负责人最新反馈，摘要行收为“姓名、电话、年级、学服、联系情况、最近备注、最近更新”七列，开发端待人工视觉与交互验收。

- 姓名、电话和年级分别显示并筛选，三列总宽由 20rem 缩为 16.75rem；姓名打开学生 360，电话保留拨号入口。学服在独立列显示并筛选。
- 联系情况以主状态和已保存的微信、意向、诺访事实显示小标签。未登记的事实保持空缺；正在填写的草稿用“未保存”圆点提示。
- 最近备注独立显示，最多两行，悬停可读完整内容。摘要行按内容收缩为一至两行高度。
- 点击行、左侧箭头或按 Enter 展开登记；联系结果、沟通方式、备注输入、身份确认及保存操作集中在详情。联系结果平铺为四个按钮，1／2／3／4 选择结果，0 或“清除选择”清除当前结果并保留备注与其他草稿。输入框中的数字继续用于录入；Ctrl／Cmd + Enter 显式保存，收起再展开继续使用同一份草稿。
- 选中结果用底色、描边和勾选共同标注：未接通浅黄、已沟通浅绿、暂缓／下次联系浅蓝、号码无效浅红；清除后恢复普通按钮样式。
- 沟通记录视图继续显示所选日期的实际结果、备注和发生时间，当前状态在展开区对照。

## 读取合同

- 默认队列沿用 `view=unscheduled` 的兼容参数，展示名为“待联系”。缺省、无效视图或缺少有效清单 ID 时返回此队列；明确的 `day`、`records`、`all` 和有效 `worklist` 链接继续可用。
- 负责人范围由既有权限与 RLS 限定。未分配、无效及已转化线索不进入待联系；已关闭或完成报名的活动跟进不进入该队列。仅有测评权限的教师仍可看到分配给自己的待确认邀约。
- 待联系按真实到期提醒优先排序，其余名单保留稳定来源顺序。选定的历史日期不影响待联系队列；日界沿用上海时区。
- 按完整队列筛选、计数，再进行分页，继续支持 20／50／100 条每页。默认进入不加载当日登记汇总；按日查看、沟通记录及既有清单按需读取日汇总。
- 默认队列和全部名单的沟通内容搜索覆盖当前负责人范围内的历史记录，沟通记录视图的内容搜索继续限定在选定日期。
- 新入口使用独立的 `communication-entry-v2` 偏好，保留当前手动选择的负责人范围和每页条数。旧入口隐式保存的“我的”、日期、搜索和列筛选不决定新入口初始名单；显式 URL 条件继续生效。
