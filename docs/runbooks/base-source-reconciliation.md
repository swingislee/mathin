# Base 来源整理与当前阶段

本规则按 2026-09-23 用户确认的五标签和导入边界执行。原始来源行、学生身份、业务经历、当前阶段、查看分组分别保存。

## 来源与增量

- 每份导出保留文件摘要、表 ID、行 ID、字段 ID 和原值。逻辑来源键为表 ID＋行 ID；导出版本变化不表示新增学生或新增电话。
- 首次确认、后续跟进、项目沟通分别投影。相同来源阶段复用已有业务主键；被覆盖的源字段由历史归档保留，无法恢复的多次电话不补造。
- 月份、月日及完整日期保持各自精度。导出日期不写成联系日期。
- Base 更新使用来源差异清单；生产独立新增和人工修订保持原样。来源行消失不代表退课、删除或撤销报名。
- 同名且完整电话一致，可在无既有关联冲突时绑定已有学生。同电话不同姓名、昵称、缺失电话、姓名或年级冲突进入现有资料核对流程。
- 重复获客资料分别留存；当前学生身份和阶段统一，跨学服视图使用同一进度。

## 五个互斥大标签

按正式服务、已结束服务、实际测评结果、有效沟通依次判断：

| 标签 | 依据 |
| --- | --- |
| 待首联 | 尚无有效沟通；连续未接通仍属于此阶段 |
| 待测评 | 已有有效沟通，尚无实际测评结果；包含已约未到、体验课已到但无结果 |
| 待报名 | 有实际测评结果，尚无正式课程报名/入班证据 |
| 待续保 | 有当前正式课程或入班证据；其他历史资料缺失不使其降级 |
| 已停课 | 有已退课、停课或已结束正式课程，且无其他当前正式课程；自然结束显示“课程结束／未续报” |

确认月份/日期与确认人员构成沟通上下文；明确未接通或仅记录失败电话时仍保留失败结果。有效备注、加微、诺访、活动参与及其他阶段的有效沟通共同参与当前展示。后续失败电话不抹去既往成功沟通。

测评等级、学习力等级、实际分数或正式完成的测评报告属于测评结果。单纯到访、班型、家长关注点和普通沟通备注分别保留，不能反推为测评结果。

到访表“已报名”保留为来源报名事实；课程性质和当前服务由其他正式报名、在读、学期资料交叉验证。拟入班信息作为小标签和筛选项显示，不增加正式在读人数。
