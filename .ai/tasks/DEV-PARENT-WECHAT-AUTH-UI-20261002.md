# 小程序微信登录与绑定入口

## 目标与验收

- 用户需要看到可加载的家长数据，并指出微信登录/绑定缺口。本端消费同批提交的微信HTTP合同。
- 账号页提供微信登录；未知身份引导先登录现有账号并明确绑定。已登录账号可查看绑定状态并发起绑定，使用同一账号及亲子权限。
- AppSecret未配置时显示真实未开通状态与密码入口；不模拟微信成功、不伪造绑定或自动新建家庭。
- 双语维护，延续已修复家长页结构与四列布局；登录/绑定后返回原业务页面，密码和临时code及时清理。

## 合同与验证

- 依赖 Next.js 子agent先提交的版本化合同；其唯一维护公共DTO与微信生成副本，本端只消费。
- root在独立worktree实现，Next.js子agent只读复核客户端与合同一致性。
- 定向检查覆盖wx.login失败、配置关闭、绑定引导、密码/会话持久化和登录返回，不追加全量视觉回归。
- 本机API与固定账号由root在主线集成后验证；微信开发工具只确认页面能启动，视觉/真机平台登录需用户验收。
