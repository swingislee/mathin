# 微信绑定与首次登记统一入口

首次扫码进入同一张登记表。已绑定微信且手机号已验证的账号直接填表；手机号账号已登录时，可确认绑定当前微信后填表；已完成登记的账号直接进入小程序。

登记完成以 `miniapp_intakes.completed_at` 为准。老账号已有参与人可直接选择，补填保留原档案及权限。绑定沿用真实会话、账号状态、MFA、身份冲突检查。

开发可验收：微信开发者工具已刷新，发现页运行；登记页为 `pages/onboarding/index`，沿用开发 API `http://192.168.5.213:3130`。登记页保留“已有手机号账号，登录并绑定微信”入口，当前账号的微信归属不一致会阻止继续。

已有参与人补填复用原 ID，仅关联本次登记资料；原档案字段、监护权限和主要家庭关系保持原值。服务端和 SQL 都校验本人或已有监护关系，不按姓名或手机号认领其他参与人。

已通过的机器检查：微信鉴权、开户安全、账号参与关系、客户端会话、提交定位定向用例；参与人复用及原账号保护 SQL（独立事务回滚）；小程序类型检查、登记页与账号页模板编译、相关源码 ESLint。3130 微信能力接口返回 200。全仓类型检查未通过，存在 Supabase、Playwright、Vitest 等依赖声明及既存项目类型错误；本批未扩大到全库修复。

迁移 `20261009180000_miniapp_existing_participant_registration` 已应用到已核对的本机隔离开发库，只替换内部挂接函数，无现有业务档案修改。迁移执行前检查了 origin、3130 监听、Docker 本地端点及数据库指纹。
