# OPS-CLASS-MATERIAL-20261003 · 班级教材更正与配置入口核查

## 目标与验收

- 用户要求将指定教师的三个一年级 A+ 班从 2026 版 E 系列秋季 B 教材调整为同版 A 教材，已逐一确认周五傍晚、周六上午和周六下午三个班均在本次范围。精确标识保留在受控私有清单。
- 用户补充：2026 年暑期、秋季新开班适用新的班型与教材对应，随学生升年级沿用；既有班保留原对应，不能按当前年级或教材年度全量重映射。
- 当前阶段沿用 doc 04 的 R1-Live-2；本任务处理生产反馈，不关闭 Gate。
- 核对管理员现有教材与难度设置入口，记录产品模型及硬编码缺口。本次数据授权不包含发布新增界面、修改全局规则或调整其他班。

## 执行边界

- 只更正清单内班级的教材引用和对应课次的讲次引用；班名、排课、人员、报名、考勤、教案、批注、审核、课程内容及不可变 release 保留。
- 写前核对执行主机、应用实际 Supabase origin、监听 PID/cwd、网关和数据库指纹；使用 `docs/runbooks/r1-write-target-policy.md` 的生产边界。
- 写前保存受控行级备份，执行精确行数与旧值校验；同一事务先演练回滚，独立连接确认零残留后提交，提交后独立只读复核。
- 既有备课不被认定为新教材已完成备课。已有页面批注仍绑定原页面，不能自动迁移其坐标。
- 本任务由一个 Agent 执行，没有并行派工。生产操作为用户明确指定范围内的可回退业务更正，没有 schema、Storage 或服务切换。
