# DEV-PERIMETER-VERTEX-20261004 · 单顶点定量编辑

- 授权与阶段：用户确认下一步及多个平面工具并行深修；补齐上一增量明确保留的逐顶点定量能力，属 doc 04 教具开发轨。
- 用户动作：选中自绘简单多边形，在明确的「定周长调顶点」或「定面积调顶点」操作中直接拖动一个顶点，其余顶点保持。关闭操作后恢复原自由编辑，已有整体拉伸与矩形变方形继续保留。
- 数学合同：固定面积时保持有向面积与绕序；固定周长时两邻边长度和保持，其余边不动。投影到真实约束轨迹，不以包围框或显示舍入作不变量。凹凸、镜像、旋转、共线编辑点均须处理；退化、自交、短边或越界时保留合法状态，不能跳过另一种拓扑把非法路径视为可拖。
- 新操作不新增持久字段、内容版本或跨操作永久锁；合法终点存为既有 v2 几何，只重置改变材料的绕边／拉直进度。矩形单顶点变形按原构造合同转为普通多边形。
- 输入、准确参数（若提供）使用同一终点；只读和非操作态无专用手柄。沿用共用指针取消、阈值、一次提交、撤销及课堂回执，不添加输入原语。
