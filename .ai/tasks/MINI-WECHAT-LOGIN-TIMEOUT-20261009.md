# 小程序开户页微信登录超时

- 用户反馈：刷新小程序“建立家长账号”页后，微信登录不能使用。
- 证据：当前页面显示“连接暂不可用”，客户端记录两次 `request:fail timeout`。本地登录服务、微信配置和真实微信临时码交换正常；原页面点击“重新微信登录”后进入手机号授权，错误清空。最新一次实际登录共 52 秒，其中开发编译 52 秒、业务处理约 350 毫秒，客户端原上限为 20 秒。
- 修复：微信登录/状态和开户提交请求统一等待 60 秒；其他业务请求仍使用原上限。
- 补充诊断：另一次刷新曾在业务处理 22.1 秒后返回 503，暂未复现，未认定该次错误与编译相同。认证入口增加仅开发环境生效的失败步骤/耗时记录，原样保留异常；日志不含身份、URL、凭据或上游原始错误。
- 范围：`apps/parent-wechat/miniprogram/lib/api.ts` 与 `src/features/parent-portal/wechat-server.ts`。不更改凭据、账号绑定、数据库或生产服务。
- 已检查：小程序 TypeScript、受影响服务端 ESLint、17 项原有认证边界用例通过。真实临时码交换、身份读取及开户凭证签发通过。最后完整刷新小程序已进入手机号授权，接口 HTTP 200、业务处理约 299 毫秒。
- 状态：当前开发入口已恢复，机器检查通过。手机号授权及实际开户由本人继续；未替用户提交手机号授权或创建账号。若业务处理期间的 503 再现，可由新增脱敏日志确定具体环节。
