# 微信小程序登录与已有账号绑定接口

## 目标与验收

- 本会话用户指出小程序没有微信登录/绑定，要求让家长能进入真实业务流程；沿用其 Supabase 与 Next.js 子agent同步接口升级指令。
- 新增版本化微信鉴权能力查询、登录和明确绑定现有账号的接口。使用 wx.login code 的官方服务端兑换，沿用现有 custom:wechat identity、UnionID namespace 和唯一 auth.users 主体。
- 未绑定身份只返回需要绑定，不自动创建账号/角色/学生/亲子关系；绑定要求现有账号会话与凭据证明并保持 MFA/停用等原有安全约束。
- 服务端验证 code，限制请求体/频率，敏感认证URL、原始微信错误、身份值和session_key不返回或记日志。
- AppSecret 当前未配置（用户已确认）；缺必要配置时 fail closed，并给客户端可理解的状态。真实微信往返需用户配置后独立验收。

## 合同与交接

- 基线 main e9274eae；先单独提交 contracts/parent-api 与生成微信DTO，告知root消费；随后提交后端实现和有意义的错误、冲突、并发、权限测试。
- 复核者：Supabase子agent负责账号主体和数据权限，root负责HTTP/客户端集成。需要DDL时先提出精确范围，不自行新增表。
- 配置模板只写环境变量与空占位值；不将网站AppID当小程序AppID，不回显用户密钥。
- 复用已有已验证custom OAuth/PKCE实现。影响网站微信共享模块时运行相关回归；正常密码登录保持兼容。

## 环境与状态

- 独立worktree施工；不重启3130，不写数据库或外部身份，不执行生产操作。
- 合同/源码/检查/交接提交分别记录，root集成后验证本机能力关闭、已有密码登录与安全拒绝。
- 机器检查、实际平台配置、真机微信往返和用户体验验收分别报告；正式Gate不涉及。
