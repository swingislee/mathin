# 课次首行直接操作

- 目标：老师无须展开课次详情，就能处理未上课和已上课的核心工作。
- 依据：用户截图中点名、学情修订、课评发布仍在详情；既有首行只有备课与课堂入口。首行最后一列与课次标题距离过远。
- 范围：班级名册中的课次首行；按原服务端能力显示备课、点名、试讲/进入课堂，以及课后的考勤补录、学情课评修订、发布与课后工作区。
- 初次实现：操作紧邻课次标题，在同一行直接显示 SVG 按钮与悬停/焦点提示；移除对应详情内重复主操作。编辑仍按需读取，保存后刷新同课摘要与已打开详情，发布期间保护原草稿和切换位置。
- 检查节点：相关源码 ESLint 与定向 TypeScript；提交前核对本任务暂存范围与凭据检查。普通 UI 增量不运行浏览器、截图或业务测试。
- 验收入口：http://192.168.5.213:3130/zh/dashboard/classes?view=arrange&scope=mine
- 待确认：未上课、正在上课和已上课首行操作的实际可发现性与使用体验；未部署生产。
- 初次检查：8 个变更源码文件 ESLint 与 TypeScript 语法/语义检查通过；复用已有 3130 开发服务，匿名课次入口 HTTP 307 跳转登录。该阶段未执行浏览器、截图、数据库写入、发布课评或课堂业务操作。
- 环境说明：pnpm 包管理器启动时需要下载且网络受限，改用仓库已安装的 ESLint 与 TypeScript 完成相同静态检查；未改动依赖与包管理器配置。
- 当前交付：开发代码可验收，机器检查覆盖源码静态正确性；实际登录后的交互与视觉仍由产品负责人确认。

## 反馈后调整

- 用户反馈推翻了“图标紧邻标题便于操作”的假设：教师难以识别，习惯在行最右侧操作。
- 保留核心操作无需展开课次、既有编辑发布流程及保存保护；改为文字按钮，放到课次行最右侧，窄屏允许换行，发布课评用明确文字表达。
- 用户授权给管理员的班补充测试数据。先核对实际本机数据库、管理员和所属班级，再仅追加明确标记的验收课次及其课堂记录；既有身份、学生、班级关系与历史课次保留。
- 必要检查：两个 UI 文件定向静态检查；数据执行前目标校验及写后数量、状态、关联与原记录保留核对。视觉与业务仍交用户实际验收。
- 开发数据：2026-10-21 在核对主机、监听进程、Docker 本地连接、Supabase origin `http://127.0.0.1:35421` 和数据库标识后，复用写入目标策略，在单个事务中给管理员的 3 个班追加 8 节“按钮验收”课次：已下课 3 节、正在上课 1 节、即将上课 1 节、下周待备课 3 节。
- 示例内容：4 节已开始课次通过既有 RPC 冻结名单与白板课件，包含部分考勤和学情；3 节已下课课次各有 2 条未发布课评。每节课保留未登记项供操作验收，课评未发布。
- 写后核对：管理员身份可以读取全部课次、学生及对应记录，学情编辑读取可用；事务内核对班级、身份、学生、报名和教师关系摘要保持一致。计划与回执只保存在忽略的 `.tmp/lesson-row-actions-20261021/`。
- 当前检查与交付：两个调整文件 ESLint 与相关源码定向 TypeScript 检查通过；开发页面可供人工验收，未运行浏览器或截图，未部署生产。
