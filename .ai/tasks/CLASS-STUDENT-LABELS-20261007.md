# 班级学生 A/B/C/D 标签

- 范围：班级全部学生名册、单班名单（含短期班）共用姓名右上角颜色角标；一名学生在一个班选择 A/B/C/D 之一，可改可清除。
- 产品确认：2026-10-07 用户要求所有人可见；沿用班级名册可见范围，由当前任课老师修改。
- 保存：独立标签表关联正式在班记录，记录最后修改人与时间；不改变学生、在班、学情或续报事实。
- 文件：`student-labels-*`、`StudentLabelControl.tsx`、名册读取和呈现、增量 migration。
- 当前：已实现并安装到本机开发库（迁移 `20261007010000`）；生产未部署，待产品负责人实际使用确认。
- 操作：姓名右上角用小圆形颜色灯表示标签；点击后选择 A（绿）、B（黄）、C（橙）、D（红），或清除。未标记学生对任课老师显示空心圆入口，其他人只显示已设置的颜色灯；悬停和无障碍名称保留具体标签。
- 快捷录入：点击颜色灯，或在班级行按方向键进入学生标签区；A/B/C/D 或 1/2/3/4 保存对应标签，成功后到下一位可编辑学生。←/→ 在同班切换，↑/↓ 到相邻班级最接近当前列的学生；单班纵向名单按学生顺序切换。Delete/Backspace 清除并停留，Esc 退出；最后一位停留，失败保留当前对象。
- 查看学生：单击姓名沿用原有学情 360 入口；标签键盘焦点上的 Enter 和颜色灯菜单的“查看学生”也可打开详情。
- 配色反馈：2026-10-07 按用户要求将 B 改为黄色，角标和选择按钮同步使用黄底深色字；纯样式改动，复用上轮权限与类型检查结果，待实际视觉确认。
- 权限：沿用名单的读取范围，主讲和助教可写；非任课老师、学服和未任教的管理人员只读。归档班级、非在班学生不可修改。标签按在班记录保存，另一班不自动继承。
