# 小程序、Mathin 与 Supabase 配置化重构

- 目标与授权：产品负责人同意 2026-10-12 全面审查与性能建议，要求一并重构小程序、Mathin 后台和 Supabase。开发实现与本地迁移属于本任务；生产部署、小程序上传和提审沿用此前暂缓状态。
- 分支：`main`，当前任务直接推进；保留工作区已有 `.ai/registry.json` 排序与未跟踪资料。
- 负责范围：`contracts/participant-api/`，`apps/parent-wechat/miniprogram/`，`src/features/school/miniapp-settings/`、活动详情、登记表单、诊断预约、联系人及任务／报告编辑入口，`src/features/participant-portal/`，受影响的 `src/features/parent-portal/`，新增 Supabase migration／定向安全用例、数据库类型和合同同步脚本。

## 可独立交付增量

1. 统一小程序设置：草稿、发布、历史恢复、已发布快照；首页／我的入口、品牌、共享字典与前端版本缓存。
2. 活动展示与图片：列表封面／摘要／标签／排序、按活动报名说明；图片压缩、缩略图、校验后缓存与详情恢复。
3. 表单与预约规则：核心身份字段保持，附加问题与回答快照；预约窗口／方式／截止、操作能力由后端执行。
4. 公开文档、联系服务与内容模板：条款版本、帮助文档、服务范围／时间／地址、报告栏目、任务提交要求；对应后台编辑入口与原生展示。

## 交付约束与检查

- 前端使用已有原生模块和稳定业务编号；未知模块可忽略，配置读取失败保留默认可用入口。
- 缓存公开展示配置；身份、参与关系、名额、取消与提交权限继续服务端校验。
- 新增迁移兼容现有发布、表单、申请和历史回答；不删除或重建业务资料。
- 数据库写入前核对实际开发主机、origin、监听进程和数据库目标。按新增 RPC、公开读取与上传风险执行定向权限及兼容检查。
- 每个可操作增量单独提交；开发验收链接使用 `http://192.168.5.213:3130/`。

## 增量 1：统一发布与页面编排

- 已实现 `/zh/dashboard/miniapp-settings`，从机构设置进入：品牌、首页模块、推荐活动、浮动入口、“我的”菜单、阶段名称／分组／排序／显隐、草稿与发布历史恢复。
- 小程序使用原生模块与受限动作；公开配置按 origin 和发布版本缓存，60 秒检查更新，失败时保留默认或上次配置。目录原始数据移出渲染数据，首页仅传当前展示的活动。
- 新增公开文档页，隐私入口复用登记时的服务端条款；条款正文后台编辑仍属于后续增量。
- 新增品牌／首页图片上传：解码与像素限制、去元数据、1600 像素展示图及 480 像素缩略图。图片在条件缓存前校验当前发布可见性，预览继续鉴权且不缓存。原活动详情图片将在增量 2 接入。
- 本机迁移 `20261012150000_miniapp_settings_publications` 已应用。已核对 WhiteHouse、本机 `127.0.0.1:35421`、隔离 Docker 网络与数据库标识；生产未改动。
- 机器检查：定向 SQL 草稿／历史／权限／图片撤回检查通过；图片处理与条件缓存边界检查通过；小程序类型、受影响网站类型、相关 ESLint 通过。只读 HTTP 核对配置 200、默认配置 4808 字节、同版本轻量响应、条件请求 304、未公开图片 404、隐私正文 200。
- 开发入口：`http://192.168.5.213:3130/zh/dashboard/miniapp-settings`。实际页面编排、手机性能与业务体验尚待用户验收；未上传客户端、未提审、未部署生产。

## 增量 2：活动展示与图片

- 详情编辑器加入列表封面／摘要／展示标签／排序，参加须知、提交前提醒与成功指引；同一次发布生效，默认列表封面复用详情封面。
- 活动发布保留历史，恢复时生成新草稿；列表只批量读取当前发布的简短信息，详情正文不随列表下载。
- 活动图片接入解码、压缩、缩略图与条件缓存；旧图片缺少缩略图时回退原图。读取和缓存响应前检查活动是否继续公开，草稿预览仍须员工权限。
- 小程序详情刷新保留已显示内容直到响应，报名前重读详情与当前可申请状态；费用和申请不占名额的业务事实由服务端返回。
- 本机迁移 `20261012160000_miniapp_activity_presentation` 已应用。定向 SQL 覆盖草稿／列表／缩略图访问隔离、版本冲突、恢复后不自动发布、撤下后不可读取；原生与受影响网站类型、相关 ESLint 通过。
- 开发入口为活动“对外展示 / 预报名”与短期课“报名申请”中的小程序详情编辑器。用户尚未验收；生产及小程序上传继续暂缓。

## 增量 3a：登记表单与回答快照

- 默认登记及推广表单支持附加文字、电话、单选和多选问题，沿用现有题目类型；核心身份字段保持原绑定。管理入口为 `/zh/dashboard/promotions`，现在显式保存草稿、发布和恢复历史。
- 首次登记与补充填写保存题目／选项／回答快照，服务端和数据库校验必填、未知选项及未知字段；原登记历史和工作人员微信登记详情可查看回答。
- 阶段显示在后台预览及小程序中复用已发布字典，客户端按稳定编号提交；当前显示字典写入新登记快照。自定义表单文案直接展示。
- 本机迁移 `20261012170000_miniapp_form_questions` 已应用。新增草稿／历史／回答权限 SQL 与原有首次登记、补充登记兼容检查通过，原生及网站相关类型、ESLint 通过；没有运行浏览器或手机验收。

## 增量 3b：活动报名问答

- 活动详情编辑器复用附加问题，随详情一同发布。报名提交同时核对活动版本和详情版本，保存题目、选项与回答；旧请求按原输入重试，不重复创建报名。
- 报名记录及工作人员预报名页按需展开回答，列表仅返回有无回答及可撤回标志，减少列表载荷。读取回答沿用本人／学生与班级范围权限。
- 本机迁移 `20261012180000_miniapp_activity_questions` 已应用。定向 SQL 覆盖必填、过期表单、幂等、历史快照、越权读取、撤回能力；原短期课报名兼容用例通过。原生和受影响网站类型、相关 ESLint 通过。
