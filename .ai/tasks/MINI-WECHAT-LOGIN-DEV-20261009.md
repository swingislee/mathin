# 开发端接通真实小程序微信登录

- 目标：用户填写小程序 AppID / AppSecret 后，接通本机开发端微信登录，交付首次开户入口。
- 范围：`main` 上的 `src/features/parent-portal/onboarding-server.ts`、`tests/wechat-family-onboarding.test.ts` 及本任务登记。运行配置保存在忽略的私有文件中。
- 状态：开发端真实 `wx.login` 已通过微信服务端兑换，应用接口返回 `200 / onboarding_required`。手机号授权、家庭资料提交与真机体验待本人实际验收；生产未部署。

## 已完成

- 核对服务端与开发者工具使用同一小程序 AppID；真实凭据、UnionID 返回及服务端访问令牌获取成功。
- 在已识别的本机隔离 Supabase 启用微信兼容 Auth 与 `custom:wechat` provider，保留原数据库、JWT 配置与精确回调限制。
- 本机 Docker 内新增 HTTPS 桥接服务，Auth 信任其专用本地 CA；桥接只开放 token / userinfo 两条路径，没有发布宿主机端口。开发端小程序继续访问 `http://192.168.5.213:3130`。
- 开启开发端小程序登录与家庭开户配置。网关日志改为仅记录方法、响应码与字节数，避免授权查询参数进入日志。
- 修复开户凭证偶发写入失败：有效期从 15 分钟调整为 14 分钟，为应用与数据库时间偏差留出余量，保留数据库原有 15 分钟限制。

## 实际检查

- 真实微信 code 兑换成功，应用登录返回首次开户凭证；没有代替用户授权手机号、绑定微信或创建正式家庭账号。
- Auth 版本、内部 TLS 证书验证、原生 OAuth provider 与回调地址、PKCE、匿名账号访问拒绝均已核对。
- 固定开发账号密码登录保持原 UUID，账号接口可读，微信绑定数量未变化；检查创建的会话已退出。
- 已有同版本手机号、无邮箱绑定、密码与 MFA 兼容性证据复用；本轮登录安全定向检查通过，凭证有效期修复后的开户用例通过。

## 验收入口与继续工作

在微信开发者工具的小程序打开“我的”，点击头像进入账号面板；如仍保留此前开发账号，先退出登录，再选择“微信登录”。首次微信进入手机号授权，随后填写家庭与孩子资料。手机号能力、真实新账号完成、再次登录及真机流程仍需实际确认。

本机运行配置位于 `.env.local` 和 `.tmp/mathin-supabase-selfhosted/docker-compose.local.yml`。当前 Auth 与桥接服务依赖 `.tmp/mini-wechat-connect-20261009/tls/`，清理临时目录前须先处理该运行依赖。该目录内保留本次脱敏探测脚本和私有配置原件，全部处于 Git 忽略范围；共享文件不记录凭据。

下一业务检查点为本人完成手机号授权后的首次开户与再次登录。后续发布另按明确目标处理。
