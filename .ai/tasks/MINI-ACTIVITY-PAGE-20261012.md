# 小程序活动详情后台编辑

- 需求：在 Mathin 后台调整公益活动详情页的版式、文字和图片，后续内容更新无需每次发布小程序。
- 范围：原活动和已接入小程序的短期课；图文模块、顺序、图片上传、手机预览、保存草稿与发布。报名身份、名额和现有申请流程保持原业务来源。
- 施工：私有图片存储、公开详情仅取发布版本，后台沿用活动或班级管理权限；兼容未配置页面的既有详情。
- 状态：开发端已实现。活动“对外展示 / 预报名 → 小程序详情页”和短期课的“报名申请”页可编辑；入口 http://192.168.5.213:3130/zh/dashboard/activities 。本轮不部署生产、不上传或提审小程序。
- 实现：封面、文字、图片、图文组合；模块上移／下移／移除、图片上／左／右、卡片／连续长页；手机预览、独立草稿、版本冲突提示和发布。新客户端显示发布内容，未配置页及旧客户端保留原文字介绍。报名沿用现有活动／班级业务。
- 数据：迁移 `20261012140000_miniapp_activity_pages` 已应用本机隔离开发库（loopback 35421，Docker 网络与稳定数据库标识已核对）；新增表、图片桶与 RPC，未写生产或改动正式业务对象。图片仅工作人员及当前公开版本可读；类型生成仅合入本任务表和函数。
- 机器检查：Web 相关 TypeScript、小程序 TypeScript、合同同步、相关 ESLint；SQL 回滚事务覆盖活动与短期课发布、草稿隔离、匿名与家长越权、存储读写、跨对象图片、旧版本冲突和关闭展示。开发 HTTP 为空活动目录 200、缺失详情与图片 404；该环境暂无公开可约活动，未做正向 HTTP 或浏览器视觉验收。
- 待确认：真实内容的排版与手机使用体验。首次上线需要后端部署与一次客户端更新；后续已有模块内的内容、图片、顺序、版式从后台更新，新增模块／交互仍需发版。
