# 后台维护活动标签与小程序分类

- 目标：活动分类由 Supabase 保存，在新建和编辑活动时维护；小程序从已发布活动标签生成筛选项。
- 分支：`main`；范围为活动管理、活动发布目录 DTO、小程序分类及新增迁移。
- 当前进度：已实现，迁移已应用本机开发 Supabase `http://127.0.0.1:35421`。新建和编辑活动可填写多个标签、复用已有标签，列表可查看及筛选标签；活动和标签同事务保存于 `activities.tags`。
- 小程序：筛选项从已发布活动标签去重生成；标签更改或移除后刷新目录，失效的已选标签自动清除。旧活动从空标签起步，由工作人员填写；不根据活动名称或类型推断标签。
- 交付入口：`http://192.168.5.213:3130/zh/dashboard/activities`。
- 实际检查：目标核对为本机回环隔离库、3130 Node 开发服务；事务内验证新增、编辑、去重、非法标签不写入、公开课分段保留、公开目录只含已发布活动，以及匿名/无权限写入限制，临时活动均回滚。小程序 TypeScript 与改动业务源码 ESLint 通过；公开活动 API 返回 200，当前开发库没有已发布活动，不能把空返回当作真机标签验收。已触发开发者工具刷新。
- 检查边界：全库 `tsc --noEmit` 出现 `@playwright/test`、`@supabase/supabase-js` 等依赖类型解析及其它大范围错误，未作为通过证据；未开展全库修复或浏览器测试。
- 发布与验收：本次代码及新增字段仅在开发端可用，生产和手机包未更新。产品负责人从活动后台填写标签、发布活动后，在小程序实际验收分类与筛选。
