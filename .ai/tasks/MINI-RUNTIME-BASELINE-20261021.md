# 小程序运行时基础与后台业务流程

目标：一年内大部分业务迭代由 Mathin 后台完成。先交付页面参数、孩子上下文、兼容机制，再完善后台权限与业务流程。开发入口为 `http://192.168.5.213:3130/zh/dashboard/miniapp-runtime`；小程序使用本机微信开发者工具。当前任务未授权生产写入或上传。

依据：页面入口只接收 id、弹层丢弃参数；导航读取未带所选孩子；缓存及迟到请求没有完整区分孩子；服务端仅按组件版本降级，动作与效果缺少统一兼容边界。

范围：隔离页面参数与身份参数，贯穿页面/弹层/局部刷新/表单命令；切换孩子同步导航并丢弃旧上下文响应；动作、效果和表单字段统一按客户端版本降级。已有亲子权限与 RLS 继续生效。

交付检查：小程序类型/编译、受影响源码静态检查；因涉及孩子身份与写入对象，定向检查迟到响应、越权孩子和旧客户端动作边界。通过后立即给出可操作版本；视觉和业务效果由产品负责人验收。

第一批开发可用：页面参数独立贯穿页面、弹层、局部读取、表单与命令；导航按孩子读取，缓存按会话/孩子/对象区分，迟到响应被丢弃；动作/效果/表单字段按客户端能力降级，命令先检查能力版本再执行。后台支持编辑对象参数。明确指定无关联孩子的写入拒绝，缺少孩子摘要时不回退其他孩子。小程序和服务端类型、相关静态及定向检查通过；开发 API r24 的 app/discover 正常；官方工具刷新成功，错误日志无匹配行。未做截图、浏览器或真机验收。

用户补充：后续优先积分兑换、抽取、错题。已有设计要求：学习积分、服务端账本与抽取结果、按孩子累计保底、概率与次数由后台配置；当前只有课堂星星汇总和逐题批改记录，需核对可消费积分与错题的权威来源后接通。新原生能力仍可能需要发版。

第二批：首次页面确定默认孩子时同步刷新导航；后台“谁能看到”增加账号角色，以及“同时满足”“满足任一”的组合编辑。角色取自服务端已验证账号，显示条件不授予业务操作权限。尚未增加班级、业务岗位或标签条件。

第二批交付检查：小程序与服务端类型检查、受影响文件静态检查通过；孩子上下文、旧版兼容和角色组合规则的 14 项定向断言通过。参数编辑按钮改用已有尺寸规格。官方工具刷新并恢复项目窗口后，错误日志查询无匹配行。未进行浏览器、截图或真机验收。

业务接续检查点（2026-10-21）：

- 用户已确认：积分来自课堂星星、独立积分和作业奖励，转换与奖励规则在后台配置。实现默认：规则变更用于后续奖励，历史账本保留原值；具体撤销和历史导入语义在业务实现前核对。
- 兑换和抽取同时支持数字收藏与实物奖品；积分扣减、库存、抽取结果和保底累计由服务端处理。

接续范围：先实现积分账本和奖励规则，再接兑换、抽取及实物领取流程；错题按配置读取既有课上/课后逐题记录。新数据源与命令沿用本轮通用页面、对象参数和客户端兼容机制。优先核对星星撤销、作业奖励唯一来源和学情修订语义，避免重复奖励或把历史记录按新规则重算。需要新增迁移、服务端权限和必要的余额/库存/幂等/亲子隔离检查；本机写入前按数据操作入口识别真实目标。业务域尚未实现，本轮没有业务数据库写入，也没有生产发布或小程序上传。
