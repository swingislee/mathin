# 小程序开发数据与微信登录集成

## 目标与验收

- 用户在本会话要求向 Supabase 插入合适的数据，让小程序可以查看和操作测评预约、情况登记，并补齐微信登录与绑定。
- 归属 doc 04 当前 R1-Live-2 的开发增量；复用现有表和唯一 auth.users 账号主体。沿用用户关于 Supabase 与 Next.js 子 agent 同步升级数据接口的明确要求。
- 开发数据使用固定身份及明确标记的开发业务对象；一名孩子可以新申请，另一名可查看教师回复并确认。公开活动、登记和课表有可加载内容。
- 微信使用真实小程序 code 兑换，绑定已有账号；未配置时说明真实限制，不伪造微信身份或自动创建正式账号。
