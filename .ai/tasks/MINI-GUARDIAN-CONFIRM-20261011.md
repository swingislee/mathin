# 家长主动关联已有孩子

- 范围：学生 360 生成一次性小程序关联码；家长扫码只见部分姓名，主动登录、授权手机号、确认监护关系与隐私说明后，关联已有学生。
- 边界：浏览、扫码和普通登录均不建立监护关系；不按姓名或手机号自动匹配学生，不新建重复孩子。保留工作人员既有角色、资料与权限。
- 开发交付：小程序“我的 → 关联已有孩子”，后台学生 360 标题旁的“关联家长微信”二维码按钮；学生详情监护人页也可生成。一次性关联码七天有效，使用前可撤销，支持输入码及扫码。
- 状态：开发代码与本地迁移已完成；暂不上传 0.1.8、不提审、不部署生产，旧 0.1.7 不含此入口。学生目录：`http://192.168.5.213:3130/zh/dashboard/students`。
- 机器检查：隔离开发库事务验证确认前无关系、部分姓名、过期／撤销、主体隔离、无同手机号自动关联、无重复学生、原账号保留、重试幂等与权限边界；事务夹具均已回滚。迁移已应用本机 `http://127.0.0.1:35421` 对应数据库，生产未操作。
- 代码检查：新后端鉴权与已有登录／首次登记测试通过；小程序扫码、授权、确认、重试和会话隔离测试通过；小程序类型、16 个相关 Web 入口及其依赖的类型检查、修改文件 ESLint 通过。系统 `tsc` 直接运行遇到 Windows 依赖路径解析错误，使用既有 `fs.realpathSync` 编译宿主完成定向类型检查，无错误。开发 HTTP 对无效请求、无效码和失效凭据分别返回 400／404／401 且不缓存。
- 待实际验收：在开发微信工程体验工作人员发码 → 家长先见部分姓名 → 主动授权与确认 → 看到原孩子完整姓名及业务资料；审核与生产发布分别办理。
