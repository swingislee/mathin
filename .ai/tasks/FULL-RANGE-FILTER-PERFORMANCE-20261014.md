# 全量筛选与共享读取性能优化

- 目标：接续“排查线索筛选与权限问题 (2)”的 PG 修复，优化完整可见集合的筛选。产品负责人要求优先从 PG 数据结构、索引和执行计划解决问题。
- 基线：`909949081d811d3dabf836317b90dd2bdeff98f1` 已将沟通摘要重复排序改为一次汇总。本增量只修改两个 PG 读取函数，迁移为 `20261014011000_full_range_filter_performance.sql`。测评专用查询由另一会话独立处理。
- 根因与实现：执行计划低估中间集合行数，分组、学服等唯一主体键关联出现反复扫描；改为一次聚合后按键读取。历史年级先取得本次主体的来源 ID，再解析对应记录；年级基准与学年投影各计算一次。完整字段值按主体键汇总，最终分页前统一排序，去掉重复的宽行排序。
- 已应用：2026-10-14，本机 WhiteHouse 隔离开发库 `127.0.0.1:35421`；迁移账本已记录，函数所有者、执行授权和 security-definer 属性核对一致。生产未部署。
