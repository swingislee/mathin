# DEV-CLASS-MATERIAL-20261003 · 管理员班级教材与对应规则入口

## 目标与验收

- 用户在生产教材更正完成后明确要求“补齐两个入口”：班级设置中的教材与难度，以及课程管理中的班型对应规则。
- 业务班型与教材难度分别保存。规则按实际开班学年、季节、起始年级匹配，不用导入时间、当前年级或教材年度推断新老班。
- 规则修改创建不可变版本。已有班保存采用的版本与实际教材；允许逐班覆盖，并支持按原班设置续建。
- 管理员选择课程后先看到课次影响，确认后原子保存；已开始/冻结、取消/作废课次保持，已有备课资料与待审内容单列。防止陈旧预览覆盖新进展。
- 开发端入口可用、相关权限与事务检查通过后交付人工验收。当前阶段沿用 doc 04 的 R1-Live-2，本次不申请生产发布或 Gate 收口。

## 实现合同

- 对应规则、不可变规则版本、逐班实际配置、变更记录存入数据库，写入口复用现有 `course.manage` / `class.manage` 及班级 scope。
- 新入口位于现有班级设置与课程管理工作区；同时补齐 zh/en、路由登记和服务端输入校验。
- 新建班级消费对应规则并原子保存配置；未知开班批次保持明确手动选择，既有导入匹配保留已确认的班级对应，不再把 A+ 全部推断为 B。
- 普通更新规则不回写旧班；开课和冻结历史、招生报名事实、教案、批注、审核与 immutable release 保留。
- 对有待审/已完成备课的课次优先保留教材；换教材不自动迁移页面批注，不把旧备课认作新教材已完成。
