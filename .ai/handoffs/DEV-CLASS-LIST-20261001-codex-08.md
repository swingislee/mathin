# Dashboard 共用窄屏滚动修复

- 基线：`156688b5`。用户确认上一轮班级修复成功，本轮要求统一处理 Dashboard 子页面的手机页头固定与滚动问题。
- 根因：`DashboardPage` 与 `ObjectWorkspace` 共用的 Chrome 在所有屏宽启用 sticky，标题、状态与多行筛选一起占住视口；班级此前只有局部静态定位例外。学服剩余高度锁定从 48rem 开始生效，部分列表另有限高，造成窄屏双层纵向滚动。
- 共用规则：视口至少 64rem × 36rem 才启用固定页头与学服表内滚动；其他尺寸页头随正文滚动，普通页及 ambient 对象工作区的 Table 取消高度上限。宽表横向滚动、portal 弹层与 internal 编辑工作区保留各自边界。移除班级局部定位例外，主 canvas 明确可收缩高度。业务字段、草稿、保存及权限沿用原实现。
- 无账号静态布局使用实际编译的生产 CSS：总览壳、普通页壳、学服列表壳在手机竖屏、手机横屏、平板、矮屏与桌面五种尺寸下检查。窄屏向下滚动 240px 时页头同步移动 240px，40 行表格自然展开且页尾可达；桌面页头保持原位，学服由表内滚动。内部编辑区及弹层限高保持。
- 定向 Vitest：32 项通过，包含本次修改的共用滚动合同、收起后定位和记录轮廓；同批另有 3 项历史测试失败，原因均为读取已移除的 `dashboard/followups/communication` 或 `dashboard/followups/leads` 路由源码，未涉及本次改动。
- 受影响 TypeScript/TSX 的 ESLint、Tailwind/PostCSS 编译、局部 CSS 解析、差异空白检查通过。未重复运行全库构建或全量 Gate。
- 待集成后进行代表路由的中英文 HTTP 启动检查。实际手机滚动手感与视觉待用户验收；无生产操作或业务数据库写入。
