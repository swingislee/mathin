- `Table mobileLayout="records"` 统一提供手机记录排列、内容宽度、字段标签、空字段隐藏、详情留白、触屏展开目标及整行圆角选中轮廓。`TableCell` 提供 `mobileLabel`、`mobileHidden`、`mobileEmpty`、`mobileSpan` 元数据；使用同一份 DOM、草稿和输入状态。班级、课次、逐生登记和联系记录接入，班级 CSS 移除重复表格规则。普通宽表和矩阵继续默认布局，已验收首联的默认行为保持原样。
- 班级顶部缩短为“我的／全部”，范围、分组及本学期／上学期紧凑横排；手机完整学期选择与日期进入筛选。班级与课次提供直接入口，名册和课次互斥，包括学生深链接默认展开的情况；继续保留未保存草稿保护。
- Dashboard 左上浮动导航按钮补充不透明背景。课前主要操作放到材料之前。
- 课次详情、学情摘要与材料读取在微任务后启动，使开发 Strict Mode 预清理取消的请求在发送前退出；普通重渲染保持请求稳定，实际权限错误、请求失败和离开页面后的取消仍按原语义处理。
