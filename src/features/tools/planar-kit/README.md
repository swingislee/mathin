# 平面教具共用工作台

## 教学边界

老师直接操作材料来呈现关系，保存的是准备好的教具现场。工具不设置标准答案、学生提交或判分。

当前目录以 `catalog.ts` 为唯一教师入口与场景归属权威：22 个独立教具。本批原有 49 个审核现场；图形运动、剪拼和计数等将相近能力组合到各自可构造舞台，活动场景描述符为 39 个，历史描述符继续可读。工程领域目录用于共用数学实现，不决定产品入口。未批准的 11 个现场不随本批开放。

按实际教学用途分组：基本图形认识用于观察边界、边、顶点以及生活轮廓；七巧板用于七块拼摆，二者分别独立。同一教具内的相近能力通过右侧添加材料或开启观察来组合，保留当前图形和操作结果，不以左上角切换整个现场代替。此增量已落实这两个入口；其余原有多现场入口仍需按教学过程逐项核对，不把现有模式选择视为最终交互。

## 新教具如何接入

1. 在合适领域实现纯模型、严格状态校验和 `PlanarSceneDefinition`；在 `scene-registry.ts` 汇入描述符。
2. 在 `catalog.ts` 登记入口、内容版本和场景 ID。工具库、缩略图、独立 `/[locale]/tools/[tool]`、备课适配器、课件选择器和课堂适配由该目录生成；新入口补充双语名称与说明。
3. 起点只保存参数、点位、开关、材料标记和演示进度。新增数学参数或版本同步补 SQL 校验及回滚用例；旧课件版本继续保留。
4. 运行相关合同与手势测试，交付开发链接供人工验收。编辑器和课堂页面不增加工具专用分支。

`PlanarWorkbench` 负责舞台、选择／取消、指针捕获、参数面板、动画、历史、起点恢复与保存接口。各领域只声明材料绘制与数学变换，不重复维护这些宿主能力。

### 可构造材料

`plane-construction` 为基本图形认识与图形运动提供同一份真实多边形／矩形／圆／椭圆模型，材料既可来自教师绘制，也可来自右侧快捷模板。默认关闭名称、边数、顶点数及测量结论；观察是可组合的能力，不是固定讲解文本。

- `construction` 声明绘制工具、草稿预览及完成后的严格几何创建。宿主共用 `usePlanarDrag`，节点轻点、矩形／曲线拖出、多边形逐点闭合；未闭合材料留在本机，不进入备课或课堂状态。`projectPoint` 让吸附后的预览、落点与首点闭合比较使用同一领域坐标。`disabled` 声明领域前置条件，`once` 使剪切／折痕完成后立即回到直接操作。第二触点、捕获丢失、失焦、Esc、关闭面板及权限／外部权威替换撤销草稿。
- `operations` 声明同一对象上的操作面板、准确参数与命令。右侧开启面板不替换图形，`api.operation` 仅控制本机辅助柄；旋转中心、对称轴不常驻。宿主从顶层动作及操作面板动作共同解析语义动画。
- 材料保存真实局部点位、中心、方向及镜像状态，支持独立长宽、半径及编辑点；变换按真实几何计算，不对固定示意图做 CSS 位移。编辑控制点与数学顶点分开，共线新增控制点不额外计边。
- 持久化限 16 个对象、单多边形 32 点、总计 192 点；只接受有面积的简单闭合多边形。矩形保持直角；自由拖其角点时转为自由多边形。圆保持等半径。反射投影的临时仿射基只用于动画帧，不能保存成变形后的数学材料。

### 材料专属数学模型

- `plane-paper` 复用同一构造状态与操作，限制为直边纸片；直线切割生成真实连通片，保留各片原位及总面积。剪刀操作通过 `operation.constructionTool` 启动共用绘制手势，剪后可以直接拖片；边缘轻点选底边，边缘拖动移动整片，窄片也能抓取。
- `plane-paper-folding` 保存真实纸张、多边形／圆形剪口及任意单折轴；折合才可剪，剪口按实际叠层映回原纸。不把双层剪口当作固定四孔模板；重画纸张或折痕先展开并显式收起剪口。
- `plane-tiling` 复用构造纸片与变换，每片保存独立轮廓。不同正多边形按相同边长追加，自绘也可用；直接移动连续，顶点吸附只在松手时落位。
- `plane-network` 共用于图形计数与一笔画，产品入口仍独立。点线可画、挪、删；真实交点拆成连接节点。图形观察沿真实边界，角按顶点与有向射线去重；路径快速跨过同一直线中间节点时补齐实际边链，不替老师选择拐弯路线。上限各 96 点／边，观察最多 24 条、闭合轮廓最多 12 点，路径最多 32 笔／192 次节点访问。
- `plane-perimeter` 使用可构造直边材料及每对象独立绕边／拉直进度。连续拉直保持逐边长度，比较副本共用比例尺，原材料保留；一格 30 舞台单位对应 1 u。矩形可打开定周长或定面积变形：准确尺寸、沿实际边方向的手柄及变为正方形动画共用同一不变量，网格吸附不改写约束。关闭操作后回到普通编辑；存档保存准确几何，操作面板不作为全局持久锁。
- `plane-grid-measure` 为钉板和面积单位提供不同入口。格点多边形可增删点、分成真实三角片；单位方格自由摆放，覆盖按方格并集与真实目标交集计算。领域网格为 40 舞台单位一格，cm/dm 只换读数，不缩放材料。
- `plane-relations` 累加三角形／严格凸四边形，逐对象保存底边、分点及观察，支持真实高、可解除平行约束及对角线。实际分区可以整体复制为独立材料，中点三角形可以搬出复制或逐层原位嵌套；派生点位保持准确，材料容量不足时整次取消。`plane-overlap` 在多个凸直边纸片中显式指定 A/B，计算交并差；差集保留孔和不连通片。二者沿用构造坐标单位，圆弧和其余旧关系动作保留在原 v1。

## 视觉与操作

- 功能按钮、SVG 和浮窗沿用 `spatial-interaction` 的 `SpatialActionButton`、`SpatialActionIcon`、`SpatialCanvasPanel`。优先选已有动作；新增动作先由主任务确认语义归属，再在公共目录登记一次。
- 材料声明在 `PlanarSceneDefinition.materials`，宿主用右侧 `add` 按钮及非模态浮窗加入当前状态；已有对象与观察标记继续保留。观察能力在 `actions` 声明 `active` 及纯状态变化，允许边界、顶点、名称同时开启。按当前材料读取准确值使用 `fields.read`，不复制一份容易过期的选中参数。
- 参数使用公共 Input、Select、Checkbox、Slider；按钮图标保持单一含义。复制用 `duplicate`，镜像用 `mirror`，留影／标记用 `mark`；`record` 留给步骤录制。
- `contextActions` 用当前材料外框和已有 action/operation ID 声明就近入口。宿主复用 `SpatialContextActions`、同一个操作终点、禁用态及对象外避让；无空间时保留右栏。只读隐藏，动画/拖动/发布中禁用，空白和 Esc 只取消本机选择。每条最多五个不同语义图标，避免重复按钮。
- 专用格点由领域按数学单位绘制，并设 `referenceGrid: false` 收起宿主普通参考网格与其开关；显示网格不改变材料的坐标或约束。
- 高通过 `HeightMark` 与 `RightAngleMark` 绘制，倾斜底边及底边延长线也必须是实际垂直关系。标记是清晰直角小方框，不用近似斜线代替。
- 直接抓图形、顶点或可操作材料；点空白／Esc 取消选择。一般状态不覆盖额外移动轴；落位预览只画细虚线，不盖住原材料。
- `usePlanarDrag` 冻结手势起点和屏幕变换，越过阈值才视为拖动。第二触点、失去捕获、窗口失焦和权限撤销取消本地手势。角度连续变化通过 previous 预览跨越 ±180°。
- 输入动作与参数动作使用同一纯数学函数。方向性手势沿实际折轴法向投影，不以固定屏幕横向代替。

## 动画与课堂

课堂只提交动作语义、准确终点和时间锚点，客户端本地重建帧；不逐帧写数据库。`useSpatialDirectCommit` 保留已经展示过的直接手势，回执不重播它。

运动有暂停／继续、准确进度、撤销和恢复备好起点。离散切割进行中可暂停观察，但半条切线不是可保存的数学材料；此时保存及更换参数等待完整停点，仍可继续、撤销或恢复。吸附允许短暂自由点位作为运动起点，终点始终执行领域校验。

保存场景、课件中的固定副本与课堂运行状态彼此独立。删除／修改个人场景不会改动已插入或发布的课件副本；课堂现场操作不会回写备课稿。

`LEGACY_PLANAR_TOOLS` 只保留历史内容与课堂运行合同，不出现在新建课件的工具选择器中。同一个工具 ID 可以有多个版本，场景、快照、适配器和课堂事件须同时按 ID 与版本选合同。基本图形与图形运动新建使用各自 `lesson-v2` 的 `01-create`／`20-create`；原 `plane-pieces-lesson-v1` 的 01／02、`plane-shapes-lesson-v1` 的 `01-basic` 和 `plane-motion-lesson-v1` 的 20／21／22／24 保持可读；七巧板仍使用 `plane-tangram-lesson-v1` 的 02。不静默改写已有副本。

## 范围

在基本图形认识与图形运动的基础上，剪拼、折纸剪纸、镶嵌、图形计数、一笔画新建使用各自 `lesson-v2` 与 `14-create`／`32-create`／`36-create`／`47-create`／`52-create`；旧 v1 与冻结副本保持原模型。

2026-10-02 第二批接入周长、面积单位、钉板、面积关系与重叠五个 `lesson-v2`，对应 `10-create`／`11-create`／`34-create`／`18-create`／`33-create`。当前 22 个新建入口、26 个活动描述符；所有旧 v1 内容按原版本回读。

2026-10-02 后续增量把棋盘覆盖与火柴棒新建切换为 `57-create`／`51-create` 的两个 `lesson-v2`，入口和活动描述符数量不变，旧 57／51 继续按 v1 回读。棋盘为 1～12 行列、最多 72 个两格骨牌；缺格独立编辑，骨牌准确落点不重叠，超出缩小后棋盘的材料移到待用区。待用区拥挤时允许堆放，棋盘覆盖只统计实际铺上的材料。火柴棒最多 96 根等长棒与 96 根独立参考轮廓；快捷组合追加独立材料，空现场、增删复制、端点吸附、连续旋转和老师主动留影共用保存与课堂合同。

后续锁量与面积材料增量沿用上述两个 v2 合同：矩形定量变形、实际分区复制和逐层中点材料都保存为既有准确几何，不新增持久字段或数据库迁移。中点材料相互独立，修改父材料不会自动改变已生成的内层。

其余预设限制按独立增量继续处理：任意多边形锁量、旧面积关系的方格条、共角／内点／共同部分和相似联动等，以及任意凹形／圆弧布尔仍待后续。钟面、圆的滚动及七巧板保留本身必要的材料约束。棋盘仍用两格骨牌，火柴不自动计数图形或判题。当前范围与检查见 `docs/evidence/tools-plane-invariants-20261002.md`、`docs/evidence/tools-plane-cover-match-20261002.md` 和 `docs/evidence/tools-plane-deep-20261002.md`；此前记录见 `docs/evidence/tools-plane-open-materials-20260927.md` 和 `docs/evidence/tools-plane-construction-20260927.md`。机器检查与人工视觉／教学手感验收分开登记。
