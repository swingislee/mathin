# 真实材料上的图形运动

`01-create`（基本图形认识）与 `20-create`（平面图形运动）共用真实多边形、矩形、圆和椭圆。图形分类按材料轮廓判断；共线编辑点不增加数学顶点，椭圆周长继续标明近似。

## 按份数绕点重复

在平面运动的“绕点旋转”面板选择 2～16 的总份数（含原片），再执行生成。所选份数把现有转角设为带原方向的 `360 / n`；任意角度未对应整数份数时，菜单显示待选择，生成动作等待有效份数。

生成保留原片和已有材料，加入 `n - 1` 个独立副本。每片都有自己的真实中心、方向、镜像状态和局部轮廓，修改一片不会改写其它片；不推断或保存副本组关系。16 个对象、每片 32 点、总计 192 点、ID 及坐标范围在生成前整批核对，任一片不合法就保留完整原现场。动画按片沿真实旋转圆弧展开，撤销将该次生成作为一个动作。

## 对应点观察

主动开启“观察变换前后的对应点”，复用原 `ghost` 与 `vertices` 开关：

- 动画／直接手势从真实起点与当前材料配对；未执行时可从当前材料与所开操作的准确目标配对。
- 直边材料按同一真实角点配对，标为 P1／P1′ 等；新增共线编辑点不变成新的数学顶点。
- 圆／椭圆使用中心 O 与材料上的参照点 P、Q，不把曲线参照点称为顶点。
- 连接线表示对应关系，不充当旋转运动轨迹；改变了轮廓或尺寸的两个材料不猜测对应关系。

存档保持真实材料和观察开关，不另存对应点缓存或上一次手势。重新打开后可开启操作观察当前材料的对应目标。

## 操作相关的直接手势

- 常规状态继续直接搬动图形。打开“准确平移”后，手势保留冻结起点供对应点观察；数值按钮按所设位移播放。
- 打开“绕点旋转”后，抓图形或专用转柄绕冻结支点转动，跨越 ±180° 接缝仍连续，可连续多圈。搬动支点是独立操作。
- 打开“沿轴镜像”后，抓图形沿真实折轴法向拖动；沿轴方向的位移不推进翻折。投影经过侧视位置，松手未达一半回到原位、达到一半落到准确镜像；另一侧可以再翻回。轴上或紧靠轴抓取时取材料所在侧及最短手势行程，保持可操作。
- 关闭面板收起该操作的辅助柄并恢复常规拖动，已完成的图形保持。取消恢复起拖现场，松手只提交一次准确终点。

直接手势的冻结起点与投影基只放在本地 `frame*`；严格 v2 校验拒绝这些临时字段。宿主落点路径仅在起点符合原运动合同时播放短吸附，其余直接提交准确终点。翻折中间投影不能作为准确现场保存，暂停按钮动画后可以继续。

本增量沿用 `plane-motion-lesson-v2`，没有新增持久字段或 SQL。基本图形认识及其它复用构造模型的工具保持原操作入口。触摸手感、重叠副本与密集对应点布局由开发页面人工确认。
