# 重叠、圆弧与真实区域

`33-curves` / `plane-overlap-lesson-v4` 将 33/44/45 放到同一舞台。起点是一圆一方，测量、辅助线与原位轮廓关闭；可以追加圆、自由凹凸纸片和圆方／双圆材料，也可自行绘制。原 v1/v2/v3 的保存和领域实现保持独立。

## 材料与操作

- 教师明确指定 A/B，选择交、并、A−B 或 B−A；新增材料保留既有配对。圆保持半径，直边纸片可改顶点与本地宽高；曲边结果只作刚性操作。
- “复制区域为独立纸片”按真实连通分量生成材料，孔留在所属纸片内；原 A/B 显式变为轮廓参照，区域强调关闭。原材料仍可选择、修改或恢复实心显示；已复制的片不跟随源材料变形。
- “叶形两弓片”仅在两圆有两个真实交点时可用，沿公共弦拆出两侧真实圆弓。半径可不同；相切、包含或同圆不产生假弦。为当前圆添加内接／外切正方形后，可以取出实际四弓片／四角片。
- 直线剪开当前材料时，以真实边界替换源材料，保留两侧各个连通片；只清空被剪材料所占的 A/B 槽。切线不穿入内部、容量不足或结果越界时整次保留原现场。
- 各片可继续充当 A/B、复制、移动、旋转、镜像或再次剪开。移开、转动与位置方向复位采用刚性插值，可暂停继续；复位保留当前镜像朝向。原位轮廓只在观察开关开启时出现。

## 几何

边界由有向线段与真实圆弧组成，区域在行进方向左侧；正环包围材料，负环表示孔。线线、线圆与圆圆交点解析计算，交点处分边后按布尔真值选取左右面不同的边，再追踪闭环。重合直边和同圆区间按共同边界处理；孤立相切不会制造有面积交集或把分离面粘成自交纸片。

面积使用局部原点鞋带积分加圆弧的 `r²(θ−sinθ)/2` 修正，小角用稳定级数。周长是实际线长与 `r|θ|`；外框检查弧极值，命中由同一复合 SVG 路径表达孔洞。布尔运算、边界积分和几何校验都不读取像素，不把圆折线化，也不依赖 SVG 蒙版。计算采用浮点解析几何和尺度相关舍入，不是任意精度符号系统。

半平面剪切使用严格包住材料外框的辅助矩形；除真实剪线外，其余三边都在材料之外，不进入结果。计算过程不显示额外教学切线。

## 合同与容量

继续使用六键 `PlanarState`，`phase=0`、`marks=[]`。每片保存局部环的顶点、圆支撑、弧方向、原点、原位及刚性角度／镜像；没有外部源引用或缓存面积。圆的两个半圆端点保持规范形式。1 舞台坐标单位仍为重叠工具的 1 u，参考网格间距为 30 u。

最多 16 份材料、自由直边单片 32 点、全场 192 个边界点／32 个圆支撑／32 个环；每份 `params` 和 `points` 映射仍不超过 256 项。圆弧数量会占用参数预算，因此复杂结果可能先达到编码容量；复制与拆片均整体核对。位置、局部点和圆心在 ±4000，圆半径为 4–1600；自由纸片边至少 1 u、面积大于 1 u²，派生曲片保留可表示的正面积小区域。

`isValidCurveOverlapState` 与 SQL 0312 校验严格字段、支撑圆、闭环、自交与孔洞绕序。`planeOverlapCurvesCases` 提供共用正反夹具，标题按 JavaScript trim 与 UTF-16 长度校验。0312 仅新增三项私有 helper；共享目录／合同／课堂接线、0313 总分发与数据库安装由集成任务完成。
