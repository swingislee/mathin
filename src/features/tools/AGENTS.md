# 教具施工入口

教具提供可编辑材料、可组合操作与有用默认起点。按教学用途组织入口，同一现场的能力延续当前舞台。具体构思见 [教学](../../../docs/workflows/teaching.md)。

## 接入现有实现

- 平面入口在 `planar-kit/catalog.ts` 登记，以领域描述符接入 `PlanarWorkbench`；数学状态、保存和课堂通过同一描述符连接。细节见 [平面工作台](planar-kit/README.md)。
- 工具内容版本在 `courseware/registry.ts` 登记，参数、固定备课内容与恢复起点使用 `scenes/`。新增持久化版本同步服务端与数据库校验，历史冻结内容按原合同可读。
- 共用空间操作见 [spatial-interaction](spatial-interaction/README.md)。相机、手柄、图标、精确步进、对象旁动作与表现层从已有入口扩展；领域提供几何约束、合法落点、计数和序列化。

## 保持操作意图

`useSpatialToolState` 声明面板及拾取方式；命令与显示开关保留自己的状态含义。收起参数后，数学结果与已完成操作继续留在舞台。

选择对象和进入精确变换分别表达。常规拖动、观察、测量和标色保持直接；明确进入移动或旋转时显示对应手柄。对象旁常用动作与右侧完整设置调用相同领域终点。

命中对象或手柄时由相应操作接管指针，空白手势交给相机。直接拖动锁定开始时的平面、支点与目标；常规可移动刚体沿 XZ，明确轴或平面手柄选择其他约束。轻点空白或 Esc 取消选择，空白拖动调整视角；这些动作延续已经形成的数学现场。

`bodyGesture`、`transform-handles`、`object-gesture-controller` 与领域 adapter 承接共用手势。精确落位按工具合法状态吸附，自由姿态按支持它的版本保存。翻滚可复用 `planSpatialRoll`，碰撞、支撑与落点按领域判断。

教学动画保留中间帧，松手提交准确终点；保存、课堂与恢复传递准确状态或语义命令，回执避免重播动作。人工手感由产品负责人在实际设备确认。

普通增量按根入口直接交付。动作语义、图标和工作台绑定分别由 `actions.ts`、`SpatialActionIcon.tsx` 与 `control-inventory.ts` 维护；验证按本次明确任务或重大风险选择。
