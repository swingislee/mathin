# 钉板与面积单位 v2

两个独立教学入口共用数学和材料操作，不引入题目、答案或判分。

- `34-create` / `plane-geoboard-lesson-v2`：围多边形、增删控制点、钉点吸附、内部与边界点、面积关系、底边与高、真实三角分片。
- `11-create` / `plane-measurement-lesson-v2`：画目标，追加、移动、复制、移去单位方格；覆盖是目标与所有方格并集的交集。
- 右侧绘图、材料与观察追加在当前现场。旧 11/34/56 与 v1 描述符由公共目录继续保留，本领域不修改它们。

## 坐标与单位

舞台坐标为 960 × 720；格点原点 `(120,100)`，40 舞台单位对应一格边，点阵范围为 `0…18 × 0…12`。这里的舞台单位不是设备像素，页面缩放不改变数学尺寸。

`unit=0` 读作 u/u²；`unit=1` 把一格读作 1 cm / 1 cm²；`unit=2` 对同一材料读作 0.1 dm / 0.01 dm²。换单位只改变读数，保存点位不变。10 × 10 格目标的面积因而是 100 cm² = 1 dm²。

`referenceGrid=false` 关闭公共 30 舞台单位网格；领域 `lattice` 开关绘制自己的点阵/单位格。`construction.projectPoint` 与创建终点复用 `projectGridPoint`，首点闭合与可见钉点一致。未闭合草稿留在宿主本机。

## 持久化合同

沿用 `PlanarState` 六个精确键。`marks=[]`、`phase=0`；`flags` 为 `GRID_FLAGS` 的精确布尔白名单，其中 `grid=false`。

| 材料 | 参数 | 点位 |
| --- | --- | --- |
| 全局 | `nextId`、`active`、`unit` | 无 |
| 多边形 | `kind.ID=0`、`count.ID`、`base.ID`、`apex.ID`、`split.ID` | 连续的 `v.ID.i`；已分片时有 `part.ID.i` 位移 |
| 单位方格 | `kind.ID=1` | `tile.ID` 为左上角，边长恒为 1 格 |

ID 是规范十进制整数，唯一、小于 `nextId`；`active=-1` 或引用现有材料。最多四个多边形、每个 32 控制点、合计 96 控制点；面积单位最多 100 方格。顶点为简单闭合、正面积边界，钉板另要求整数格点，0.5 格面积合法。相邻边回折、自交、近重复顶点、未知键和幽灵分片均拒绝。

共线控制点留在可编辑边界中，但数学角点、三角分割与分片引用排除它们。`base/apex` 是该多边形内的有效索引。分片只用于钉板，位移有界；准确动画中间帧也是可恢复的真实分片摆放。

`isValidGridMeasureState` 与 SQL 的 `tool_plane_grid_measure_state_is_valid` 对齐。`tool_plane_grid_measure_scene_is_valid` 另检查工具、版本、场景配对以及标题/负载边界。迁移仅追加 helper，集成人接入总分发器。

## 数学与表现

- 方格并集拆成不重叠竖条，再与目标的真实三角剖分逐片裁剪；重复、半格重叠、凹口、部分覆盖与越界不冒充整格覆盖。
- 多个目标分别报告覆盖，避免把互相重叠的不同目标面积相加当作整体并集。
- 钉板拖动显示连续预览，松手提交格点；非法移动保持最近合法预览。编辑顶点与分片操作不会改写原始几何面积。
- 高使用公共 `HeightMark/RightAngleMark`，编辑柄只在编辑操作面板显示；对象旁入口仅声明公共 `contextActions`，与右侧调用同一纯函数。
