# 路线工作台

两个独立教学用途复用 planar-kit 宿主，新增场景 `53-create` / `54-create` 与各自 lesson-v2。旧版 53、54 保持原合同；本目录不负责修改共享版本目录。

## 格点路线

- 教师设置 1～12 列／行、起点 A、终点 B、可选必经点 W 和封闭道路。默认只沿横纵两个方向朝终点前进；可切到四方向，包括绕行及重复经过道路。
- 最多 8 条候选，各自有递增 ID 和连续走访记录；各候选可以复用同一条边。一格边长为 1 u，全部候选合计最多 480 个走访点。添加、复制、切换、退一步、重走、删除均作用于明确候选。
- 缩小格网先把端点收回范围；每条候选从新起点保留有效后缀，到首个失效路段前停止。封路、修改起终点或通行方向采用同一规则。未受影响候选保留，撤销恢复原现场；扩大范围不会凭空补回曾被收起的材料。
- 快拖只补齐共线的中间格点，不替教师选择拐弯。部分路线、尚未到 B 或尚未经过 W 都是合法的探索材料。
- 长度、最短路线和逐点标数由教师主动展开。最短观察用无权 BFS；启用 W 时使用“尚未经过／已经经过”两层状态。标数表示满足条件的最短路线条数，不把四方向绕行产生的无限多条走法说成有限总数。

## 反射路线

- A、B 和线上点 L 使用数学坐标，准确输入范围 ±1000 u；方向角支持 -180°～180°。直接拖动、两点画线和准确字段使用同一几何模型。
- 最多 8 个独立接触点，各自保存相对 L 的沿线有向距离（±5000 u），共享 A、B 与真实无限直线。总长从 A→P→B 实时计算，不保存缓存答案。
- 数学坐标与观察窗分离。“适合画面”及准确点位编辑围绕直线基点取全方向圆包络，因此转轴和镜像不受旧水平范围限制。拖动期间保持起拖观察窗，避免坐标变换跳动；必要时主动适合画面。
- 默认隐藏长度、镜像和最短位置。开启镜像后可播放／暂停翻折；开启最短观察时，同侧点使用镜像推导，对侧点显示直连穿线位置。两点都在线上时显示整段最小值集合，重合点也有明确含义。派生数值显示为近似值。

## 合同与验证

`model.ts` 导出两个状态构造器；`validation.ts` 对每一字段、ID、格点、封路掩码和走访顺序执行严格校验；`scenes.tsx` 导出 `planeRouteScenes`。没有调用浏览器原生 UUID。

SQL `20261004030200_tool_plane_routes.sql` 仅增加私有 state / scene 两个 helper，固定 search_path，并回收 PUBLIC、anon、authenticated 和 service_role 的直接执行权限。共享分发、生成类型和本地 SQL parity／保存回读由本批集成人处理。

`plane-routes.test.ts` 覆盖模型、描述符、显隐、精确端点、撤销和缺少 randomUUID；`plane-routes-integration.test.ts` 在共享接线后验证新建入口、旧版隔离及 `planeRoutesCases()` 保存合同。机器检查不代替人工视觉和教学手感验收。
