# 圆的内外滚动 v2

当前入口为 `55-create` / `plane-rolling-lesson-v2`。同台最多四组独立圆对；可拖出固定圆并建立新圆对，也可追加、复制或移去。旧 `55` / v1 与旧模型保持原义。

固定圆体直接搬动整个圆对，滚动圆体直接绕固定圆滚动。中心、尺寸、内外模式与有符号累计角各自独立。点选底部材料标签可找到重叠的圆对。专用中心／半径手柄仅在相应操作中显示，关闭面板不改变材料或观察。

## 数学与准确操作

- 数学坐标以 u 表示，X 向右、Y 向上，正绕行角逆时针。固定半径 R 和滚动半径 r 支持 0.1–1000 u；外滚接受任意合法半径比，内滚要求 R > r。非法编辑整次保留原状，不偷偷改变另一半径。
- 外滚圆心半径为 R+r，自转角为 `(R+r)/r × θ`；内滚圆心半径为 R−r，自转角为 `−(R−r)/r × θ`。标记点初始位于接触点。圆与接触关系始终从准确参数计算，不存一份独立答案。
- 累计角 θ 为 −100000…100000°，不在 ±180° 或某次播放终点截断。起拖固定原中心、视窗和角度，后续预览用于连续跨圈计角；从零位可以向任意方向开始。达到数值安全边界时保留最近合法帧。
- “本次增加的绕行角”支持 −36000…36000°，相对当前位置播放。返回零位走原路径；插值改变真实累计角，圆心走圆弧、自转按无滑动公式进行。暂停的任意帧都是合法圆对，保存、继续、撤销和课堂回执复用宿主。
- 数字框接受合法小数，不以显示舍入改写模型。固定圆半径手柄取到圆心的真实距离；滚动圆半径手柄沿接触径向编辑并保留固定半径与累计角。中心移动不改变任何角度。

数值、名称、圆心轨道、接触连线与标记轨迹默认关闭；轨道／连线／轨迹逐圆对保存，数值与名称为全局开关。红色标记半径是小圆材料的一部分，便于直接观察自转。轨迹按当前参数从零位到累计角采样，不是过去手势的录制，也不作自动结论；每段绕行与自转角变化均不大于 3°，超过 2048 段则收起采样折线并提示调整，避免混叠成伪轨迹。历史暂缓的 26／35 不作为本次新增教学活动。

## 状态与视窗

`PlanarState` 保持六个精确键；`phase=0`、`marks=[]`。全局参数为 `nextId/active/rollBy/viewX/viewY/viewSpan`；每圆对仅有 `R.ID/r.ID/angle.ID`、`center.ID` 和布尔 `inside.ID/orbit.ID/links.ID/trace.ID`。全局开关为 `grid=false/measures/names`。ID 规范、单调且不复用；最多四组，空舞台合法且 `active=-1`。

圆心限制在 ±1000 u，视窗中心同范围、纵向跨度 1–20000 u。视窗是显示状态：新增、复制、准确改中心／半径／模式后适配所有圆对的完整绕行包围盒；手势中保持冻结映射，必要时按“适配所有圆对”。动画任意朝向都在适配的绕行范围中，不受旧固定舞台半径范围限制。

严格 TS 与 SQL helper 校验相同键、范围、内滚关系和标题 trim／UTF-16 语义；投影、轨迹采样点、DOM 选择与历史不进入存档。新增迁移仅声明私有 helper，目录与总 SQL 分发由集成任务接入。机器检查和人工教学手感验收分别记录。
