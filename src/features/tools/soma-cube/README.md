# 索玛立方体

独立入口为 `/[locale]/tools/soma-cube`。复用立方体画布、相机、移动手柄和浮动面板；每宝保持刚体形状，场景包含任意 1–7 个不同拼块。

## 操作与接入

- 左上切换单块观察、自由拼搭和选块；选块面板支持数量快捷键及逐宝勾选。观察模式保留完整作品，画布只显示选中的一宝。
- 拖动整宝或坐标箭头沿当前轴移动；面板提供每轴 ±1 格和 ±90°。落位检查边界与体积重叠，支持悬空摆放。
- 右侧可分开摆放、设置名称/网格/坐标轴、撤销/重做和恢复起点。选块面板中的 3×3×3 示例由原七宝的合法旋转拼成。
- `soma-cube-lesson-v1` 固定形状、颜色及 24 朝向的编号；5宝/6宝的镜像关系保留。形状或朝向编号变化需要新版本。
- 共用 Tools 场景库、备课组件和课堂状态外壳。拖动中间帧只在本机显示，课堂保存离散终点；失败保留已确认状态，展示端与晚加入端消费相同快照。

定向检查入口：`tests/soma-cube.test.ts`、`tests/soma-cube-workspace.test.ts`、共用编辑器和课堂同步审计。数据库校验由 `20260919000300_soma_cube_tool_scene.sql` 登记，复用 `scripts/prepared-tool-scenes-local.mjs` 的 `soma` 增量与 `soma_cube_scene_assertions.sql`。数据库修改只启用于本机隔离开发目标；产品视觉和操作手感待人工验收。
