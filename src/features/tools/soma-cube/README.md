# 索玛立方体

独立入口为 `/[locale]/tools/soma-cube`。复用立方体画布、相机、移动手柄和浮动面板；每宝保持刚体形状，场景包含任意 1–7 个不同拼块。

## 操作与接入

- 左上切换单块观察、自由拼搭和选块；选块面板支持数量快捷键及逐宝勾选。观察模式保留完整作品，画布只显示选中的一宝。
- 点空白或按 Esc 取消选中，收起高亮、手柄与对象快捷栏；拖空白继续转视角，重选拼块或对象列表恢复操作。清空的是本机操作焦点，备课中的对象、姿态和当前 ID 保持不变。
- XYZ 箭头间的 XZ／XY／YZ 方片可以直接拖动，在明确的标准平面移动；箭头与 ±1 格按钮保留单轴操作。拖整宝固定沿 X-Z 桌面移动，移动面板不再提供旧平面选项或按视角切换设置。灰色平面框移除，保留跟随对象的纵向高度虚线与地面落点。共用规则见 [空间交互](../spatial-interaction/README.md)。
- 点旋转后默认显示世界轴圆环，直接沿对应环转动。七宝复用相同手柄、固定支点和过程预览，没有 1 宝专用分支；环尺寸与轴在起拖时锁定。自由轨迹球在旋转面板中可选，电脑 Shift＋拖拼块也保留。空白位置继续转动视角。
- 旋转绕源模型固定包围中心，按抓取点与屏幕尺寸转动。“旋转吸附（松手时）”提供自由、轻吸附 15°、标准 30°、强吸附 45°，默认标准；切换只影响后续操作，不改变场景或相机。接近合法网格朝向且最近位置放得下时，细虚线提示落点，松手平滑吸附；自由档或不满足条件时保留合法自由姿态。±90° 按钮采用同一落位规则，吸附后可直接翻滚。半格等距落位优先保留同一单元锚点，连续 90° 操作保持可逆。自由姿态的网格是参考面，可转到其下方；超界或实体相交的自由落点回到起点。
- 平移与旋转落位提示共用 `SpatialLandingOutline`：一像素虚线棱边，无填充面、不参与拾取；实体继续连续跟手，虚线仅指示准确终点。
- 沿方向翻滚时，如果凹形拼块缺少底部支撑棱，共用算法以当前世界轴外接长方体的底棱作支撑，细虚线预示虚拟棱。继续保留刚体动画、路径碰撞、准确格点、撤销及课堂终点合同。
- 右侧可分开摆放、设置名称/网格/坐标轴、撤销/重做和恢复起点。选块面板中的 3×3×3 示例由原七宝的合法旋转拼成。
- `soma-cube-lesson-v1` 固定形状、颜色及 24 朝向的编号；5宝/6宝的镜像关系保留。形状或朝向编号变化需要新版本。
- `soma-cube-lesson-v2` 每宝接受互斥的 `{id,position,orientation}` 格点姿态或 `{id,position,quaternion}` 自由姿态。前者 position 是规范化格点最小值，后者是源模型刚体原点；没有两份朝向真相。旧场景打开仍用 v1，用户点击“复制到新版”后才进入 v2。
- 共用 Tools 场景库、备课组件和课堂状态外壳。中间帧本机预览，课堂只保存最终准确姿态；本地末帧保持到回执，失败恢复权威状态，展示端与晚加入读取相同版本快照。撤销、重做、恢复备课起点保留自由姿态。

定向检查入口：`tests/spatial-arcball.test.ts`、`tests/soma-rotation-snap.test.ts`、`tests/soma-free-pose.test.ts`、Soma 领域／工作台／真实 R3F 测试、共用编辑器和课堂同步审计。旧 SQL 保留，v2 由 `20260920160000_soma_free_rotation_scene.sql` 增补，使用 `scripts/prepared-tool-scenes-local.mjs` 的 `soma-free` 增量运行新旧合同及回滚检查。自动吸附复用已有 v2 格点／自由姿态合同，无数据库变更。仅启用于本机隔离开发目标；视觉和手感待人工验收。
