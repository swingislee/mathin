# 三角形、四边形与活动框架

`06-create` / `plane-polygons-lesson-v2` 将获批 06/07/08 放在同一材料舞台。默认有一份任意三角形和一副四杆框架；测量、名称、高与角片均由教师开启。旧 06/07/08 v1 保持原合同。

- 最多 16 份材料：独立小棒、三棒关系、四杆框架、自由三角形/简单凹凸四边形，以及矩形、正方形、平行四边形、菱形、梯形。添加和自绘累积在当前现场；复制和移除只影响所选材料。
- 三棒使用真实边长构造。严格三角不等式成立才围成三角形，等号为共线，失败则显示最小真实间隙；没有假闭合。可以保留整组参照并复制三根独立棒，也可以复制可行的三角形继续拆角。
- 四杆框架有两组等长对边。关节拖动和连续推斜只改变开角，四根杆的长度在全过程保持；长度由尺寸字段或基边定位点明确修改。两侧的自绘关节均保留实际方向。
- 自由三角形及四边形可逐点改形；五种家族的直接手柄和尺寸字段保持其命名约束。梯形上底独立可调，菱形四边等长。明确执行“转为自由四边形”后才解除约束，不用静默改类型接受非法拖动。
- 点边选择当前材料的底，边上拖动仍移动整份材料。每个非底顶点的高均垂直于真实底边所在直线；凹形、斜底和外高使用共用 `HeightMark`。自由四边形不套用错误的“底×高”面积公式。
- 任意三角形可拆出三个真实圆弧角片，原三角形保留。角片可以独立拖动及输入准确位姿，逐片拼角/回原位只作平移与旋转；角度、半径和弧长不变，暂停位置也是可保存的刚性状态。角片展示期间保留原三角形几何，收回角片后继续编辑顶点。

每 40 舞台单位为 1 u，参考网格只辅助定位。材料原点和角片局部中心在 ±4000，自由顶点在局部 ±2400；杆/尺寸为 4–1600，关节开角为 5–175°。自由图形边长至少 4、面积至少 1 舞台单位²，边界允许 1e−8 的计算舍入，拒绝交叉、重复点及共线假顶点。材料整体方向和角片局部方向为 −180–180°；角片插值采用最短刚性旋转，不对弧端点作线性形变。

状态只有六个 `PlanarState` 键，`phase=0`、`marks=[]`。每种材料只保存适用的尺寸字段；角片存在时才有三个中心及方向字段。三棒/框架用 `side=±1` 保留所绘手性。领域校验、SQL 0304 和共享 fixtures 使用同一边界。共享目录接线、SQL 0305 分发及数据库安装由集成任务完成。
