# 周长探究 · 可构造直边材料

`10-create` / `plane-perimeter-lesson-v2` 保存最多 16 张简单凹凸多边形、真实顶点与逐对象绕边／拉直进度。周长沿真实边界计算，边界副本在共同比例尺下保长拉直；原形保持。

## 定周长与定面积拉伸

- 选中矩形或自绘凹凸多边形后，开启“定周长拉伸”或“定面积拉伸”。整体宽高数值与两个方柄共用同一数学终点；保持顶点身份、次序、凹凸结构、材料中心、方向和镜像。
- 矩形沿实际两边联动。其余多边形沿自身本地宽高方向正比例缩放，方向随旋转和镜像，不按屏幕横纵重新选轴；当前局部包围框中心保持不动。
- 定面积令两个轴缩放互为倒数。定周长使用每条真实边缩放后的欧氏长度，单调求解另一轴；包围框只定义拉伸方向与宽高，不作为材料的周长或面积。
- 尺寸先限制到另一轴可解和存档坐标允许的范围；短边、退化或其他几何不合法时，整次保留原状态。网格开关不改写定量结果。只重置被拉伸材料的绕边／拉直进度。
- “变为正方形”仍仅对实际矩形开放，已有动画的每一帧保持对应不变量。普通多边形不改成另一种拓扑或模板。
- 测量主动开启后同时显示真实边长、周长及面积，关闭操作仍保留读数。关闭操作收起方柄并恢复普通编辑；这是一次整体定量操作，不是逐顶点自由拖动的永久锁。

读数使用 30 舞台单位 = 1 u，面积同步除以 30²；与普通构造教具的坐标读数口径区分。保存、撤销、备课固定副本及课堂恢复沿用既有 v2 几何，无新增字段或数据库迁移；旧 v1 现场按原合同读取。视觉与教学手感由产品负责人人工验收。
