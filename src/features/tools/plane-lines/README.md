# 线与角的同台建构

新建场景 `03-create` / `plane-geometry-lesson-v2`，03、04、05 的原 v1 保持读取。一个舞台容纳最多 16 份独立材料；教师添加或画出线、角、量角器与点线/平行关系，不替换其他材料。

打开时提供一份线段与一份斜向角作为可操作起点，名称、度数和比较结论保持关闭。删除所有材料后可从空舞台重新建构。

- 三个控制点和类型是准确状态，垂足、无限延长线、斜线与角弧由几何派生。每 40 舞台单位为 1 u；全部坐标受 ±4000 边界约束，定位边至少长 1 舞台单位。
- 直接抓本体移动整份材料；打开编辑操作才显示定位点。角顶点和量角器中心带材料整体移动，两臂端点可分别定位。准确输入复用同一终点。
- 角读数从第一臂向第二臂按屏幕顺时针取 0–360°；两臂均可自由定向。独立半圆量角器可准确移动、旋转和设置 1–10 u 半径。
- 点线与平行线材料保存基线及外点；第二平行线和垂足随真实方向派生。斜线落点可沿直线自由移动，读数比较真实斜距/垂距。显示由教师主动开启。
- 删除重排内部整数编号，不保存外部引用；旧版起点、课堂、冻结副本不会升级为此状态。宿主统一处理取消、只读、历史和课堂提交。
