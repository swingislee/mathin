# 重叠与区域 · 凸纸片首批

`33-create` / `plane-overlap-lesson-v2` 保留最多 16 张独立凸多边形纸片，单片最多 32 点、总计 192 点。可自绘、加模板、改变各自尺寸、编辑凸轮廓、移动和绕点旋转；同向共线的编辑点不增加数学边数。

选中纸片后明确“作为 A”或“作为 B”，舞台以 A/B 与稳定材料编号标识。不能让同一张纸同时占两槽；添加、复制或移动其它纸片不改变当前配对。移去配对中的纸片只清空该槽，老师再明确选择替代材料。

交集使用真实凸多边形裁切。A−B 按 B 的半平面逐步剥离为互不重叠的凸片；包含产生的孔保持为空白，横穿产生的分离部分分别保留。并集由 B 与 A−B 的不相交片组成。区域用一个无描边复合路径填充，内部计算分片不伪装成新的教学切线。面积来自几何，不从像素或轴对齐包围盒估计。

`pairA`、`pairB` 保存对象引用（缺失为 -1），`region` 保存显示选择（0 原纸片、1 交、2 并、3 A−B）。区域轮廓与面积不重复存档。旧 33/44/45 v1 保持原模型和精确圆弧；此 v2 不支持凹多边形及通用圆弧布尔运算，不把圆离散成无说明的伪多边形。

版本、共用宿主、目录及 SQL 总入口由本批集成人统一接入。领域 helper 只定义严格状态与版本外壳，数据库执行另有授权边界。
