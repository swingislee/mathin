# 重叠与区域 · 凹凸直边纸片

`33-concave` / `plane-overlap-lesson-v3` 在同一材料工作台接受简单凹、凸多边形，仍保留 16 片、单片 32 点、总计 192 点上限。右侧可以添加 L 形、U 形和凸形纸片，或逐点自绘。A/B 由老师明确指定；边界编辑、增删控制点、尺寸、移动、绕点旋转与镜像共用 construction，已有配对不会被新增材料抢走。

计算副本以 ear clipping 保留真实轮廓，所有片统一为正绕序；逐个 B 三角片从 A 的剩余凸计算片剥离，生成内部不相交的交与差，并集由差加 B 构成。线段交点使用解析参数，同次分割内外两侧共享交点。距离容差只有与坐标尺度对应的 IEEE 舍入量，无固定像素、网格或面积阈值；无正面积交集时保持原计算片，避免无意义碎分。同一不可变状态只计算一次。

孔洞和不连通区域在单个无描边 `nonzero` compound path 中保留；计算三角线不作为教学边、剪线或可选材料，不写入存档。镜像的临时压扁帧只显示运动，不将投影形状的面积伪装成材料面积；准确终点恢复区域与读数。该版本不接收自交轮廓或圆弧，不作像素、凸包或圆弧折线近似。

## 历史凸纸片合同

`33-create` / `plane-overlap-lesson-v2` 保留最多 16 张独立凸多边形纸片，单片最多 32 点、总计 192 点。可自绘、加模板、改变各自尺寸、编辑凸轮廓、移动和绕点旋转；同向共线的编辑点不增加数学边数。

选中纸片后打开“观察 A / B 交并差”面板，明确“作为 A”或“作为 B”，舞台以 A/B 与稳定材料编号标识。两项指定动作保留在面板内；对象旁工具条只提供观察面板、编辑、旋转和复制入口。不能让同一张纸同时占两槽；添加、复制或移动其它纸片不改变当前配对。移去配对中的纸片只清空该槽，老师再明确选择替代材料。

测量沿用 construction 的坐标单位：1 u 等于 960×720 SVG 舞台中的一个坐标单位，不是屏幕设备像素，也不是一格。准确宽高、位移、周长和高使用同一单位，面积使用 u²；缩放显示不改变读数。公共参考网格与吸附间距为 30 u，一格面积为 900 u²。

交集使用真实凸多边形裁切。A−B 按 B 的半平面逐步剥离为互不重叠的凸片；包含产生的孔保持为空白，横穿产生的分离部分分别保留。并集由 B 与 A−B 的不相交片组成。区域用一个无描边复合路径填充，内部计算分片不伪装成新的教学切线。面积来自几何，不从像素或轴对齐包围盒估计。

`pairA`、`pairB` 保存对象引用（缺失为 -1），`region` 保存显示选择（0 原纸片、1 交、2 并、3 A−B）。区域轮廓与面积不重复存档。旧 33/44/45 v1 保持原模型和精确圆弧；此 v2 不支持凹多边形及通用圆弧布尔运算，不把圆离散成无说明的伪多边形。

版本、共用宿主、目录及 SQL 总入口由本批集成人统一接入。领域 helper 只定义严格状态与版本外壳，数据库执行另有授权边界。
