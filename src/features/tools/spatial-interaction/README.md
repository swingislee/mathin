# 立体教具共用交互

状态：2026-09-21 开发端增量，待产品负责人实际手感验收。范围是教具空间的操作，不增加题目、提交或判题。

## 功能与图标共用（2026-09-21）

- [功能清单](control-inventory.ts)覆盖 7 个工具入口、9 个操作现场，包含主工具栏、对象旁控件和参数功能。`actions.ts` 是动作名称与 SVG 语义的权威；`SpatialActionIcon` 唯一实现图形。`SpatialActionButton` 组合原有 shadcn 按钮，不复制按钮样式。
- 对照页从实际组件与工作台绑定生成：`node scripts/spatial-controls-catalog.mjs` → `.tmp/spatial-controls-comparison.html`。同时列出旧图／新图、各舞台功能及所用图标、全部动作与视角／轴／标记参数图形。
- 整体移动用三轴箭头；移面用纸面向外移出的立方体。对象旋转、视角旋转、视角平移各自独立。展开使用展开符号，复原保留回到起点；透明用半透明圆，液量用烧杯；截面使用穿过立体的切平面，剪刀用于剪棱／拆分。
- 共用组件：`SpatialViewButtons`（视角与适合画面）、`SpatialAxisSteps`（移动／旋转 XYZ 准确步进）、`SpatialWorkbenchControls`（按钮、浮窗、颜色、轴与标记）、`SpatialOpacitySlider`（帧级预览与一次提交）、现有对象手柄／旋转／翻滚。原 Cube 命名入口仅 re-export 兼容，当前工作台直接引用共用层。
- 合并 UI 和动作入口，不合并不同数学过程。折纸的面与折痕、骰子的点数和投掷、液体守恒、截面／测量仍使用各自模型；旧冻结版本与场景格式不变。数据缩略图（七宝、展开图、点数、截面多边形）从数学状态生成，不当作功能按钮 SVG。
- 参数行里的加减、方向、关闭等基础符号允许复用；旋转正负方向始终带轴与角度，不用单独的回转箭头冒充“展开”。工作台接入测试防止再次本地导入 Lucide 或内联 SVG 自选功能图标。

## 操作约定

- 同一个左键／单指手势按命中位置分流：命中当前动作的对象或手柄则操作对象，未命中则交给 `SpatialCameraRig` 旋转视角。右键平移和滚轮缩放保持原控件规则。
- 轻点空白或工作台内按 Esc 取消选中，收起对象高亮、手柄、快捷栏与对象参数；拖动空白保留选中并转视角。再次点模型、对象列表，或打开对应对象参数可恢复操作目标。输入框的 Esc 保留自身行为，多个实例互不影响；仅被动工作台容器的焦点外框不显示，内部控件焦点样式保留。
- 取消选中是本机操作焦点，不移动对象、复原移面、展开纸片或改写备课现场。旧快照仍可保留必要的当前对象 ID，通过 `selectionActive` 控制舞台反馈。立体观察的已开启截面和测量保留，仅停止直接手柄拾取。
- 共用手势读取允许交互对象为空：React 可先更新 ref，再清理旧监听。清理只结束该绑定持有的手势／收拢动画及原回调，先移除监听并释放捕获，不读取已清空或替换的当前对象；重复清理保持无副作用。接入回归保留真实 `CubeMoveHandles` 的 effect 生命周期，不仅检查工作台传给 Canvas 的属性。
- 共用工作台将舞台标签、按钮字样和说明文字设为不参与原生框选，避免拖动／Shift 旋转误选网页文字；输入框、文本域和可编辑区域显式保留选字能力。保护限于工作台，不修改文档全局选择或指针事件。
- 正常观察状态同时提供对象操作。专用平移按钮改变的是空白手势；移动、折叠、剪棱等动作不会以 `navigationMode="object"` 关闭整块画布的旋转。
- Soma 连续二维拖动固定沿 X-Z 桌面保持高度；其他平面通过 XZ／XY／YZ 方片指定。起拖平面锁定到松手，松手才对齐网格；旧平面选项与按视角切换设置已移除。其他已接入工具暂留原起拖选轴规则。XYZ 箭头明确指定轴；轻点选中，拖动另一物体直接提交它的终点，选择不抢先发送课堂写入。
- 已编组的结构／Soma 拼块保持刚体；立方体普通观察选择已编组或面相连部分，原移动、多选工具仍可操作单位块。
- `SpatialTransformHandles` 提供 XYZ 箭头间的 XZ／XY／YZ 平面方片，以及明确的世界轴旋转环；`SpatialRotationControls` 在对象旁切换圆环并保留正负 90° 入口。精确面板调用同一领域操作，动画终点继续满足领域约束。
- 旋转、翻滚快捷栏共用 `SpatialObjectToolbar`。领域提供当前姿态的世界顶点和移动手柄，投影后按实际 HTML 尺寸在模型／句柄热区外找空位；优先保持可用的一侧，给舞台工具栏保留边界。极端放大或窄舞台没有完整空位时收起浮动栏，侧栏入口保持可用，不把快捷栏硬压回模型上。
- 模式按钮和参数面板共用 `useSpatialToolState`：切换操作时同步更换拾取方式；再点当前操作、关闭面板或在工作台内按 Esc，返回常规直接操作。显示开关、一次性命令与操作模式分开；关闭参数不隐藏舞台上仍在展示的截面手柄。
- `SpatialCameraRig` 统一保护轻点命令：超过移动阈值后即使拖回起点，也不会误触标色、删除或剪棱；双指、右键、取消和已由对象接管的拖动同样不会留下点击。
- `SpatialRollControls` 与 `SpatialRollButtons` 提供 X/Z 正负方向翻滚，指向对象显示支撑棱与中心路径。每次绕行进方向的底部支撑棱翻 90°，不是平移再原地旋转。
- 教学变化保留过程；减少动态效果时采用短过渡。首个绘制帧开始计时，编译或绘制等待不消耗动画。动态帧只负责显示，不保存为数学参数。
- 手动拖动实时预览、松手写一次。`useSpatialDirectCommit` 在课堂回执前保留已经展示的终点，失败或外部状态替换则返回权威现场。相同回执不重播；按钮动作等待权威状态后播放。
- 对象写入忙碌和相机控制分开。教师可在对象动画或持久化期间观察；展示端原有只读权限保持不变。

## 新增操作的接入步骤

1. 先区分操作模式、显示开关与一次性命令。需要拾取对象／面／棱的参数面板，在 `SpatialToolDefinition.panels` 中声明所需模式；使用 `controls.bindings` 限定键盘退出与状态反馈的实例范围，把 `controls.onPointerMissed` 传到实际 Canvas。用 `onClearSelection` 清理本机选择；快照需要保留当前 ID 时使用 `selectionActive` 关闭反馈，并在选中或直接拖动成功后 `activateSelection`。收起控件后保留对象拾取，既不留下隐形热区，也不要求重新切换模式。
2. 按命中对象接管指针；复用相机的空白手势和点击保护。移动和旋转优先接入共用平面方片／世界轴圆环，不单独为模型重写拾取或手势。对舞台上的直接手柄与精确输入，提供同一个领域目标函数。
3. 准确终点由领域模型校验。移动、旋转、翻滚复用现有控件和刚体表现层；对象旁控件传入包含实体大小的当前世界顶点，以及实际移动手柄，复用屏幕空间避让。需要旋转吸附时用 `rotation-snap.ts` 查找邻近允许朝向，领域校验位置／碰撞，返回 `snapped` 候选。拖动保留自由帧，松手由共用控制器平滑收拢，不要求另点对齐。翻滚使用 `rolling.ts` 的接触棱规划，并由领域检查合法落点和路径。对旧版本明确关闭不支持的动作。
4. 仅提交终点／语义命令；本地预览与课堂回执沿用现有桥接。为新动作补充中间帧、精确终点和撤销／复原用例。
5. 运行按钮交互、选择生命周期、工作台接入检查及受影响领域测试。接入检查遍历所有使用空间工具栏的工作台，新增工作台遗漏空白取消选中会失败，允许组合入口复用已接入的子工作台。手感和视觉继续由产品负责人实际验收。

## Soma 自由轨迹球（2026-09-20）

- 普通鼠标／单指拖动保持连续跟手，沿 XZ 桌面移动；平面方片 XZ 保持 Y，XY 保持 Z，YZ 保持 X，不随视角改选。侧看桌面无法可靠求交时提示换视角或使用可见方片、轴箭头。
- 2026-09-21 精简旧入口：移除平面选择、按视角切换阈值、俯仰角读数和灰色平面框，保留三标准平面方片及单轴箭头。`SpatialHeightGuide` 只画纵向细虚线与地面小十字，随整块、方片和轴拖动更新，不参与拾取，不写入场景或课堂快照。
- 常规状态显示 XYZ 精确手柄及轴间平面方片。平移与旋转轴分别保存为 UI 状态。点旋转后默认拖轴向圆环，再点返回常规操作；面板可切到自由轨迹球后直接拖对象，电脑 Shift 拖拼块也保留自由旋转。
- `arcball.ts` 按对象投影尺寸、抓取起点和当前点映射球面：中心附近翻转，边缘绕圈拧转。手势开始锁定相机、球心和半径，以起点计算总四元数，不累加欧拉角。球外拖动映射到圆周；显示圆环不扩大对象命中区。
- v2 支点采用源模型固定包围中心，转动中不随世界 AABB 变化。“旋转吸附（松手时）”提供自由、轻吸附 15°、标准 30°、强吸附 45°，默认标准，与顶部视角吸附独立。档位阈值统一定义于 `rotation-snap.ts`。接近 24 个网格朝向中的一个且最近格点能放下时，细虚线预告落位；松手用 160 ms 平滑收拢。自由档、远离目标或网格有冲突时保留合法自由末帧；自由末帧自身无效则回退。90° 按钮使用相同吸附策略，吸附后的格点姿态可直接翻滚。
- 平移与旋转预览复用 `SpatialLandingOutline`，从已有单位块棱边去重规则生成一像素虚线，不渲染填充面、不占用拾取。实际对象保持自由跟手，候选轮廓只说明松手终点。
- 网格落位保持中心尽量接近，每轴最多修正半格；半格等距优先保留源姿态的同一单元锚点，避免连续 90° 操作产生取整漂移。开关只影响后续操作，不改写已保存的姿态；显示网格开关也不改变数学约束。
- 自由姿态的网格仅作参考，允许绕中心转到参考平面下方；坐标范围、单位四元数与拼块之间的实际 OBB 碰撞由前后端共同检查。旧 v1 格点、地面与支点语义保持不变。
- 单指开始移动前加入第二指，将完整起点交给相机平移／缩放；对象已开始移动后保留第一指归属。松手只提交一次，160 ms 短过渡用于平移落位、邻近旋转吸附或无效落点回退；无修正时立即结束。取消、失焦、外部权威替换均不发布对象操作。
- `object-gesture-math.ts` 保留已验收的平面平移；`object-gesture-controller.ts` 管理设备归属和一次提交。`rigid-geometry.ts` 管理局部空间拾取与单位 OBB 碰撞。领域通过 `SpatialObjectInteraction` 提供选择范围、支点、包围半径、合法候选与提交，由 `CubeMoveHandles` 保持精确轴优先级。

自由轨迹球仍是 Soma 的可选方式；本轮共用平面／圆环手柄已接入 Soma、立方体结构、骰子和立体观察。其他工具的直接拖对象规则和合法终点不随之扩大。自动检查覆盖数学、指针事件、真实 R3F 姿态和课堂回执；桌面、iPad 与大屏的实际手感待产品负责人验收。

## 明确平面与旋转环（2026-09-21）

- 移动方片与 XYZ 轴使用相同中心；XZ 保持 Y，XY 保持 Z，YZ 保持 X。抓住方片即可连续移动，不需要先选平面再抓模型。Soma 直接拖整宝固定沿 XZ。
- 旋转环以世界 XYZ 为轴，抓住环后沿环转动。共用控制器冻结起拖相机、轴、固定支点与圆环尺寸，模型变化不反过来改变操作方向。接近侧看的平面／环淡化并停止拾取，不暗中换成其他方向。
- `transform-handles.ts` 同时提供可视几何与屏幕命中；平面方片优先于旧轴手柄和物体拾取。触屏扩大命中余量，单指未移动前加入第二指仍交给相机，取消不提交。中间帧与松手收拢共用控制器，准确参数仅在松手写入一次。
- Soma 沿用自由姿态与吸附合同。骰子、实体和立方体结构用 `gizmo-adapter` 将每次旋转手势限制在正负 90°，预览连续，松手落到最近允许的四分之一圈；这些工具没有因此获得任意角度的保存合同。
- 立方体平面移动原子提交两条原有轴向步骤，保留已有录制／回放格式和每轴撤销粒度；两种轴顺序均不合法或录制容量不足时整体回退。本轮不升级冻结快照。直接旋转的去重同时使用几何与语义历史，均色单块的撤销仍有过程动画。
- 骰子与立体观察的手柄复用现有终点写入；拖动过程留在本机。立体观察的截面与测量继续跟随同一展示实体，展开图／剪棱的已验收折纸手势不变。

## 接入与验证边界

`policy.ts` 管理共用动作计时与普通操作状态；`picking.ts` 读取实际表面，适配尺寸、转角、透明与裁切。现有 `CubeMoveHandles`／`bindCubeAxisDrag` 作为共享移动入口复用，领域提供选择范围、落点有效性和提交函数。

`useSpatialPresentation` 接收严格目标的稳定键与领域插值。`rigid-motion.ts` 使用四元数和固定轴圆弧，Soma 的格点模型与显示姿态分离，旋转中不让各小方块独立滑动。旧立方体历史仍由既有语义旋转解析，复用相同动作计时，不改发布版本。
