# 面积关系 · 开放材料首批

`18-create` / `plane-area-relations-lesson-v2` 用同一舞台累加三角形和凸四边形。材料复用 construction 的真实局部点位、独立中心与方向；上限 16 张，每张 3 或 4 个严格凸顶点。

打开“选底与面积关系”后点边选底。三角形可添加底边分点、拖动分点、准确设置分配比例或回到中点，显示同高两片。凸四边形可以用两条真实对角线分为四片。“复制当前分区为独立材料”把已显示的两片／四片整体复制到旁边，各片可以独立搬动；原材料、分点及观察保留。容量或几何边界不能容纳整组时，整次复制保持原状。

连接三个中点后可以把中点三角形复制到旁边，也可以直接“原位添加一层中点三角形”。每次原位添加后选中新材料，再次添加就生成下一层；各层是独立材料，不保留对父图形的联动。每层点位都是当前图形的真实中点，面积为当前层的四分之一；达到最小合法几何或 16 张材料上限后停止添加。数学派生动作保持网格开关原值，同时使用准确点位。观察开启后保留在各自材料上，关闭操作只收起分点手柄。

“保持底线与等高线”让三角形顶点沿各自真实平行线移动；开启编辑后可直接拖顶点。网格吸附在这类受约束拖动中让位于数学约束；宽高修改在约束开启时停用，解除后恢复自由比较。整体平移和旋转仍可用。高复用 `HeightMark`，斜底与底边延长线按实际垂直关系显示。

每张材料的 `base.ID`、`fraction.ID` 和 `height/division/parallel/diagonals/midpoints.ID` 保存操作参数与观察开关；辅助点、交点、分区面积派生。复制没有源对象引用，修改原件不影响复制件；移去材料同时移去它自己的关系元数据。

测量沿用 construction 的坐标单位：1 u 等于 960×720 SVG 舞台中的一个坐标单位，不是屏幕设备像素，也不是一格。准确宽高、位移、周长和高使用同一单位，分区面积使用 u²；缩放显示不改变读数。公共参考网格与吸附间距为 30 u，一格面积为 900 u²。

## 迁移边界

当前覆盖旧 18 的平行顶点移动、37 的共高分点、40 的四边形对角线，以及 42 的中点构造、独立复制和逐层原位材料。旧 v1 仍原样读取；18 的方格条细分、38/39/41/59 的共角／内点／共同部分／相似联动仍待后续。逐层材料使用真实独立几何，不是随父图自动更新的参数化层级。

共用工作台负责选择、草稿、历史、动画、保存和课堂回放；领域只提供数学终点及声明式操作。分区与中点材料沿用现有 v2 几何合同，不增加字段、版本或迁移。机器合同通过和人工教学手感验收分别记录。
