# 面积关系 · 开放材料、内点、共角与方格覆盖

新建使用 `18-coverage` / `plane-area-relations-lesson-v5`，同一舞台累加三角形和凸四边形。材料复用 construction 的真实局部点位、独立中心与方向；上限 16 张，每张 3 或 4 个严格凸顶点。已保存的 `18-strips` / v4、`18-interior` / v3、`18-create` / v2 和旧 v1 继续使用原描述符和字段合同。

## 完整格与边界格覆盖

选中三角形，打开“完整格与边界格覆盖”，再开启“显示完整格与边界格”。绿色方格完整位于三角形内部，黄色方格与三角形有正面积交集但未完整位于内部；仅接触点或边的方格不计入。每格按真实三角形裁切，颜色不取决于中心点是否在形内。完整格面积之和 ≤ 原三角形面积 ≤ 全部相交格面积之和；全部相交格包括完整格和边界格。

方格沿真实底边及其垂直方向排列，网格起点为该坐标系投影包围框的左下角。密度是**真实投影宽高中较长者**的等分数，支持整数 4～48；钝角顶点向底边外伸时，投影宽包含完整外伸，而不是只取底边长度。两轴至多各 48 格，每张材料最多检查 2,304 格；旋转、镜像、两种绕序和换底均使用真实几何。覆盖与下节方格条使用独立密度，两者在钝角外伸时尤其不能混用。

“继续细分覆盖方格”依次进入 4／8／16／32／48 中的下一档。几何不变时，4→8→16→32 是同起点的嵌套细分，内覆盖不减、外覆盖不增；32→48 不是嵌套网格，不承诺每个任意三角形的单步界限都单调。任意合法密度均保持内外面积界。极狭长或低密度的三角形可以没有完整格，内覆盖面积为 0，边界格仍覆盖原形。

关闭面板、取消选择或切换操作保留观察。只有主动开启“显示长度与面积”才显示格长、格数与面积界，单位沿用 u／u²。原有条带观察、底高、内点、共角及相似操作继续保留，网格覆盖不将方格复制为材料。

v5 只新增 `coverCount.ID`（默认 16）与 `coverCells.ID`（默认关闭）；方格、交片及面积均实时派生。桥接将原动作送入 v4，并按真实材料 ID 恢复新设置；普通复制继承原值，新构造或数学派生材料默认关闭覆盖，删除同步清除字段。16 张材料共 230 个参数键、153 个开关键，保持现有 256 键上限。四边形保存密度但覆盖开关保持关闭；旧版本严格校验、保存 API、RLS 与冻结副本保持。

## 正方形条带与细分

选中三角形，打开“正方形条带与细分”，再开启“显示正方形条带”。小方格始终沿当前真实底边及其垂直方向排列，自绘、斜放和镜像三角形使用同一模型。密度为底和高中较长者的等分数，可准确输入 4～48 的整数；“继续细分”依次进入 4／8／16／32／48 中的下一个档位。每张材料独立保存密度和显示开关，关面板或取消选择保留观察。

一行以该高度中点处的三角形截宽为基准，向下取整成整小方格，并左右居中；不足一格的行与顶端余高不画。阶梯是面积近似，不是精确三角形切片，也不表示每格完全位于三角形内。特别狭长的材料在低密度下可能没有条带，界面提示继续细分。开启测量后显示方格边长、格数、条带近似面积和原三角形面积，单位沿用 u／u²。

保持底边长度及高不变、沿等高线移动对顶点时，每条只作平行移动，格数、格长与近似面积保持。移动底边端点而改变底长，或解除约束改变高时，按新几何重新计算；不把“在两条平行线上”误认为底长也固定。

“复制近似条为独立材料”把每行复制成一张真实矩形，整体移到原底边外侧，保留原三角形与观察。复制件没有父材料依赖，后续可自由搬动、旋转、编辑或移去；它们的总面积等于当时的近似条带面积，并不补成原三角形面积。现有上限为整个舞台 16 张材料，过密条带需先降低密度。任何一行过小、坐标越界、材料或 ID 不足时整次保留原状，不留下半组。复制与细分分别占一次撤销。

v4 只增加每材料的 `stripCount.ID` 和 `strips.ID`；方格点位、条宽、格数和面积均由真实几何派生。桥接将原操作送入 v3，再按真实材料 ID 恢复条带设置；普通复制沿用源数值，新构造材料默认关闭观察，删除清除所属字段。旧版本、原保存 API、RLS 和冻结副本保持，新增版本只追加严格校验。完整格／边界格内外覆盖由 v5 独立承载，任意凹多边形关系仍另行施工。

## 内点与两翼

选中三角形，打开“内点与两翼”，再开启“显示内点与四个分区”。P 位于三角形内部，D 位于所选底边；四片由底边两段、顶点和 P 的实际连线划分。测量开启后显示各片准确面积；两片靠底区域合成底边与 P 的三角形，另外两片为两翼。

准确参数保存内点的底边方向比例与高度比例，均为 0.05～0.95；高度比例指相对于原三角形高的比例，底边方向比例沿两条侧边之间的同高线计算。自由拖动越出范围时保持在合法内部。开启共线后 P 沿“对顶点—D”连线移动，调整 D 时 P 保持高度比例并跟随该连线；解除共线保持当前 P 位置。网格吸附不改写这些数学约束。

换底按原 P 的位置重算新比例；开启共线时，同时把 D 调整到新底上的共线位置。若 P 极靠边，导致新基准比例超出合法范围，则保留原底与全部几何，可先将 P 移回内部再换底。

专用操作开启且材料被选中时可以拖 P、D；关闭、空白或 Esc 收起手柄，分区观察保留。只读端保留观察，不提供手柄。四片可整体复制成独立材料；容量、最小几何或 ID 不足时整次保持原状。新材料不保留对原件的依赖。

v3 每个对象增加 `innerBase.ID` / `innerHeight.ID` 和 `interior.ID` / `collinear.ID`；辅助点与面积派生，不另存一份坐标。桥接层将原有操作交给 v2 数学函数，再按材料归属恢复新元数据；原 v2 校验保持不变。凸四边形继续使用原对角线能力，其内点开关保持关闭。

## 共同片与两翼余片

在“内点与两翼”中显示分区后，所选底边 A、B 与 P 围成共底小三角形 ABP；其余两翼为 BCP 和 CAP。调整 P 后，可按当前真实点位执行以下动作：

- “拆成共同片与两翼”：把当前整张三角形替换为三张原位材料，选择共同片，可直接独立搬动。
- “移开共同片”：完成同样拆分，并把共同片沿所选底边的真实外法向移出原三角形；两翼原位，片形和面积不变。过程可暂停、继续，中间停点也是合法材料。
- “只保留两翼余片”：去掉共同片，只留下两张原位余片；剩余总面积等于整片减去 ABP。

这些动作在本次历史中各占一次撤销，恢复完整原件及其辅助点／观察。生成材料彼此独立，可继续搬动、旋转、编辑、保存或配置新的内点；不保留对原整片的引用。其他材料与标记保持原样，仅清除已拆原片的关系字段和标记。

数学拆分不受绘图网格吸附影响。先释放原片容量，再检查全部新片；任何一片低于最小几何、超出坐标范围，或材料／ID 额度不足时整次保留原状。这是当前三角形及内部共底小三角形的操作，不是任意两张纸片的布尔裁切。保存继续使用既有 v3 几何，无新增字段或数据库迁移。

## 共角调边与定点等比伸缩

选中任意三角形，打开“共角分别调边”。O 是当前所选底边的对顶点，A、B 为该底边两端；在原“选底与面积关系”中换底即可换 O。OA／OB 有准确长度输入，A、B 可沿各自真实射线独立拖动。斜放、旋转、镜像与自绘材料使用同一数学操作，网格不改变射线或终点；若已锁定等高线，先在原面板解除该约束再调边。

“添加同向共角副本”按当前三角形以 O 为中心取 0.6 倍，形成嵌套材料；“添加反向沙漏副本”在两条反向射线上取同样比例。新副本被选中，原材料及其观察不动。两片都是真实独立材料，可以继续改边、搬动、旋转、保存或移去；容量、ID、最小几何或坐标边界不允许时整次保留原状。

“定点等比伸缩”让当前三角形的两边联动，拖任一端或设置任一长度，都围绕 O 按相同比例伸缩。面板同时提供缩为一半、放大一倍的过程动画，可以暂停、保存准确中间材料、继续或一次撤销。“使参照底边与当前底边平行”保留 OA，沿 OB 调整至两射线的对应比例相等；参照片不变。关闭操作后收起手柄，继续普通自由编辑；操作面板不是存档中的永久约束。

开启已有测量显示后，按当前实际几何比较共顶点、同向或同时反向的射线材料。参照取面积最大的合法候选（同面积按 ID），在舞台明确显示参照编号、A′／B′、两边比例及面积比；不存在合法参照时不生成比较结论。面积比始终为两射线对应比的乘积；两比相等、底边平行时才追加平方关系。两比不相等仅说明这组射线对应不平行，不排除交换两边对应后的相似情形。读数为近似显示，计算使用未舍入点位。

本批复用 `18-interior` / v3 的准确几何和底边字段，没有新增持久参数或跨材料引用。自由移动／编辑其中一片后重新按真实几何判断，不把原材料与副本绑定成自动跟随的层级；需要保持当前图形比例时开启定点伸缩，其他材料不随之变化。

## 底、高与派生材料

打开“选底与面积关系”后点边选底。三角形可添加底边分点、拖动分点、准确设置分配比例或回到中点，显示同高两片。凸四边形可以用两条真实对角线分为四片。“复制当前分区为独立材料”把已显示的两片／四片整体复制到旁边，各片可以独立搬动；原材料、分点及观察保留。容量或几何边界不能容纳整组时，整次复制保持原状。

连接三个中点后可以把中点三角形复制到旁边，也可以直接“原位添加一层中点三角形”。每次原位添加后选中新材料，再次添加就生成下一层；各层是独立材料，不保留对父图形的联动。每层点位都是当前图形的真实中点，面积为当前层的四分之一；达到最小合法几何或 16 张材料上限后停止添加。数学派生动作保持网格开关原值，同时使用准确点位。观察开启后保留在各自材料上，关闭操作只收起分点手柄。

“保持底线与等高线”让三角形顶点沿各自真实平行线移动；开启编辑后可直接拖顶点。网格吸附在这类受约束拖动中让位于数学约束；宽高修改在约束开启时停用，解除后恢复自由比较。整体平移和旋转仍可用。高复用 `HeightMark`，斜底与底边延长线按实际垂直关系显示。

每张材料的 `base.ID`、`fraction.ID` 和 `height/division/parallel/diagonals/midpoints.ID` 保存操作参数与观察开关；辅助点、交点、分区面积派生。复制没有源对象引用，修改原件不影响复制件；移去材料同时移去它自己的关系元数据。

测量沿用 construction 的坐标单位：1 u 等于 960×720 SVG 舞台中的一个坐标单位，不是屏幕设备像素，也不是一格。准确宽高、位移、周长和高使用同一单位，分区面积使用 u²；缩放显示不改变读数。公共参考网格与吸附间距为 30 u，一格面积为 900 u²。

## 迁移边界

当前覆盖旧 18 的平行顶点移动、正方形条带细分及完整格／边界格覆盖、37 的共高分点、38 的共角独立调边、39 的内点／两翼及可解除共线、40 的四边形对角线、41 的共底共同片拆分／移开／两翼余片、42 的中点构造与逐层原位材料，以及 59 的同向／沙漏材料、平行调整与当前材料两边等比联动。旧 v1/v2/v3/v4 均按原合同读取；v5 覆盖基于当前自绘材料及严格正面积裁切。拆出、复制或逐层添加的材料使用真实独立几何，不是随父图自动更新的参数化层级；本批没有新增跨材料永久约束。

共用工作台负责选择、草稿、历史、动画、保存和课堂回放；领域只提供数学终点及声明式操作。内点元数据通过独立 v3 保存校验接入原 API，不改写历史草稿、发布副本或课堂事件。机器合同通过和人工教学手感验收分别记录。
