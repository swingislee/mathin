# 图形计数与一笔画线网

`47-create`（图形计数）与 `52-create`（一笔画／多笔画）共用真实节点和边，继续使用既有两个 lesson-v2 保存合同。没有新增持久字段或 SQL。

## 准确编辑

- 先用“编辑点和线”选中节点或边，再从对象旁入口或右侧打开准确参数。点位沿用 960×720 舞台坐标，X 向右、Y 向下；数值输入接受任意有限小数，不受拖动的吸附开关量化。
- 边端点 A／B 按节点 ID 从小到大标识。两端坐标可独立修改；边长使用既有 30 舞台单位＝1 u，长度和方向输入固定 A、更新 B，方向角以逆时针为正。
- 准确输入保留节点／边身份。零长、越界、节点重合、与其它边相交而未建立节点等结果整次保留原现场；既有直接拖动和绘线仍使用原有交点分裂／节点合并语义。

## 真实连通组

- 组由所选节点或边的图连通关系确定，包含真实交点；孤立点也能单独平移，不按框选区域猜组。
- “平移或旋转整个连通组”提供中心十字柄、转柄、准确中心 X／Y、参考边方向、一步平移和 15° 转动按钮。关闭操作面板收起辅助柄，材料保留。
- 支点取组内节点坐标平均值。方向参考所选边；选择节点时参考组内最早的边，孤立点没有旋转方向。操作每次写入实际点位，不保存容易过期的中心／方向缓存。
- 整组刚体移动保留边、观察和笔迹身份；其它连通组保持原位。越界、碰撞或拓扑失效时整次保留原状，不自动把两组焊接。直接手势冻结起点，取消恢复原现场，松手提交一次。

## 单条观察与逐笔管理

- 下方托盘显示已形成记录的稳定编号；图形计数显示 R 编号，一笔画显示笔号。删除之后保留编号空缺，不复用旧身份；托盘在隐藏彩色留痕时仍可选择和管理原记录。
- 选择一条记录后，对象旁或记录面板可仅移除该记录，保留节点、边和其余记录。已有暂选顶点也保留。
- 每笔以圆圈和 S 编号表示起点，方框和 E 编号表示终点，闭合笔迹可在同一点同时显示二者。标记展示老师已走过的事实，不自动给出一笔画判定或标准答案。
- 可以明确选择旧的一笔，从其终点继续；原 v2 的跨全部笔迹禁重复边规则保持，开启“允许再次走同一条边”后才可重走。回放继续按稳定笔号逐笔呈现，不把继续旧笔改成新增笔。

## 边界

沿用原合同：各 96 个节点和边、24 条计数观察、32 笔且共 192 个走访点；点位 X 在 -1000～2000、Y 在 -1000～1720。观察、线网和笔迹都保存真实节点关系，课堂／冻结／历史继续走共用 v2 合同。机器检查不替代人工确认密集记录布局和触摸手感。
