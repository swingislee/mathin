# 真实圆片割补

`27-sectors` / `plane-circle-area-lesson-v2` 保存每片扇形的圆心顶点与第一条半径的方向。真实圆弧始终参与展示；各片独立移动、连续旋转及准确输入，默认不显示面积结论。

- 8／16／32／64 份等分，半径 0.5–3 u，50 舞台单位为 1 u，数学 Y 向上。每片顶点 X ±20、Y ±12，方向 ±36000°，数值输入保持任意合法小数。
- 圆形和两行交错排列可互相刚性搬移。细分保留排列类别；自定义摆法把每片原地切成相邻子片，原区域不改变。自由摆法合并只接受真正同顶点、邻接方向吻合的片；无法合并时整次保持。
- 旋转柄只在圆片位姿操作中显示。直接拖动冻结起点和支点，连续解角；靠近原圆或两行目标时可选吸附。关闭操作保留材料。
- 过程帧仍是准确扇形位姿，可暂停、继续、停在当前位置并保存；细分重编号按父子关系延续当前片选择。显示参照圆、编号和量度分别控制。
- 两行轮廓保持弧形边，面积读数指各片面积之和，不冒充当前叠放区域的并集面积。旧 `27` v1 按原版本读取。

数学模型、严格验证、SQL 0307 与共享课堂使用同一六键状态；不保存 SVG 路径、动画进度缓存或派生面积。
