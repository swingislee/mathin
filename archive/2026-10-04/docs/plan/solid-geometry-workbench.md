# 立体观察 · 教具工作台

> **状态**：2026-09-19 开发实现与定向机器检查；共用目录、备课和课堂入口由本批集成统一登记。待产品负责人在开发端进行视觉与操作验收，不改变 R1-Live Gate。
>
> **范围来源**：[可备课数学教具](prepared-teaching-tools.md) 与本轮七个典型教学现场施工授权。展示、操作和关系观察为目标，不设置题目、提交、判题或检查点。

## 1. 定位与依据

**新的工具：立体观察（`solid-geometry`）**。单位立方体结构的搭建规则无法准确表达圆柱、圆锥、球以及一般多面体。保持旧立方体结构工具独立，立体观察使用真实尺寸和曲面参数，复用视角、拖动、按钮、非模态浮窗、场景保存和课堂状态接口。

截面、测量分别适合作为该工具的功能按钮；本增量为它们提供严格实体合同与同一舞台的扩展槽，不再建设一套通用 CAD 或题目系统。

## 2. 教师现场动作

1. 从右侧“添加立体”放入正方体、长方体、三棱柱、四棱锥、圆柱、圆锥或球；最多 16 个同时比较。
2. 点击实体选择，也可以从“实体与尺寸”浮窗切换；修改当前实体适用的尺寸。
3. 空白或实体上拖动旋转观察；右上沿用立体、前、左、右、上、底视角、适配视野和视角吸附。
4. 用“移动实体”的 X/Y/Z 箭头或半格步进摆放，独立开关移动吸附；“转动实体”让当前实体沿 X/Y/Z 转动 90°。
5. “观察面／观察棱与边界／观察顶点”选择实际语义结构；可以直接点可见结构，也可以从浮窗选择被遮挡部分。
6. 为当前实体标色或调整不透明度。尺寸、旋转、步进位移和透明过程平滑变化；手动拖动终点直接保留，不重播。
7. 移除当前实体；“恢复备课起点”同时恢复原来的实体、摆放、尺寸、颜色、透明度、突出结构和视角。

各浮窗位于舞台内，不改变 4:3 尺寸；没有下方过程提示导致布局变化。共用工具栏只显示 SVG，标签保留在可访问名称与悬停提示中。

## 3. 实现及复用点

- `solid-geometry-contract.ts`：严格参数、起点、课堂快照、合法尺寸编辑和默认起点。
- `solid-geometry.ts`：纯实体拓扑、闭合渲染网格、解析面积/体积、局部到世界坐标、保守包围盒和取景范围。
- `SolidGeometryScene.tsx`：按真实实体绘制。圆柱/圆锥/球的曲面不是体素；渲染三角网格不会进入教学面、棱、顶点计数。
- `SolidGeometryCanvas.tsx`：共用 `SpatialCameraRig`、`cubeWorkbenchCamera` 和全仓 `THREE_SHADOWS` 兼容入口；不创建 `THREE.Clock` 或弃用阴影类型。
- 移动复用 `CubeMoveHandles` / 原轴向拖动控制器；`solid-geometry-drag.ts` 的单点代理仅服务手柄命中和位移，不参与实体几何或数学量计算。
- 右侧工具、面板、视角图标、颜色盘直接使用 `CubeWorkbenchControls`；输入和按钮使用现有 shadcn 控件。
- `renderScene` 接收同一动画展示帧；`renderToolbar`、`renderPanel` 接收严格工作台上下文。截面/测量可以作为本工具按钮接入，不占新舞台。

## 4. 参数、备课和课堂接入

版本 `solid-geometry-lesson-v1`，`toolId=solid-geometry`。`solidGeometryToolSchema` 的 `payload.initial` 包含完整实体列表、当前选择、语义结构高亮、轴/网格开关及预设视角；不引用个人草稿，不包含相机逐帧或拖动中间帧。

实体字段：稳定 ID、kind、dimensions、position、rotation、color、opacity。以实体中心为局部原点、Y 为竖直方向；rotation 为 XYZ 欧拉弧度。正方体三边保持相等，四棱锥保持正方形底面；合法尺寸为 0.2～12，位置范围 ±30，透明度 0～1。三棱柱采用 X–Y 等腰三角形截面并沿 Z 拉伸，因此其解析公式中的柱高是 `depth`。

`getSolidTopology` 为多面体返回真实面、棱和顶点；圆柱返回 2 个平面、1 个曲面、2 条圆周边界；圆锥返回底面、曲面、圆周边界和锥顶；球只返回一个曲面。不将圆周边界称为直棱，不把曲面的细分点当作顶点。不同教材对曲面是否称为“面”的用语可以在浮窗中明确区分。

`useToolSnapshot` 保持课堂教师单写者。等待持久化回执时保留确认现场，回执后启动一次表现动画；失败反馈复用既有模式。展示端和晚加入端读取完整快照。`useSceneCapture` 在拖动、动画和发布中返回空候选，避免冻结中间过程。

扩展参数应由集成层在版本 schema 中逐项声明；不存在任意 JSON 插槽。参数保存、课件固定副本、实例隔离、事件传输和晚加入继续复用 Tools 共用层。

## 5. 定向验证

- `tests/solid-geometry.test.ts`：7 种实体的闭合网格与解析体积、真实拓扑和欧拉关系、曲面语义、合法尺寸及引用、严格场景往返、XYZ 旋转、动画精确终点及拖动边界。
- `tests/solid-geometry-workspace.test.ts`：多实体/局域网 UUID、右侧非模态入口、尺寸渐变、透明渐变、恢复起点、语义选择、直接拖动无重播、扩展槽、课堂单写与晚加入/失败回退。
- 机器检查不替代 3D 视觉、手柄命中、尺寸手感和课堂实际人工验收；本增量不运行浏览器控制、Playwright 或全量构建。

## 6. 剩余边界

- 首批三棱柱使用等腰三角形、四棱锥使用正方形底；任意多边形实体属于后续明确设计。
- 旋转实体提供 90° 教学步进；自由拖动旋转的是观察视角。未引入 CAD 式任意轴旋转手柄。
- 标色、透明作用于实体整体；语义单面当前可突出观察，逐面持久染色/独立透明可在同一合同下另行扩展。
- 曲面的渲染网格按有限分段采样，体积和表面积始终使用解析公式。截面扩展使用采样时应说明精度边界。
- 截面、测量与容积教学 UI 由同批对应 agent 制作，本增量不重复实现。
