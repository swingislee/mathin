# 尺寸、表面积与体积 · 测量按钮

> 2026-09-19，七个立体教具现场第 5 项。分项组件与定向机器检查已完成；主 agent 统一接入立体观察的场景快照、课堂与注册。尚未进行产品视觉、教学手感验收，不改变生产阶段或 Gate。

## 1. 定位与依据

作为「立体观察」右侧的测量功能按钮，不新增工具库条目或另一套工作台。尺寸、所选面、透明度和实体摆放都已经由立体观察持有；测量是在同一实体上增加观察方式。

教师可控制是否显示数值。这里没有题目、学生作答、正确答案、评分或必须依次完成的教学步骤。

## 2. 教师现场动作

1. 选择实体，打开右侧「测量与单位」浮窗。
2. 开关尺寸标注；转动视角或移动实体，标注跟随实际展示帧。
3. 选择一个语义面，观察该面面积；整体表面积和体积可单独显示、隐藏。
4. 对正方体、长方体开启表面单位网格，观察单位长度与面片划分。
5. 当三条边为 1–6 个整数单位时，开启单位方块分层，点击「放入一层」「移出一层」「逐层填满」「逐层清空」。各层按顺序平滑放入或移出，目标可以中途改变，空白处仍沿用主舞台的旋转观察。

浮窗沿用 `CubeCanvasPanel`，不会建立第二个 Canvas 或占据 4:3 舞台外的常驻说明行。关闭浮窗不要求关闭测量显示。

## 3. 实现与复用

- 尺寸、总表面积、体积使用 `solid-geometry.ts` 的同一实体尺寸与解析量。圆柱、圆锥、球不会把渲染三角形当作数学面片计数。
- 单面面积按已有语义拓扑选择。多面体使用平面多边形三角剖分；圆面、曲面从共享解析量取得面积，不用离散圆周近似值冒充精确值。
- 单位方块直接复用旧 `buildRectangularPrismMeasurement` 的占据格、坐标映射及限制，并映射到以实体中心为原点的展示空间。旧面板的公式/内核价值保留，不复制其整页 Card 布局。
- 右侧按钮、浮窗、开关、按钮分别复用 `CubeIconButton`、`CubeCanvasPanel` 与 shadcn `Switch`、`Button`。
- 单位方块按层实例化，每层使用相同尺寸的真实单位块。填充时只暂时淡化展示壳体，教师设置的实体透明度不被修改；关闭后仍使用原材质。
- 层数动画只在表现层使用 rAF。系统减少动态效果时保留短暂透明度过渡，不执行方块的上下位移。

## 4. 参数、备课与课堂

分项只提供受控 API，由共用宿主持有状态：

| API | 用途 |
| --- | --- |
| `measurementSettingsSchema`、`createMeasurementSettings()` | 严格的测量参数合同及默认值 |
| `MeasurementButton` | 现有右侧工具栏中的入口 |
| `MeasurementPanel` | 读取 `settings / selected / feature`，通过 `onChange / onSelectFace` 返回离散操作 |
| `MeasurementOverlay` | 接收当前动画/拖动帧的 `entity`，在原场景中绘制 |
| `measurementUnitFillAvailability()` | 返回可填充条件，或明确不可用原因 |
| `measurementDisplayEntity()` | 仅淡化用于展示的壳体，保持保存参数不变 |

保存字段为 `measurement`：

```ts
{
  enabled: false,
  dimensions: true,
  faceArea: true,
  totals: true,
  unitGrid: false,
  unitFill: false,
  fillLayers: 0, // 0–6，具体展示还会受当前实体层数约束
  unit: "unit"
}
```

同一 `measurement` 进入立体观察初始条件和课堂快照；主 agent 接入既有 `useToolSnapshot` 和 Tools 版本化同步。单面选择复用 `feature`，不保存第二套选面状态。只保存填充层数终点，不发送动画中间帧。晚加入直接恢复当前目标层数，后续操作再播放层间变化。

建议截面与测量模式互斥，避免把原实体的面积/体积读数误认为切除后剩余部分的测量。分项本身不修改已有版本合同、数据库或课堂传输。

## 6. 当前边界

- 单位使用抽象 `u / u² / u³`；不将屏幕长度解释为厘米，不提供未经定义的实物换算。
- 单位网格限正方体/长方体，可显示小数尺寸的剩余边段；单位方块填充限各边整数 1–6 u（最多 216 块），不静默截断或四舍五入。其他实体保留尺寸及解析面积、体积观察。
- 数值最多展示三位小数，发生舍入时明确使用 `≈`。原始数学值保持全精度。
- 这是既有参数对应的尺寸与面积观察，不是任意两点测距、曲面涂格、自动推导公式、容量倒水或流体模拟；容量比较由第 7 个现场负责。
- 修改实体种类或尺寸时，单位填充按新实体重新判定；对暂不能整块铺满的尺寸不显示假造单位块。每次分层动画有独立的目标，记录不包含逐帧的中间形态。
- 分项没有运行浏览器控制、截图或生产写入。页面交付与人工验收状态由主 agent 更新。
