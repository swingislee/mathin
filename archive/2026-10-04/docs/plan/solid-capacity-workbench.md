# 容积比较教具 · 首批现场

> 2026-09-19 七项教具施工的第七项。开发实现及定向机器检查已完成，尚待根任务完成共用接入及产品负责人视觉、教学手感验收；无生产写入，不改变 R1 阶段或 Gate。

## 1. 接入判断

采用独立工具 **容积比较**（`solid-capacity`）。它的操作主体是两个容器之间的液量，而非某个实体上的静态测量按钮。教师可保存一对容器及初始液量，再围绕容量关系自由组织教学。底层复用立体观察画布、实体外壳、相机、视角吸附、右侧工具、非模态浮窗与 Tools 的备课／课堂快照入口。

## 2. 教师现场动作

- 默认圆锥装满、圆柱为空，二者同底等高。打开右侧“装入与转移”，将一锥液体倒入柱中；装满圆锥后再次倒入，第三次可见柱体恰好装满。
- 转移量可选全部现有液体、半锥容量、一锥容量；也可从圆柱倒回圆锥。来源液体或目标余量不足时，只转移实际允许的液量，余量保留在来源。
- 两者可以保持同底等高，也可分别设置半径和高。尺寸变更明确清空两容器，再由教师装入新的液体。
- 数字默认隐藏；需要时显示液量／容量。只有实际同底等高时才显示 `1 : 3` 关系，不把不同尺寸的比较强行套入同一结论。
- 可切换圆锥尖端朝向、清空、恢复备好的起点，开关尺寸、网格、坐标轴，并在灌入过程中继续旋转观察。改变朝向先排空圆锥再旋转。

## 3. 实现与复用

`SolidGeometryCanvas`、`SolidGeometryScene`、`SpatialCameraRig` 和 `CubeWorkbenchControls` 直接复用，额外渲染层只绘制液体和尺寸标签。保持 4:3 舞台与既有浮窗组织，不新增第二套相机、工作台外框或课堂传输组件。

液量用容量占比 `fill` 保存。圆柱容量为 `πr²H`；圆锥为 `πr²H/3`。液面高度从最低点量起：

- 圆柱：`h/H = fill`。
- 圆锥尖端朝下：`h/H = ∛fill`。
- 圆锥尖端朝上：`h/H = 1 − ∛(1 − fill)`。

圆锥液体使用对应圆锥或圆台网格。转移过程对液量插值，再求两边的液面高度，因此同一帧的两容器总液量守恒，不把圆锥的液量变化直接当作等速升降高度。转移虚线是受控示意，不标称流体物理模拟。

## 4. 参数、备课与课堂

独立 strict 版本为 `solid-capacity-lesson-v1`。`solidCapacityInitialSchema` 保存两个容器的半径、高、液量占比、圆锥方向、尺寸联动、数字／尺寸显示、网格／轴及预设视角；半径和高范围为 `0.25..6`，液量占比为 `0..1`。联动开启时两者尺寸必须一致，额外字段被拒绝。

`solidCapacitySnapshotSchema` 仅额外包含离散的 `cameraRevision`。`SolidCapacityWorkspace` 暴露 `initial / onSnapshot / classroom / readOnly`，由根任务纳入同一 Tools 场景保存、课件副本和版本化课堂 provider。

课堂动作只发送一个离散终点，等待权威持久化回显后播放动画；教师确认回执不再次播放。旁观端可从权威 snapshot 恢复，失败保留此前确认状态。rAF 表现帧不写入课堂日志，动作过程中暂停起点捕获。`prefers-reduced-motion` 下仍以短过渡衔接数学状态。

## 5. 定向检查

- `tests/solid-capacity.test.ts`：容量与两种尖端方向、液位逆算、圆台网格液量、三次装满、容量不足保留余量、分量／反向转移、尺寸联动与 strict 版本、逐帧守恒、排空后转向。
- `tests/solid-capacity-workspace.test.ts`：共用浮窗与工具栏、连续液面和恢复起点、不同尺寸关系、数字开关、单次权威提交、失败保持与晚加入只读恢复。
- 当前两个文件共 12 项通过；使用假 rAF 的 DOM／数学合同检查，不替代 WebGL 视觉与真实课堂手感验收。根任务统一执行跨工具类型、注册与 SQL 集成检查。

## 6. 实际边界

首批固定为一圆锥和一圆柱，尺寸为抽象长度单位、容量为相应立方单位。保留不同尺寸的实验空间，没有答题、评分、结果判定或强制步骤。

当前不模拟容器倾斜时的液面、飞溅、溢流、真实倾倒轨迹或无限数量容器，也不实现曲面展开。切换尺寸／尖端方向属于重新配置演示条件，界面明确提示清空行为。容量与转移数学使用解析式；圆周网格的 64 段仅为图形表现精度。
