# 候课与课堂翻页热修补 · 2026-09-08

状态：开发端已交付，待人工视觉与交互验收。当前阶段仍为 R1-Live-2；本次没有生产发布、数据库迁移或业务数据写入。

## 交付范围

- 正式课、微课的 LiveShell 与公开课 PublicClassRunShell 共用候课组件及进入规则。`entry=prep` 可在已开课后主动进入候课，课堂内也保留入口；继续课堂只切换当前设备视图。
- 返回候课时保留已挂载的课堂舞台、页码、板书和事件连接。正式开课及冻结仍由原领域动作负责；已开课、已结束和试讲的候课按钮分别进入继续、查看和演练路径。
- 正式课与微课试讲先经过候课；公开课新增独立试讲入口。试讲的开始、插白板页、名单刷新和公开课名单操作均与正式写入隔离；展示预览保留试讲模式，各窗口独立运行。实际设备配对继续在正式候课检查。
- 左右方向键、PageUp / PageDown 与空格直接翻页，文字输入、输入法组合及弹层内操作保留自身按键。候课和非教师控制端停用翻页快捷键。
- iframe 按键桥由父窗口显式启用，校验当前 iframe、焦点、会话 token 和允许的按键；嵌套 iframe 逐层转发。应用注入脚本使用独立缓存版本，课程包摘要及 iframe sandbox 权限保持不变。
- 正式课堂的键盘翻页复用既有 `page` 事件与 `current_page` 基线，登记 `page-navigation-v1` 同步 provider；H5 内容自身的只读合同保持。公开课继续原有本机展示逻辑。

## 机器检查

- TypeScript 全项目检查通过；受影响文件 ESLint 通过。
- zh/en 消息键一致性通过。
- 候课规则、键盘及 iframe 桥、R1 课堂连续性和互动同步审计：4 个定向文件、35 项通过。
- 同批已通过 H5 shim、H5 pointer bridge、来源页切换、共享课件工作台的定向检查。
- 公开课工作台测试 10 项通过；另 1 项既有活动目录断言失败，仍要求 ActivitiesManager 包含 `?view=onsite`。该文件在本次热修补中未修改，当前 HEAD 的活动目录调整已移除此旧入口。
- 本机开发主机与 Supabase origin 已核对；复用现有开发服务，登录页面 HTTP 200。没有运行浏览器控制、Playwright 或截图验收。

## 人工验收

1. 任意正式课或微课进入试讲，先检查候课页，再开始试讲；绘制板书、切换页面后返回候课并继续，确认现场操作保留。
2. 已开课课次从工作区或另一设备进入“候课 / 设备检查”，主按钮显示“继续上课”；确认课堂其他设备保持原状态。
3. 公开课从备课工作区进入试讲，验证候课往返及名单只读；已开课公开课可重新打开候课并继续。
4. 分别在课件、普通按钮、分栏手柄及 iframe 内操作后测试左右方向键和空格；输入文字及打开弹层时确认按键留在当前控件。验证首次进入、返回候课、再继续三个时点。

以上机器结果只覆盖已检查的合同；实际键盘、板书和设备切换体验等待产品负责人验收。
