# 总览接入现有业务数据

状态：**开发端已交付，待人工视觉验收**，2026-09-08。本轮为只读统计适配，阶段与生产 Gate 保持原有状态。

产品负责人确认总览继续统计本周／本月；在读学员取当前学期班级的全部在读名单。页面入口为 `/zh/dashboard?view=overview&period=month`，周视图使用 `period=week`。

## 统计口径

| 数据 | 读取与计数 |
| --- | --- |
| 周／月比较 | 使用机构时区的自然周／月；本期截至现在，上期比较相同进度。 |
| 新增线索 | 线索进入系统的创建时间。分批导入的入池数量与来源中的历史接通日期分开统计。 |
| 有效接通 | `lead_communications` 的 `connected` 事实，兼容 `occurred_at` 与 `occurred_on`。 |
| 确认邀约 | 现有邀约确认事件，以及来源预约的 `registered_on`；同一邀约／来源在一个周期内去重。 |
| 到访 | 已到预约，兼容场次的 `scheduled_at` 与 `occurred_on`；未到与取消不计到访。 |
| 测评 | 已完成结果，按实际测评日期／完成时间归日；来源中的仅有家长备注、未到预约不作为完成测评。 |
| 报名 | 课程报名登记优先，兼容原生入班记录；已有报名—入班桥接只计一次。来源报名缺失日期时保留缺项，不回退到导入时间。 |
| 花名册导入 | 既有导入 RPC 以 `班级学员导入：` 标记来源，`joined_at` 是导入时刻。这类记录进入在读快照，新增报名读取独立的报名登记。 |
| 在读与班容 | 读取系统当前学期的正式班级，含筹备中班级，排除已归档及回收站班级。名单采用 `active` 入班记录，人数按学生去重，席位逐班计数。既有班容规则继续适用，缺少容量设置的项目保持空值。 |
| 归属与身份 | 读取实际负责人和已保存的来源学服，再沿机会、邀约和关联线索回退。未关联 Student 的 Lead 保留独立身份。 |

报名确认前序阶段的标签继续属于学生阶段依据，不自动生成具体接通或测评次数。数据口径弹层列出日期待补的来源数量。

- 各业务表每页读取 200 行并按主键稳定排序，避免 API 单次返回上限截断结果；总读取保护仍为每来源 10,000 行，达到保护上限或读取失败时显示受限状态。
- 当前学期班级沿用 `resolve_classroom_scope` 与 `list_classrooms_for_scope` 的授权和分页。`classrooms.term_id` 未直接开放列读取，本次通过既有目录筛选取得班级范围。
- 今日工作中的周摘要复用同一日期、报名去重和当前学期口径。
- 继续使用当前登录身份、既有 RPC 和表的行级权限。
