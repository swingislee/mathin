# 开放图形材料 · 开发增量

状态：开发端已交付，待人工视觉与教学手感验收。未操作生产环境，未关闭阶段 Gate。

## 可操作范围

- [基本图形认识](http://192.168.5.213:3130/zh/tools/plane-shapes)：默认单一材料，不自动给出边数／顶点数结论。右侧“绘制图形”可拖出长方形、圆、椭圆或逐点围出多边形；也保留快捷形状与生活实例。
- [平面图形运动](http://192.168.5.213:3130/zh/tools/plane-motion)：使用同一构造模型，平移、绕点旋转、沿轴对称作用于老师实际创建的材料。开启操作面板才显示旋转中心／对称轴，可拖动或填准确坐标。
- “编辑当前图形”显示可拖编辑点，支持在选中边上加入编辑点或移去编辑点。共线控制点不增加数学边数和顶点数；自由改动矩形角点后按自由多边形处理。观察边界／顶点只高亮，不暗中改变图形。
- 长宽、半径和方向读取实际材料；生活实例的细节与轮廓同步变换。数量、名称、测量默认关闭。原位轮廓来自真实语义运动起点，不另造一张固定模板。

## 共用与兼容

绘制复用 `usePlanarDrag` 的捕获和取消逻辑，宿主负责非模态面板、历史、语义动画及课堂。完成的材料通过 `plane-shapes-lesson-v2`／`plane-motion-lesson-v2` 自动进入原 Tools 备课、两类课件及课堂接入。旧 v1、历史合并工具与已存副本保留；按版本校验，互相混用状态会被拒绝。

SQL 只追加严格几何校验与版本映射，不改写旧数据或 RLS；新对象数量、真实几何、键集合和标记均有边界。绘制草稿及反射中间投影帧不保存为准确起点。

## 检查

- TypeScript、受影响文件 ESLint；共用工作台真实 DOM 测试覆盖自定义绘制、编辑、失焦／双指／Esc 取消、权限和外部权威替换、撤销、暂停继续及只读端。
- 场景与课堂合同覆盖两个新版本、原模板版本、两种编辑器固定副本及课堂事件；数学测试覆盖真实几何和变换，边与顶点观察采用真实转角。
- 本机只读 preflight 核对执行主机、实际 Supabase origin、监听、Docker 隔离网络和数据库标识后，运行新旧三组 SQL 回滚断言，再应用 `20260927110000_plane_construction`。测试材料全部回滚。函数类型由核对后的本机 pg-meta 生成，仅合并本次两项。
- 共用 SVG 对照页生成成功；复用现有开发服务，两个入口 zh/en HTTP 均为 200。未运行浏览器自动验收或生产部署。

## 后续范围

此增量落实“材料可以自建，操作仍然成立”的共同基础，不代表其余工具已经完成开放化。剪拼的任意合法切线、折纸的自定义纸张／折轴、计数和路径的自建结构仍待逐项扩展；七巧板等明确材料约束继续保留。

建议先人工试“画不规则四边形 → 拖动一个编辑点 → 关闭编辑 → 绕自设中心旋转 → 沿自设轴对称 → 保存并重新打开”。电脑与触屏手感、浮窗遮挡及课堂使用仍由产品负责人验收。
