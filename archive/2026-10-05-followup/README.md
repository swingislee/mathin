# 2026-10-05 全仓辅助流程复查

本轮承接产品负责人“再做一次全仓巡检，看是否仍有过时流程、规范、测试夹具”的要求。以巡检开始时 3,734 个未归档的已跟踪文件为静态扫描范围，重点核对规范入口、操作命令、辅助脚本、测试依赖和夹具。现行工作从 [产品方向](../../docs/product-direction.md) 与 [操作规则](../../docs/agent/operations.md) 进入。

## 本轮处理

- 归档四个旧 R1/P4E 手工造数脚本及其家庭权限核对脚本；相关历史页面和人工验收链路已经退出，当前家庭业务与权限用例继续保留。
- 归档没有现行调用者的微信 Next 临时路由、已交付固定教具迁移脚本及专用检查、仅被历史入口调用的局部数据库类型拼接器及其用例。
- 协作读取器继续核对任务、仓库内路径和独占范围冲突，允许从当前目录查看其他任务；去除固定集成人、强制工作区和分支形式要求。把上批登记中的通配符展开成合法的精确路径，恢复登记可读性。
- 更新 Auth 兼容层、家长端和两份教具 README：移出失效命令、过时启用状态和默认批次验证要求，修复历史证据链接。平面教具的圆弧状态说明与现有版本保持一致。
- 三处测试读文件路径对齐测评和班级当前入口；课件集成检查改为核对现行讲次工作台。旧导航布局、已退役夹具和过时流程要求从混合用例中移出，业务及权限断言继续保留。

[manifest.json](manifest.json) 记录每份原文件的来源、去向、取舍理由和 SHA-256：共移动 10 个文件，另存 13 份修订前原稿。原稿保留当时字节及目录结构；恢复时按清单取回，在当时源码与依赖背景下使用。

## 保留与检查范围

Auth 兼容补丁、Dockerfile 与原生 Go 夹具仍支持当前身份兼容维护；导入资源和数学场景样例、有效 E2E 辅助、保存恢复及权限相关用例继续保留。历史命名、日期或版本本身不是退役依据，既有数据库迁移与冻结内容保持可追溯。

本轮静态核对通过：65 份现行 Markdown 的本地链接与明确 Node 命令入口没有缺失；686 份测试代码中识别到的 1,138 处字面文件读取路径全部存在；23 份归档摘要匹配；退役文件没有残留的现行执行引用；8 份改动代码语法解析和工作副本登记读取通过。扫描覆盖明确的链接、导入与字面路径，不推断动态拼接的全部运行行为。

本轮未运行功能回归、浏览器或数据库检查，未执行数据库写入、服务切换或生产操作。以上是仓库静态整理结果，产品可用性和教学手感仍按具体任务验收。
