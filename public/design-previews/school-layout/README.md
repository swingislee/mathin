# 学校运营排布试用

2026-09-19 产品讨论原型。使用共同的虚构名单，比较三种可实际操作的排布。现有业务页面、权限和数据保持原状。

## 入口

- [比较入口](http://192.168.5.213:3130/design-previews/school-layout/index.html)
- [A：对象集中](http://192.168.5.213:3130/design-previews/school-layout/a-objects.html)：学生、班级、活动是常用入口；分班提升为共同班级工作面，班级内切换组织安排、教学记录和续班。
- [B：业务分区](http://192.168.5.213:3130/design-previews/school-layout/b-business.html)：招生处理新客、测评和等班；教学处理班级与课次；续班是独立业务。学生档案用于跨业务查找。
- [C：工作清单](http://192.168.5.213:3130/design-previews/school-layout/c-worklists.html)：今天、在读班级、新客联系、测评、等班、寒假续班、周末公开课直接作为可进入的工作清单。

顶部“用同一件事比较”会将各方案定位到相同业务场景。三个文件与 `layout.css`、`layout.js` 放在同一目录，也可直接打开 HTML 使用。

## 可体验的操作

- 展开班级，点学生查看记录、课程关系和本课登记。
- 将沈念、陆明哲、白可欣从等班安排至同年级、有余量的班级。
- 逐人登记寒假续班意向，筛选结果，保存后继续下一位。
- 登记本课出勤、课堂观察、公开课到场和家长反馈。
- 登记新客联系、完成测评，查看更新后的名单与完整历史。
- 切换学服、教师和负责人体验视角；教师班级视图默认显示李老师任教的班级。

结果只保存在同源浏览器的 `mathin-school-layout-demo-v1` 存储项中。三个方案共用该示例存储；“重置示例”恢复虚构初始名单。存储不可用时，编辑仍在当前页面内有效。原型没有网络写入或业务 API 调用。

## 验证范围

已核对脚本语法、六个页面／资源的开发服务响应，并用 DOM 环境检查三套导航、场景切换、入班、续班、课堂、活动、学生历史与关闭弹层的主要交互。布局与使用直觉待产品负责人实际体验；这些检查不构成现有业务系统的运行验收。
