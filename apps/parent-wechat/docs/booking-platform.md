# 预约小程序完整配置与连接

开发入口：`http://192.168.5.213:3130/zh/dashboard/miniapp-settings`。页面、服务、表单、流程、规则、资源、字典、网页、通知、报告与业务连接在同一工作台维护。首次打开已有配置时补齐完整模板，保存为草稿后预览，发布才影响小程序。

现有测评和活动继续使用自己的报名表、真实排班及原权限。通用规则不改写这些业务的约束；编辑器会提示不适用的绑定。外部支付、套餐权益、统计、身份交换、外部报告等已经有类型合同和能力标识，仍需接入对应流程；界面标注“已预留”，不能仅凭勾选推定已连接。候补名额开放及支付事件尚未接入事件源，规则可保存为停用状态。

历史保存、发布回退与旧版客户端兼容：`protocol=2` 获取元数据清单，正文按页面单独授权读取；旧协议不接收新动作。草稿不会进入公开接口。受保护正文不进入公共缓存；私有图片按当前权限签发短期 URL。发布使用版本比较，冲突时保留编辑内容并提示重新读取。需要首次更新小程序客户端才能使用新模块，此后已支持的内容可由后台发布。

## 业务提供方绑定

工作台“业务连接”新增 `http-v1` 连接，复制连接标识。部署环境的私有变量 `MATHIN_MINIAPP_PROVIDERS` 是按连接标识索引的 JSON 对象，每项字段如下。真实值只写到私有环境配置，不保存到公开设置、源码或日志。

| 字段 | 用途 |
| --- | --- |
| `endpoint` | 公网 HTTPS RPC 地址，无账号密码和认证查询参数，仅允许标准 443 端口 |
| `token` | 服务端 Bearer 凭据，至少 16 字符 |
| `identityKey` | 至少 32 字符的专用身份映射密钥，计算账号和参与人的 HMAC 标识 |

账号映射由提供方建立；请求不会携带 Mathin 登录令牌、真实账号 ID、手机号或姓名。用户主动填写的表单回答会提交给所选服务提供方。连接检查只返回绑定与能力状态。更换凭据可沿用预约；更换地址或身份映射密钥后，旧预约停止远程修改并保留历史，需原连接迁移方案。

所有调用为 JSON POST：`{version:1, operation, ...input}`；认证在请求头。类型定义见 [provider-protocol.ts](../../../contracts/participant-api/provider-protocol.ts)。实现中的响应以 Zod 再校验；第三方错误正文不会回显给用户。

首次调用 `capabilities.read`，响应 `{version:1, capabilities:[...], contracts:[...]}`。声明必须符合实际能力，预约需要 `booking.v1`、`policy.v1`、`idempotency.v1`；通知需要 `notifications.v1`、`idempotency.v1`。握手最多缓存 60 秒。

| 已接入操作 | 输入重点与返回 |
| --- | --- |
| `availability.read` | 账号映射、外部服务 ID、起止时间、规则、时长、资源。返回 `slots`，含时段 ID、起止 ISO 时间、剩余量、资源 ID；单次窗口不超过 31 天。 |
| `booking.create` / `waitlist.join` | 稳定 `requestId`、账号与参与人映射、外部服务、时段、回答和同意版本、规则及资源。返回预约对象。 |
| `booking.read` / `booking.cancel` / `booking.reschedule` / `waitlist.leave` | 原提供方预约 ID、同一账号映射、稳定请求号；改期附新时段。返回同一预约对象。 |
| `notifications.send` | 消息 ID 作为幂等号、账号映射、渠道、提供方模板标识、标题、正文和事件变量。接收方已授权且持久接收后返回 `{accepted:true}`。 |

预约对象字段为 `id`、`actor`、正整数 `version`、`status`、可空 `startsAt`/`endsAt`、`note`、`canCancel`、`canReschedule`。状态为 `requested`、`confirmed`、`cancelled`、`completed`、`noShow`、`waitlisted`。每次真实变更递增版本，同一版本内容必须相同；旧版本响应不能覆盖本地新状态。

提供方须用事务落实容量、资源占用、缓冲、参与人数量、人工/自动确认及候补规则，并持久去重 `requestId`。小程序服务端另外校验参与人权限、当前版本、表单、时段范围及取消/改期截止。网络结果不确定时重试原请求，不能生成新的预约号。当前外部预约状态在用户刷新时同步，提供方 webhook 推送属于后续接入点。

网络边界：请求最多 256 KiB，响应最多 512 KiB，超时 10 秒；只连接经校验的公网 IPv4，固定 DNS 解析结果、验证 TLS 主机名、不跟随重定向。外部网页与 RPC 地址分别配置。URL 中的私有令牌不用于登录；身份交换合同预留一次性短票据流程，当前网页不会调用它。

## 通知任务

服务端配置 `MATHIN_MINIAPP_NOTIFICATION_WORKER_SECRET`（至少 32 字符）。任务进程使用同值，设置 `MATHIN_MINIAPP_WORKER_ORIGIN` 后运行 `node scripts/miniapp-notification-worker.mjs`；`--once` 只处理一批。任务只使用 HTTPS 或 loopback 本地地址。部署时作为独立进程管理，当前开发交付没有自动启动长期任务。

消息提供方负责接收人映射、微信订阅授权/模板、短信或邮件授权。系统只传账号映射和配置的服务事件，不传真实学生 ID。报告通知在生成及领取时复核当前可读权限。已开启的小程序内消息无需外部任务。通用通知尚未订阅原测评/活动预约变更，报告发布已经接入。
